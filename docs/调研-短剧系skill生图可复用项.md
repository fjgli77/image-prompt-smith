## 二、七个能直接搬的机制

### 1. 风格 = 九槽区间块（来自 manju-laoli `style-prefix-blocks.md`）

它把"风格"写成一整块可逐字粘贴的常量：

```
成像底层 / 形体骨相 / 影调区间[光比] / 色彩区间[色温+饱和] / 空气介质
/ 光学区间[焦段] / 材质响应 / 特效语言 / 针对性禁项
```

三个细节价值最高：

- **用区间不用单值**：`光比 [1:6,1:10]`、`镜头 [21mm,28mm]`、`饱和度 [中,高]`。单值会逼模型每张重掷一个随机点，区间给弹性又设边界。
- **针对性禁项**：每套风格自带"我最容易漂成什么"（徐克块写`禁塑料感三渲二 / 禁均匀打光`），比通用负面词准十倍。
- **越界即判漂移**：镜头要求 `[21,28]mm`，提示词里出现 `16mm` → 判画风漂移，不是构图问题。这让"风格"第一次变成可机检的东西。

### 2. 风格候选卡 + 冻结（同源 `style-lock-protocol.md`）

四张卡，每张固定三行：**看得见（具体参数）/ 易跑偏 / 适配用途**。选定即冻结，中途改 = 重开。

另有**八族互斥对**（硬光×柔光、厚写实×动画平涂、留白×满幅…）由脚本常量机检。这条比"风格别混"这句劝告有用得多——它给了可执行的边界。

### 3. 专名转译：交付稿零人名（同源，F-4 铁律）

"王家卫风格"这类写法：不可复现（随版本漂）、不可检查、商用有风险。
正确做法是转译成参数：`手持微晃 + 抽帧 + 钨丝暖黄×霓虹青绿 + 光比[1:4,1:7] + 颗粒[中,高]`。

> 这条修正了我上一版的写法：`05-styles.md` 里用了 `studio ghibli style` 作示例。现在标注为「探索稿可用，交付稿转译」。

### 4. 三视图九字段 + 用途先行（zenstory）

模板不是从"角色长什么样"开始，而是从**"这张图给下游复用什么"**开始：认脸 / 认衣服 / 认状态 / 认局部。用途决定视图数量、光线、背景。

配套三条硬规则：

- **画面内无视图标签、无引线箭头、无尺寸标注、无图注**——图上的字会被下一环继承
- **每个视图指定一个"该视图可见"的认人特征**（正脸看得清的眉距瞳色，撑不起背面）
- **光线按"要对比什么"选**，并列出代价：均匀正面光让五官位置好比，但压平立体感；侧光给体积但丢暗部细节

### 5. 正面穷举（libtv `prompt-recipes.md` §6）

实测结论：负面指令很弱，**提名字反而召唤**。写`禁止出现狗`连改三版都出狗；改成`画面里有且只有：女主、漂浮姿态、蓝色海水、珊瑚`一次就干净。

同源还有**数量铁律**：`总数严格等于 N` + 逐个点名 + `不允许第 N+1 个、不允许分身`；且参考图不能用"多姿态拼图"（那张图本身就在暗示"有很多个"）。

### 6. 参考图污染与职责分工（libtv §1/§10/§11/§12）

- **参考图里有什么，输出就照抄什么** → 排查穿帮第一步是翻参考图
- **职责三段式**：`只取脸型发型` + `衣服完全不按这张图` + `正面描述新款 + 负面排原款特征`
- **in-scene 锚定**：道具单品图会被"重新设计"，"道具已在场景里"的合成图会被照抄

### 7. 联想触发词（libtv §17）

写"农村/砖房/90 年代"会触发模型的破败滤镜。解法与正面穷举同构：**删触发词 → 正面描述"被打理好的温馨家" → 硬负面兜底**。

## 三、没搬的三样，及理由

| 不搬 | 理由 |
|---|---|
| 74 组导演风格目录 + 11 槽参数全表 | 那是**剧集生产**的资产（要按题材×打斗强度路由），对通用单图是过度设计。只取"九槽 + 区间"这个结构 |
| 帧率/升格/抽帧/表演四拍 | 视频参数，静帧无意义（除"颗粒/拖影"这类可转成摄影语言的） |
| 真人合规墙、审核探针 | 平台侧限制，与提示词写法无关；写进 skill 只会误导 |

## 六、一句话结论

**这批仓库里真正能迁到生图上的，不是"风格词库"，而是三套"约束机制"**：

1. 把风格写成**带上下限的区间**（可复现、可机检）
2. 把参考图**先分工再使用**（防渗透、防污染）
3. 把排除写成**白名单**（正面穷举 + 数量封顶）

词库谁都能写，这三套机制才是它们花了几十个版本试出来的东西。
