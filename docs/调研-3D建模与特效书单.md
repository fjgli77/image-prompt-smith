## 一、原书单

### 1.1 3D 人物建模美学与设计

| 书籍 | 核心定位 | 最适合谁 |
|---|---|---|
| **《3D艺用人体解剖学》**（3dtotal 编） | 2D 设计到 3D 雕刻的解剖桥梁，覆盖比例、骨骼、肌肉、皮肤细节 | 想打牢人体形体美学基础的人 |
| **《藝用3D人體╳表情解剖書》**（烏迪斯·薩林斯） | 面部表情"圣经"，用 3D 模型拆解肌肉骨骼如何驱动表情 | 专攻角色面部与情绪表现的人 |
| **《Anatomy for Sculptors》**（Uldis Zarins） | 为雕塑家和 3D 角色创作者写的解剖书，强调体量与块面 | 想用雕塑思维理解人体的人 |
| **《Figure Drawing: Design and Invention》**（Michael Hampton） | 从解剖走向"设计"，讲姿态、重心、张力与形体表现力 | 想把"做对"提升到"设计好"的人 |
| **艺术理论三本**：《How to Render》《Color and Light》《How to Draw》 | 光照、阴影、反射、色彩与从想象构建物体的底层原理 | 想提升打光、材质与构图审美的人 |
| **《ローポリで極めるキャラクターモデリング》**（高部） | 低多边形风格化角色设计，强调轮廓、剪影、色块与平面化美感 | 走 Low-Poly / 风格化路线的人 |

**一句话总结**：先靠解剖书建立可信结构，再用设计书和艺术理论把"准确"升华为"有意识的美学设计"，风格化方向另看低多边形专著。

### 1.2 3D 动漫建模

| 书籍 | 核心定位 | 最适合谁 |
|---|---|---|
| **《Blenderでつくる：亥と卯流 セルルックキャラクター》** | 2D 设计稿到赛璐璐渲染全流程，强调动漫感由建模、材质、渲染共同定义 | 想要完整动漫角色成品流程的人 |
| **《Blenderでアニメ絵キャラクターを作ろう！モデリングの巻》** | 聚焦头部、身体、衣装建模，讲"为什么这样建"；续篇接卡通渲染与动画 | 想先打牢动漫角色建模基本功的人 |
| **《VRoid Studio超入門講座》** | 快速产出动漫风格角色的轻量路径 | VTuber、插画、轻量内容创作者 |
| **《Maya建模從入門到實踐》** | Maya 多边形建模，含卡通、Q 版角色案例 | 必须走 Maya 工作流的人 |
| **《3ds Max动漫游戏角色设计实例教程》第 2 版** | 动漫游戏角色建模教材，含写实、Q 版、幻想风格案例 | 必须走 3ds Max 工作流的人 |

### 1.3 3D 动漫特效

| 书籍 | 核心定位 | 最适合谁 |
|---|---|---|
| **《Blenderではじめる視覚効果・VFX制作実践入門》** | 用 Blender 完成物理演算、合成、运动追踪等完整 VFX 案例 | VFX 入门与个人创作 |
| **《VFX Made Easy with Houdini》** | 粒子、烟雾、火焰、流体、破坏等程序化工业级工作流 | 决定深入 Houdini 的人 |
| **《The VES Handbook of Visual Effects》第 3 版** | VFX 行业标准参考书，覆盖数字角色、合成、3D 扫描等全流程 | 想建立行业全局认知的人 |
| **《Maya动画特效从新手到高手》**（来阳） | Maya 粒子、布料、流体等特效模块操作参考 | Maya 特效学习者 |
| **《3ds Max三维动画特效剖析》** | 3ds Max 三维动画特效模块剖析 | 3ds Max 特效学习者 |

**一句话总结**：动漫建模书的核心是教你"如何设计并渲染出动漫感"，特效书的核心是"掌握特定软件或工业级工作流"。

### 1.4 按目标选书

- **想系统提升人物形体与美学**：解剖三本 →《Figure Drawing》→ 艺术理论三本。
- **想做 Blender 动漫角色**：重最终效果选《セルルック》；重建模基础选《アニメ絵キャラクター》建模卷。
- **想快速产出动漫风格角色**：评估 VRoid Studio 路线。
- **想入门 VFX / 个人创作**：从 Blender VFX 实战入门开始。
- **想走专业特效 / 影视流程**：先读 VES 手册建立全局认知，再按软件深入 Houdini 或 Maya / 3ds Max。

**总原则**：选书优先匹配你的**软件、目标风格和制作深度**，而不是追求"最全面"。

## 三、可迁移性判定（关键）

不是所有书都能变成提示词。按"能否翻译成可执行约束"分三档：

| 档 | 书 | 判断 |
|---|---|---|
| **A 能直接变成词** | 低多边形专书、艺术理论三本、Hampton | 低模 → 面数分区 / 剪影 / 三色 / 面片朝向；艺术理论 → 明暗三值、反射光、色温对比；Hampton → 动态线与"设计优于准确" |
| **B 只能当风格来源** | Blender 赛璐璐、Blender 动漫建模卷 | "动漫感由建模 + 材质 + 渲染共同定义"与 `anime-3d.md` 的"写死影子写法 = 写死流派"是同一件事的软件侧表述，能补"渲染器差异"，但转不成独立词法 |
| **C 基本不可迁移** | Maya / 3ds Max / Houdini / VES 手册 | 讲的是 DCC 操作与工业流程。本 skill 是"描述 → 提示词"，不教人点菜单；它们只有**选书参考**价值 |

**结论**：这份书单**不能整份塞进 reference**。正确落法是"A 档挑出来写成词法，B 档做交叉引用，C 档留在本文件当选书指南"。

## 四、落地成了什么

### 4.1 新增 `references/character/low-poly.md`（约 230 行）

A 档里唯一值得单开一章的——因为低模的规则**与所有其它风格冲突**（面数要分区、光要硬、色只能三块、细节必须少）。原 `character-styles.md` 只有四行块词，撑不住。

内容：

- **面数预算法**：头 40–50% / 手高于预期 / 躯干极简；三条铁律（不均分、细节跟视线走、同图级别一致）
- **面片朝向就是形体**：额头向上、颧骨斜下、下颌向耳——"翻一条边就是颧骨分明和胖脸的区别"
- **三色规则**：60–70 / 25–35 / 5，明度差优先于色相差
- **光只干一件事**：让三角面生成明暗图案（单一硬光 + 硬阴影 + 克制 AO）
- **面数档位表**：200–500 艺术向 → 5000–12000 高精度低模
- 中英成品块、隔离反向、八个崩坏点、八项自检

> 最有价值的一句：**提示词不要写 `800 tris`，要写"头与手密、躯干与腿为大块平面"**——模型不执行数字，只执行"哪密哪疏"。

### 4.2 新增 `references/character/text-to-3d.md`（约 200 行）

书单里"3D 建模"方向真正的延伸：**原来 skill 只覆盖"出图给人建模"，没覆盖"直接喂 3D 生成器"**。检索 Meshy / Tripo / Hunyuan3D 的官方口径补齐：

- 路线判定：text→3D / image→3D / 多视图→3D / 要绑骨该走哪条
- **六层简报**：对象 / 用途 / 几何 / 材质 / 纹理 / 约束（少一层生成器就自己填）
- **绑骨五条件**：A-Pose 55° 外张、四肢间有完整背景带、双腿留缝、关节不被披风长发遮、单层衣少配饰
- 面数拓扑口径：300k 上限、先 triangle（quad 计数歧义会翻倍）、绑骨前 remesh、basecolor 4k
- 3D 专用负向：`no floating parts / no thin sheets / no fused limbs`
- 六类固定失败与改法、三平台差异、交付三句话

> 关键判断：**text→3D 的提示词不是描述，是技术简报。** 写"唯美、氛围感强"等于没写。

### 4.3 补 `vfx.md`（新增"六·五 体积感的三条物理条件"）

B 档里 Blender/Houdini/VES 的可用部分，最终落到三条**能立刻写进词**的规则：

1. **体积光必须有介质**——不写 `dust motes in light beam`，永远出不来光柱；
2. **流体写三个属性**（粘度 / 湍流速度 / 与光交互），不是四个形容词；
3. **镜头缺陷才是真实感**（变形光斑 / 85mm f/1.4 / 边缘色差），但主特效片最多两件。

### 4.4 机检与入口同步

- `prompt_lint.py`：新增"低模未分面数（P2）/ 低模混高模细节（P1）/ 3D 生成缺四肢分离（P1）/ 3D 生成未排除悬空件（P2）"；`--purpose` 新增 `model3d`（该用途下豁免光段/镜头/画幅检查——3D 简报没有相机）。自测 **19/19**。
- `SKILL.md`：路由与升级表各加两行；铁律 18 → **22 条**（新增低模 1 条、3D 生成 3 条）。

## 五、一句话结论

**这份书单的价值不在"读完这些书"，在它逼出了一个此前没覆盖的档位：**
`aesthetics.md` 管"形状对不对"，`modeling-handoff.md` 管"图能不能用"，
差的那个中间层是——**低模只有形状和颜色，没有第三次机会**；以及**机器直接吃的那份简报，比图更不容糊弄。**

选书仍是原书单的总原则：**匹配软件、风格、深度，而不是求全。**
