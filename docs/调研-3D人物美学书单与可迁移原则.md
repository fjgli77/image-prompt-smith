## 二、五条被反复讲的原则（跨书共识）

### 1. 先形状，后五官

四本书的顺序完全一致：**几何形 → 剪影 → 体块 → 五官**。
而多数提示词是反的：上来写"凤眼、柳叶眉、唇珠"。

> 同一套五官，配圆身体是温柔，配三角身体是阴狠。

### 2. 一个主形，一处夸张

- 主形三选一：圆（亲和）/ 方（可靠）/ 三角（危险）
- 夸张四选一：头 / 手 / 肩 / 眼
- **两处以上同时夸张 = 比例崩 + 没有重点**

### 3. 剪影测试

把图填成纯黑，还认得出是谁吗？认不出就是造型问题，加细节救不回来。

### 4. 负空间与切线

AI 出图最高频的"看着对但用不了"：手臂粘躯干、手指粘大腿、武器贴背。
根因是没写负空间，模型把两个形体画成一整块。一句 `clear gap between arm and torso, no tangent lines` 能解决大半。

### 5. 体块感来自概括，不来自细节

写"块面清楚"给结构图，写"毛孔绒毛"给糊图。3D 建模尤其吃这套——
`Anatomy for Sculptors` 在 Fortiche（《双城之战》）的建模流程里就是当体块字典用的。

## 三、落地成什么

新增 `character-drawing/references/aesthetics.md`（六轴）：

1. **形状语言**：圆/方/三角 + 主副破三层比例（70/20/10）
2. **剪影**：可读性 + 负空间 + 关键凸起 + 反切线
3. **体块**：九个部位的几何体对应 + 与 3D 动漫 `planar` 的接点
4. **动态线与重心**：一条弧线 + 承重脚 + 骨盆倾斜 + 肩髋反向
5. **比例节奏**：头身/三庭/五眼/肩宽/腿长/手臂落点
6. **夸张**：一处原则 + 三档幅度（R1/R2/R3）
7. 附：负空间与切线专章、视觉重量与明暗结构、三套组合示例（圆润治愈/锐利刺客/厚重守卫）、反例清单、八项自检

接入方式：

- `SKILL.md` 新增 **Step 0.5 先定形状语言**（放在"锁定风格"之前）
- 拼接公式 十三段 → **十四段**，【形状语言】排第一位
- 关键提醒加三条：形状先于五官 / 夸张只放一处 / 负空间必写
- 机检加三条：人物未定形状语言（P2）、全身未写负空间（P2）、资产级全身未提剪影（P2）

## 四、验证

```
自测 13/13 通过
合规样例（形状+剪影+负空间+动态线+比例）→ 100 分
反例（只写"鹅蛋脸柳叶眉凤眼"的全身立绘）→ 96 分，命中 2 条 P2
```

一句话：**这三本书真正教你的不是"怎么画脸"，是"怎么让一个形状在 0.5 秒内被认出来"。**
提示词要写的，就是那个形状。
