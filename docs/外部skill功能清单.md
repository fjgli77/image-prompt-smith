### 3. short-drama-factory（V4.9.1）—— 纯剧本层最硬

- **三档篇幅**：标准 90–120s / 长档 150–195s（双回合+中段小钩）/ 漫剧 60–90s
- **情绪契约单元链**：单矛盾 20–30 集必闭环、三缝合一换矛盾、每单元一张往返回合表
- **付费墙挂单元接缝**
- **单集 15 秒四拍换挡**：0–15 抓人 / 15–45 交锋 / 45–85 亮牌 / 85–110 余波
- **强画面三大锚点**：每 2~4 句必插 1 条 `△`，连续纯对白 ≤6 行（E24）
- 大白话同轮直给（E25）、封杀无效微动作（E26）
- **流派分流**：情绪流 ⇄ 剧情流
- 前三集节拍卡、人物圣经（欲望/秘密/弧光/语言指纹）
- **网文改编流水线**：抽取→砍并→章集映射→回合化
- **剥壳留核仿写 + 40 赛道全图**
- **跨集连续性台账**（伏笔/人物/道具/规则四账）+ **A~I 九类反转轮换**（相邻 3 集禁复用）
- 台词七维直给、独白旁白受控
- 机检 `E1~E26`（单集）+ `S1~S8`（全剧），均含 self-test
- **8 个交互模式 + 动态按需挂载**（防 Context 爆炸）
- 评审官/修复器双角色、P0/P1/P2 定级、**保护性反例**（防误伤安静场）

- `spatial-anchor-and-hold.md` 空间锚点卡 / 维持句 / 站位门窗分身专治
- `atmosphere-and-light.md` 氛围三层分工 / 段首六件套
- `camera-four-axis-h3.md` 八档四轴 / 回合制切镜
- `h3-lexicon-cleanup.md` **五遍词根清洗 + 九条改写公式**
- `dialogue-density.md` **3.3 字/秒标定、一镜一句**
- `acting-facs.md` 四区肌肉 + **30 种情绪英文配方**

**核心机制**

- **双 checkpoint 路由**：FL2VA（三字段）/ Ref2VA（六段式）
- **H1~H36 机检**（`h3_lint.py`），含跨段图槽一致性、图槽越界

- **真机坑专治**：穿门融化、同框分身、门窗状态锁、画外敲门污染、物理推理死锁（半蹲+静置）、画幅写进正文

### 6. shanyin-screenwriting-master —— 单文件，纯方法论

### 7. huangbai-AI/post-production-skill —— 一个母版，不要高估

## 四、三条能直接用的观察

**① 台词语速，三个独立源都比我原来的 5.5 慢。**
老李 4.1、H3 包 **3.3**、zenstory 4.1。我 3.7 版已改到 4.2/3.7/4.0——**仍比 H3 包的 3.3 快**。
H3 是"一镜一句"的硬约束模型，3.3 是它的物理上限；我按 4.0 折算是通用值，遇到 H3 项目应该单独调 `--cps 3.3`。

**② 别人的强项集中在我不做的两段：付费卡点、真渲染。**
`short-drama-factory` 把"付费墙挂单元接缝""单矛盾 ≤30 集闭环"做成硬规则；`zenstory` 的 `short-drama-edit` 是**真的跑渲染**。
我做的是提示词层，这两块要么不碰，要么单独补。

**③ 真机坑这件事，只有 H3 包做到了可执行。**
它把"穿门会融化""半蹲+静置会卡 76%""画外敲门会绑错主体"写成 H29~H33 可检查项，还配 50 条症状码。
我的 `18-failure-atlas` 是"崩坏案例"，但没有"症状码 → 排查树"这套检索结构——**这是最值得抄的一处形态，不是内容**。
