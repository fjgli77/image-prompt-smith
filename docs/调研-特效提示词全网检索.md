# 特效提示词全网检索（2026-11-16）

> 检索源：ahaprompt（VFX 分类方法论）、FlowPix（两组实测）、LzyPrompt（视频特效物理）、
> MakeAIPrompt（七段 VFX 模板）、CSDN/Firefly 工作流、菜鸟AI（光效层次）。
> 目的：把"特效"从"堆几个词"升级成"可复现的写法"。

---

## 一、最有价值的五个判断

### 1. 特效不是"长什么样"，是"怎么发生"

> VFX 最典型的失败是「凝固的海报」：爆炸像贴在天空上，烟像挂着的棉花，闪电只是装饰线条。
> 模型渲染了特效的样子，却没有渲染它的物理。——ahaprompt

对照：

| 状态（废） | 事件（有效） |
|---|---|
| 一团火 | 火从横梁底部点燃，向上舔舐，边缘卷曲成焦黑 |
| 魔法爆炸 | 尘土从撞击点向外环状点燃，冲击波卷过碎屑，余烬映亮沉降的薄雾 |

**每个词自带运动与密度**：余烬是飘的，火花是溅的，浓烟是翻滚的，薄雾是悬停的，冲击波是荡开的。**"火"只是颜色，"点燃"才是事件。**

### 2. 特效要在语法上依附主体（防淹没）

> 特效在语法上依附主体时，构图就保住了主角；特效单独成句，就会吃掉整个画面。——ahaprompt

- ❌ `强烈的火花在画面中飞散`
- ✅ `火花勾出她的侧脸轮廓`
- ❌ `浓烟弥漫`
- ✅ `烟从她身侧分开，露出一道侧影`

这条比任何"降低粒子密度"的提示都直接——**只要每个特效句里出现主体，特效就抢不走画面**。

### 3. 粒子词只出现一次（实测最硬的一条）

FlowPix 实测：把 `glowing particles + fireflies + floating sparks + bokeh` 四个词堆一起，**十张糊七张**，前景后景全是白点。

改法：只留一个粒子词 + `sparse` + 负向 `dense particles, cluttered` → 十张恢复七张干净。

原因：**粒子词之间会叠加密度**，不是"各画各的"。

### 4. 要锚尺度，否则默认变屏保比例

> 用熟悉的东西锚定尺度：「一个街区大小的冲击波」「萤火虫大小的火星」。——ahaprompt

不锚尺度，"巨大爆炸"和"小火苗"在模型眼里没有区别。

### 5. 要写环境交互，这是"合成感"与"真实感"的分界线

- 冲击波压弯树梢
- 雨在发烫金属上嘶嘶蒸发
- 体积光照亮空气中的尘埃
- 烟被人物分开

流量数据佐证：`dust motes in light beam` 是"性价比最高、几乎不翻车"的一组词。

## 二、实测数据（可直接当验收标准）

| 特效类型 | 关键写法 | 十张干净率 | 最常见崩法 |
|---|---|---|---|
| 轮廓光 | `sharp rim light` + 方位 + `fading into darkness` | 8/10 | 光溢出到背景 |
| 粒子光点 | 单个粒子词 + `sparse` + 负向 dense | 7/10 | 密度叠加糊成雪花 |
| 烟雾 | `thin wisps of smoke` + 形态动词 | 7/10 | 浓烟堵在主体前 |
| 动态模糊 | `background motion blur, subject in sharp focus` | 6/10 | 主体跟着一起糊 |
| 光轨 | `light trails` + `long exposure` | 6–7/10 | 没有长曝光语境 |

补充实测结论：

- **全图笼统写 `motion blur`，十张只有两张主体立得住**
- `radial blur` 适合爆炸/冲刺；`vertical motion blur` 能让雨的方向听话
- 光效题材 SD 系 **CFG 锁 5.5–6**，高了辉光边缘出锯齿
- 星芒别用 `rays`（会变十字创可贴），改 `sharp starburst, natural diffraction`
- 粒子要 `varying sizes, some bokeh-blurred`，全一个尺寸像刷漆
- 颜色脏的根因：光源色太多 → 全场限两种主光色，第三色只做点缀
- 静态图的"闪烁感"三来源：**噪声**（subtle film grain）+ **疏密**（一大带六七小）+ **方向统一**

## 三、七段 VFX 模板（MakeAIPrompt 的可复用结构）

```
① 场景与主体（谁、在哪、什么姿态）
② 主特效（能量形态 + 类型 + 源头 + 颜色）
③ 二级粒子与碎片（火花/余烬/碎晶/残影）
④ 环境交互（怎么照亮场景、怎么被打破）
⑤ 大气（热浪、薄雾、臭氧感、镜头光晕）
⑥ 镜头（机位 + 景别 + 焦段 + 焦点）
⑦ 风格与画质（但别堆 8K/masterpiece）
```

我把它压成了更适合单图的三段句：**成因 → 发展 → 消散**，并保留"主/辅"分层。

## 四、别抄的东西

| 别抄 | 原因 |
|---|---|
| `8K, masterpiece, best quality, trending on ArtStation` 全家桶 | 不增加清晰度，只增加噪点风险 |
| 点名画家（Greg Rutkowski 等） | 探索稿可留；交付稿按 `11-style-block.md` §五转译成参数 |
| "magic explosion""big fire"这类单词特效 | 正是"凝固海报"的成因 |
| 把 `--v 6` `--s 1000` 当万能参数 | 版本参数以官方当日为准，旧文数字不可信 |
| 全图 `motion blur` | 十张只有两张能用 |

## 六、一句话结论

**特效提示词的竞争不在词汇量，在约束。**

同一条物理规律，写作"事件 + 依附主体 + 单粒子词 + 尺度锚 + 环境交互"，比堆二十个渲染词有效得多。
