> 目的：**把"能用的"和"看着像那么回事但其实是编的/过时的"分开**。

## 一、核心结论：3D 动漫不是一个词，是五条互斥路线

三个独立来源（FlowPix 五流派、觉醒学院国风3D五套、菜鸟AI 风格方向表）指向同一件事：

| 路线 | 一眼可辨 | 影子怎么画 |
|---|---|---|
| ① 全 3D 写实（次世代/虚拟人） | 像游戏 CG，看不出动画感 | 物理体积光、柔和过渡 |
| ② 三渲二 cel-shaded 3D | 3D 立体 + 2D 色块 | 一到两档**硬边**，无渐变 |
| ③ 国漫半写实（原神/崩铁向） | 五官精致、材质华丽 | 体积光 + 手绘感过渡 |
| ④ 皮克斯/迪士尼卡通 | 圆润弹性、夸张表情 | 柔和物理光 + SSS |
| ⑤ 风格化手绘 3D | 笔刷感多边形块面 | 大色块明暗、边缘不齐 |

**最有价值的一句来自 FlowPix**：

> 写死影子写法 = 写死流派。
> 赛璐璐：`hard-edged cel shading, two-tone shadow, no gradient`
> 皮克斯：`volumetric physical lighting, subsurface scattering, ambient occlusion in creases`

这解决了"写 3D 动漫却出塑料手办"的根因——**只写"3D 动漫"等于让模型在五条路线里随机抽**。

## 二、四个能直接用的发现

### 1. 建模语义只在部分模型上有效

"clean edge loops / subdivision surface topology / no visible polygons" 这串词，在 MJ v6+、Nano Banana Pro、Seedream 5、GPT Image 上确实能把画面往"3D 资产感"推；在 SD 系上是噪声（要靠 LoRA），小模型直接忽略。

**别一刀切**：写建模术语前先确认目标模型吃不吃。

### 2. 三渲二的"关掉真实感"比"加上卡通词"更重要

一篇讲 AI 生 3D 模型的文章（ipipp）里有个反直觉但正确的判断：

> 生成时建议关闭真实感材质选项，避免 AI 为让模型看起来真实而加凹凸、粗糙度变化、过深 AO——**这些信息进了三渲二材质反而会脏**。

对应到提示词就是：**三渲二必须显式禁掉体积雾、软渐变、真实皮肤**，只留硬边与色块。这也解释了为什么很多人写 "cel shaded" 仍然得到柔和过渡——因为他没禁柔和。

### 3. 即梦/Seedream 的三大硬伤，有现成修正句式

什么值得买那篇实测（废片率 80% → 5%）给了三段可直接粘的"结构修正指令"，本质是把形容词换成**结构、数量、角度、色温**：

- 面部：`两眼大小一致、瞳孔连线与水平线夹角 <2°、鼻梁中点在两眼中心正下方、耳上缘与眉平齐`
- 手部：`五指、中指最长拇指最短、拇指与食指夹角 30–45°、每指三个关节、指甲占末节一半`
- 光影：`删掉柔光/明亮/自然光，改左侧 45°/侧逆/顶光，写明鼻右侧三角阴影、颧骨下暗区、下巴投影，色温 5500K，光比 1:3~1:6`

这套东西的价值不在"3D"，而在**它示范了怎么把形容词翻译成可执行约束**——可以直接迁移到任何中文平台。

### 4. 一条真实的高质量社区 prompt 结构

MeiGen 上的 stylized 3D 手绘风 prompt，把"风格"拆成了三组并列词：

```
形体：angular faceted form construction / planar facial structure / simplified geometric anatomy
表面：broad graphic color masses / visible painterly surface treatment / irregular painted edges
光色：warm directional sunlight / gentle ambient occlusion / subtle rim lighting / soft bloom
反向：NO photorealism / NO glossy CGI / NO clean plastic 3D / NO anime lineart / NO cel-shading flat colors
```

**把"风格"拆成"形体 / 表面 / 光色"三组**，比堆一串形容词稳得多。这个结构我直接收进了参考库的成品块。

## 三、可信度分层（哪些别抄）

### ✅ 可用（多源交叉或实测）

- 五路线分野 + 影子写法判定法
- 头身比区间（3D 写实 7.5–8 / 国漫 7–7.5 / 三渲二 6.5–7.5 / 皮克斯 5.5–6.5）
- SSS（次表面散射）是"去塑料感"的第一关键词
- 三渲二要"禁柔和"而不只是"加卡通"
- 即梦三段修正句式（结构/数量/角度/色温）

### ⚠️ 别抄（过时或编造）

| 内容 | 问题 |
|---|---|
| `--v 6.6 --s 750 --q 2` 这套 MJ 参数 | MJ 当前是 v7，`--v 6.6` 不存在；`--s` 上限也变了。这类数字多为旧文复制或直接编造 |
| "九头身、修长双腿、完美五官"通用套话 | 会覆盖角色本身设定；且逐字重复会被模型当成"整套图的画风" |
| "3D 动漫 = 加 3D 两个字" | 正是本文要破的误区 |
| 重拓扑/非流形边/合并顶点那段 | 那讲的是"AI 生 3D 模型 → Blender 修模"，**不是生图提示词**，容易被误当教程 |

### 🔍 需要自己验的

- "原神风/崩铁风"这类作品名：探索稿能快速命中画风，但交付稿要转译成
  `semi-realistic anime 3D + painterly shading + layered fabric + gacha illustration aesthetic`
  （理由：不可复现、不可检查、商用有风险）

## 五、一句话结论

**"3D 动漫人物"的提示词难点不在"3D"，在"哪条 3D"。**

写对路线（用影子写法点名）→ 写对解剖（3D 体块，不是 2D 线条）→ 写死比例与手 → 禁掉相邻路线。
四步做完，塑料感、平涂感、Q版化三个毛病会同时消失。
