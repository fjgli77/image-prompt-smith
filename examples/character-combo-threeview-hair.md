# 组合请求示例：三视图 + 发型图

> 用户输入：**"给出三视图 + 发型图"**
>
> 这是一次**两种图型**的请求，不是一个。判定过程与两条成品词如下，可直接照这个手感套。

---

## 一、判定（四步，30 秒）

| 步骤 | 判断 |
|---|---|
| ① 判族 | 两个都是 **B 资产族** → 光必须平、姿态必须中性、背景必须纯色 |
| ② 查合图三条件 | 同姿态 ✅（都不需要动作）｜角度能对齐 ✅（都是正/侧/背）｜同光 ✅（都平光） |
| ③ 查取景 | 三视图＝全身，发型图＝头部特写，**差一个量级** |
| ④ 结论 | 合图会因为"上区全身、下区只有头"导致格高不等、头部过小 → **默认拆两条**，另附合图版备选 |

**为什么不能只出一张**：同图里全身格与头部格的比例差 4–5 倍，模型会把下排头部画成缩小的人，或者干脆把两区合成一整张立绘。这是"合图失败"最常见的形态。

---

```
二十七岁上下的东亚女性；黑发，发根纯黑、发梢冷褐，长及肩胛上缘；

7.5 头身；国漫 3D 半写实（三渲二与体积光之间）。
```

## 六、交付说明（三行，必须给）

1. **两条词锚点完全相同**，可以分别生成后再拼版；若发现两张脸不一致，先检查发梢色与分缝位置有没有写丢。
2. **图 2 只解决"发型怎么看"，不解决"头发怎么建模"**——要建模口径请看 `hair` 段（`body-parts.md`）与 `modeling-handoff.md` 的发束分组要求。
3. 若要补**发型分层图**（底/中/表三层），再出一条：`3 格横排，每格只画一层，移除的层完全不出现在该格`。那是建模用的，与上面两张不是一回事。

## 八、这套写法能迁移到哪些组合

| 组合 | 处理 |
|---|---|
| 三视图 + 服装正侧背 | 可合（服装三视就是三视的裁剪版），**只出服装版更省** |
| 三视图 + 骨骼视图 | 拆（骨骼要透视线框，与立绘冲突） |
| 表情集 + 口型图 | 拆（9 格 + 8 格同图必挤成蚂蚁） |
| 材质分区 + 配色图 | 拆（一个要纯色块，一个要角色本身） |
| 发型图 + 发型分层图 | 拆（一个看外观，一个拆层次） |
| 任何图 + 灯光参考图 | **绝不**合（它要求每格光位不同） |
