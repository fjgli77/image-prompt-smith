# 示例走查：一句"做个秋季咖啡海报"到可交付提示词

> 演示 B 档（版式档）全流程：判档 → 推断 → 版式蓝图 → 双平台主词 → 反向 → 参数 → 变体 → 机检。

---

## 0. 用户原话

> "帮我做个秋季咖啡活动的海报，要能放标题。"

## 1. 判档（Step 0）

关键词命中 **"海报" + "放标题"** → **B 版式档**。  
不是 A 快档：因为要留标题区，只给画面词会交付即废。

## 2. 意图解析（Step 1）

只问一项（用户没说平台），其余全推断：

```
推断：画幅 3:4（海报标准竖版）｜风格 生活方式摄影（写实）｜光 左侧窗光 45° 侧逆
      ｜85mm f/2.8 浅景深｜色 暖琥珀 + 燕麦，低饱和｜文字 留白后期，图内零文字
```

**为什么不定真文字**：海报主标题通常是品牌资产，模型写字成功率不稳，**留白 + 后期**是唯一零风险路径。

## 3. 骨架（Step 2）

选 **版式蓝图**：上 60% 主视觉，下 40% 纯色块承载标题。

## 4. 十一格落位

| 格 | 内容 |
|---|---|
| ① 形态 | 秋季咖啡活动海报主视觉 |
| ② 主体 | 一只哑光米白陶瓷杯，盛黑咖啡 |
| ③ 动作/状态 | 杯口细微热气、枫叶散落 |
| ④ 场景 | 做旧橡木桌 |
| ⑤ 风格 | 生活方式摄影（写实） |
| ⑥ 光 | 左侧窗光 45° 侧逆、3800K、光比 1:4 |
| ⑦ 镜头 | 85mm、f/2.8、浅景深 |
| ⑧ 构图 | 上 60% 场景 + 下 40% 纯色块；主体居中偏左 |
| ⑨ 色材 | 暖琥珀 + 燕麦，低饱和；木纹、叶脉、釉面 |
| ⑩ 文字 | 零文字，留白承载 |
| ⑪ 参数 | 3:4，2K |

## 5. 交付物

### 5.1 主提示词（Seedream 5.0 Pro / 即梦 / 豆包，中文原生）

```
3:4 竖版秋季咖啡活动海报主视觉。上区 60% 为场景：一只哑光米白陶瓷杯盛着黑咖啡，
杯口有细微热气，放在做旧橡木桌上，三片干枯枫叶散落左右；左侧窗光 45° 侧逆入射，
3800K 暖光，光比 1:4，85mm 镜头 f/2.8 浅景深，木纹与叶脉清晰可见。
下区 40% 为深墨绿纯色块，供后期排版标题。
整体生活方式摄影风格，暖琥珀与燕麦色，低饱和。
画面中不出现任何文字、字母、数字、标志与水印，不添加其他杯具与人物。
```

### 5.2 同需求（Midjourney v7，英文 + 参数）

```
editorial still life photo for an autumn coffee poster, a matte cream ceramic cup of
black coffee with faint steam, on a weathered oak table, three dried maple leaves
scattered around, window light raking from the left at 45 degrees, 3800K warm,
lighting ratio 1:4, 85mm f/2.8 shallow depth of field, warm amber and oat palette,
low saturation, lower 40% of the frame left as a clean deep-green color block
--ar 3:4 --style raw --stylize 150 --no text, watermark, people, extra cups
```

### 5.3 反向 / 禁令

```
SD 反向：text, watermark, logo, people, extra cups, clutter, plastic look,
         oversaturated, blown highlights, blurry, lowres
自然语言禁令：画面中不出现任何文字与标志；不添加其他杯具与人物；不改变杯子形状。
```

### 5.4 参数

| 项 | 值 |
|---|---|
| 画幅 | 3:4 |
| 分辨率 | 2K（交付）／1K 先试 |
| 建议模型 | Seedream 5.0 Pro 首选；MJ v7 `--style raw` 备选 |
| 种子 | 定稿后固定，便于换文案复现 |

## 6. 三条变体（各只改一格）

| 变体 | 只改什么 | 效果 |
|---|---|---|
| V1 暗调版 | 光段 → `单侧硬光 90° + 黑旗，光比 1:8，背景压到近黑` | 高级、克制，适合精品咖啡馆 |
| V2 俯拍版 | 镜头段 → `顶视 90° 平铺，50mm f/8`，构图改 `上半 50% 平铺 + 下半 50% 色块` | 适合小红书信息型封面 |
| V3 冷调版 | 色段 → `冷灰 + 一点砖红`，色温 → `6500K` | 适合北欧风品牌 |

## 7. 机检（真实输出）

```bash
python scripts/prompt_lint.py --text "（5.1 主提示词全文）" --platform seedream --purpose poster
```

```
=== 提示词机检 ===
平台：seedream ｜ 用途：poster ｜ 长度：210 字
得分：100 / 100   [P0×0 P1×0 P2×0]   判定：可直接交付
```

30 项人工自检里，D3 文字策略 = 零文字 + 留白，D1/D2 留白比例与颜色已写，E3 基础反向已给 → 通过。

## 8. 交付说明

- **推荐平台**：Seedream 5.0 Pro（中文原生、版式听话）
- **已知风险**：下区色块与上区过渡可能过硬 → 若出现，光段补一句 `上下区之间柔和过渡`
- **下一步**：出图后在留白区叠标题；标题建议 ≤6 字，深墨绿底配暖白字
- **变体优先试 V1**（暗调在咖啡品类上点击率通常更高）

---

## 复盘：这条需求最容易错的三处

1. **不给留白比例** → 模型填满画面，海报变插图（D14）
2. **直接让模型写"秋日限定"** → 中文乱码，返工（D30）
3. **只写"柔和的暖光"** → 平光，出图廉价（D17）
