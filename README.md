# image-prompt-smith

把一句话描述，锻造成能直接粘贴出图的提示词。

> **一句话进，一条提示词出。** 不够就问一轮，够了就直接给；要什么图型就给什么规格；给一张图，就还原出能再生成它的词。

一个给 AI 绘图用的提示词工程 Skill（Claude Code / WorkBuddy / 任何支持 `SKILL.md` 的 Agent 宿主）。仓库根即 Skill 根，clone 下来可直接安装；另附单文件版，供豆包、ChatGPT、Claude、Coze 当人设用。

---

## 它解决什么

大部分人写提示词的毛病不在词汇量，在这四件事：

| 毛病 | 后果 | 本项目的做法 |
|---|---|---|
| 用形容词代替参数 | "高级感""唯美""氛围感" → 模型随机发挥 | 换成机位、焦段、光位、光比、色温、材质数值 |
| 结构漏格 | 没写光就出平光，没写负空间就手臂粘躯干 | **11 格画面语法**，逐格检查 |
| 图型认错 | 要立绘给三视图，要头像给全身 | **36 种图型**分三族，先判族再选型 |
| 出图不对就加词 | 越改越糟，最后放弃 | **48 条症状码**，定位是哪一格写错了 |

## 30 秒上手

**输入**

```
画个二十岁的男生，穿白衬衫，看起来很温柔，用来做小说封面
```

**输出**

```
以圆形为主的写实风格角色，7 头身。二十岁上下的东亚男生，白棉质衬衫袖口卷到小臂中段、
外松一颗扣，深灰长裤；圆下颌、眼尾略下垂，短发有几缕散在额前，左手腕一块旧表。
他靠在窗边低头翻书，另一只手插在裤袋里。左侧窗光 45° 柔光入射，光比 1:3，5200K，
墙面有柔和投影；85mm f/2.8 半身，浅景深，主体偏右，左侧留出浅米色负空间；
奶白与浅灰为主，低饱和低对比；手臂与躯干之间留出可见空隙。2:3，画面中不出现任何文字与水印。
```

判断过程：小说封面 → 2:3 与留白；"温柔" → 圆主形 + 柔光 + 低饱和；"白衬衫" → 补材质与袖口状态；其余走默认，**不问**。

## 三条主路径

### 1｜描述 → 词（默认）

```
① 拆句 → ② 判密度 → ③ 认图型 / 提问 → ④ 拼装 → ⑤ 一核多壳交付
```

**判密度**：描述够就直接出，不问；偏薄问 2–3 项；太薄问 4 项（场景 / 气质 / 脸型 / 用途）——一轮问完、每项带默认、回数字即可、不答照出。

**一核多壳**：默认给「中文核心版 + 英文版 + 3 行适配说明」，覆盖 90% 模型——中文版给即梦 / 豆包 / Seedream / 万相 / 可灵 / Nano Banana，英文版给 MJ / Flux / SD / GPT Image。

### 2｜图 → 词（反推）

给一张图，还原出能再生成相似图的提示词。三把锁：

- **同人归并**：1 个角色 + N 个状态，不是 N 个人
- **唯一代号**：开头定名，全篇不改
- **逐项 1:1 绑画面**：每条描述都要能在图上指到位置，指不到就删

先修图再反推（裁到主体、去水印），分「可见 / 可推 / 不可知」三档标注，并写缺口预警。**交付时必须说明：反推得到的是"能再生成相似图的词"，不是原始 prompt。**

### 3｜组合图型（"三视图 + 发型图"这种）

先判**能不能合图**，三条全满足才能合一张：同姿态 + 角度集合能对齐 + 同光。

不满足就拆成 N 条，每条独立可粘，**锚点（年龄 / 发色 / 瞳色 / 脸型 / 主色）每条完整复制**——分开生成时模型看不到另一条，写"同上"等于没写。

## 36 种图型｜先判族，再选型

图型不是清单，是**三族**，规则互相冲突。判错族，后面全错。

| 族 | 给谁看 | 光 | 姿态 | 背景 |
|---|---|---|---|---|
| **A 展示族**（11 种） | 人（甲方 / 读者） | 可戏剧 | 可自由 | 可有场景 |
| **B 资产族**（23 种） | 下游（建模 / 绑定 / 打光 / 动画） | **必须平** | **必须中性统一** | **必须纯色** |
| C 版式族 | 排版与投放 | 按版式 | 按版式 | 按版式 |

**A 展示族**：头像、半身写真、全身立绘、Q 版、KV / 主视觉、壁纸、阵容图、档案海报、场景概念、社媒封面、书籍封面。

**B 资产族**：三视图、四 / 五视图、正交建模图、表情集、表情 BS、姿态集、动态姿势图、动态多视图、发型图、发型分层图、眉眼图、脸部特写、局部放大、口型图、服装正侧背、换装图、装备拆分、配饰图、材质分区、配色图、灯光参考、骨骼视图、资产套装、**物体四视图**（车 / 衣 / 枪 / 手办）、**真人定妆四视图**。

B 族四条铁律：

1. **一格一信息**——造型与光不能同格，材质与配色不能同格
2. **角度用标准集**——0° / 45° / 90° / 135° / 180°，不写"侧一点"
3. **同组共享比例尺**——八条地标线贯通，脚底对齐同一水平线
4. **光只有两个合法值**——`flat even lighting` 或 `single directional light`

### 三个反直觉的点

- **灯光参考图是唯一允许"光不一致"的多格图**：它要求每格光位不同、其余全同。四格都写平光，就成了一张图重复四次。
- **不要靠 AI 画引线**：放大图的引线一定歪、编号一定乱码。改用上下分区（55% / 45% / 4% 分隔带）；装备拆分改沿中轴等距分离。
- **AI 给不了 rig / 拓扑 / 中间态**：骨骼视图只写关节球位置、脊柱曲线、骨段比例；写"权重 / 控制器 / armature"必出怪机械。表情 BS 只能出「中性 + 极值」两行，写 30% / 60% / 100% 会得到三个不同的人。

```bash

# Claude Code 换成 ~/.claude/skills/image-prompt-smith
```

**作为单文件人设**（豆包 / ChatGPT / Claude / Coze / Dify）

把 `dist/单文件版-通用人设提示词.md` 全文粘进「人设与回复逻辑」或系统提示词。约 9 千字，覆盖主路径；深度细节可按需上传知识库（部位 / 特效 / 3D 动漫 / 建模 / 图型）。

## 机检脚本

零依赖，单文件 Python，不需要装任何包。

```bash
# 自测
python scripts/prompt_lint.py --self-test

# 检一条提示词
python scripts/prompt_lint.py --platform seedream --purpose poster \
  --text "3:4 竖版秋季咖啡活动海报……"

# 从文件读，输出 JSON
python scripts/prompt_lint.py --file prompt.txt --platform mj --json
```

输出 **P0（必改）/ P1（建议改）/ P2（可选）** 与 0–100 分，共 23 类检查：

- 结构缺格、画幅未量化、语义冲突、平台语法误用
- 画质词堆砌、动作过量、空词、文字期望不匹配
- 多格未封顶 / 未排标注层、参考图未分工、数量未封顶
- 通用美颜套话、第三方专名、3D 动漫未点名路线、3D 混写实皮肤
- 特效多层未分主次、粒子词堆砌、动态模糊未保主体
- 建模向：缺正交 / 缺 A-Pose / 缺地标线 / 缺中性表情
- 图型专属：灯光参考写了统一光、材质分区混入材质参数、骨骼视图写 rig、换装图未锁变量
- 低模：未分面数（P2）、混入高模细节（P1）
- 3D 生成：缺四肢分离（P1）、未排除悬空件（P2）；`--purpose model3d` 豁免光段/镜头/画幅
- 服装：叠穿 ≥3 层（P1）、配饰 ≥5 件（P1）、服饰特效无附着点（P2）
- 场景：人物/玄幻题材未分层（P2）
- 玄幻：可数实体未封顶（P2）、头顶光环与身后轮盘同时肯定（P1）、光环带辐条（P2）
- 服装锚点：缺分层（P2）、配色超三色（P2）、多视图未锁同一套服装（P2）
- 题材：跨族混搭未声明主题材（P2）
- 题材：跨族混搭未声明主题材（P2）

**两条保护机制**（避免"误报逼人改设计"）：

- `--length short|standard|long`：长度分三档，轻微超出只报 P2；
- `--purpose turnaround|character_sheet|profile_page`：展示型设定稿**不套建模五项**（正交/A-Pose/地标线/中性表情）；
- `--energy restrained|epic`：战斗 KV 允许多一层特效，阈值放宽但要求分层写清。

已知边界：脚本是启发式检查，命中后仍需人工复核。它不能判断"这张图好不好看"，只能判断"这条词有没有结构性错误"。

## 已知边界

- **不管"好不好看"**。它保证结构和规格正确，审美仍需人判断。
- **不做图**。需要出图时调用宿主的图片生成能力。
- **AI 出的不是资产**。三视图、骨骼图、材质分区图都是**给建模师看的工程参考**，不是可绑定模型；真正能绑的资产必须人工重拓扑。
- **反推不是还原**。相似度 80–95%，还原不出模型、种子与后期。
- **机检是启发式**。P2 可以放过，P0 必须看。
