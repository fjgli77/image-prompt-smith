# 12 多格图与参考图

> 来源：`zenstory-ai` 的三视图规范（用途先行 / 标签不入图 / 光线按对比项选）、`libtv-video-agent` 的参考图铁律（污染 / 分工 / 正面穷举 / 数量 / in-scene 锚定）。
> 两件事决定多格图成败：**格数有没有封顶**、**参考图有没有分工**。

---

## 一、多格图五要素（缺一必崩）

```
① 共几格   ② 怎么排   ③ 是否等高/等宽   ④ 每格职责   ⑤ 仅此 N 格
```

**声明模板**

```
画面为〔N〕格并排：横向 〔N〕 等分 / 网格 〔行〕×〔列〕，每格等宽等高，格间距一致。
每格依次为：〔格1职责〕、〔格2职责〕…。
仅此 〔N〕 格，不增加任何额外画格、分镜或重复视图。
```

**为什么"仅此 N 格"不能省**：只写"共 4 格"是**下限**不是**上限**，模型会自己补第 5 格、或在角落加一个小图。多格图的头号崩法就是"多出来一格"。

---

## 二、标注层：格号、箭头、标签一律不许画进图

**这是最容易被忽略、后果最严重的一条。**

图上的"① ② ③""正面/侧面/背面""← →"、尺寸线、图注，一旦被画进图：

- 后续用它当参考图时，**这些字会被继承进成品**
- 事后再写"不要文字"清不掉，只能裁切、涂抹或换图

**必写段**：

```
画面内无视图标签、无格号数字、无引线箭头、无尺寸标注、无图注、无可读文字。
```

**中文/英文双写更稳**：

```
no view labels, no panel numbers, no arrows, no measurement marks, no captions, no readable text
```

> 同理：海报/封面/包装上的字，如果这张图之后要当参考图用，**一律走留白后期**，不要赌图内文字。

---

## 三、参考图污染矩阵

**铁律：参考图里有什么，输出大概率就有什么。**
所以排查"反复出现的穿帮"，第一步永远是**翻参考图**，不是改提示词。

| 参考图类型 | 能当参考吗 | 原因 |
|---|---|---|
| 纯色底 / 白底设定图 | ✅ 最佳 | 无环境、无文字、无干扰元素 |
| 正交转面图 / 三视图 | ✅ 最佳 | 结构信息完整，无透视 |
| 单格故事板线稿 | ✅ | 但要先去掉格号与箭头 |
| 主视觉 KV / 氛围图 | ❌ | 带环境光与情绪，会把后续十张图都染成同一氛围 |
| 角色档案海报 / 排版图 | ❌ | 带版式与文字，会被照抄 |
| 多姿态拼图 / 多个体合集 | ❌ | 暗示"这里有很多个"，诱导分身与多主体 |
| 带文字的截图 / 界面图 | ❌ | 文字必被继承 |
| 低分辨率 / 压缩图 | ⚠️ | 会把糊与噪点带进高质量输出 |

**判定口诀**：这张图里，除了我想要的，**还有什么是我不想要但会被照抄的？** 有 → 先做一张干净的。

---

## 四、参考图职责声明（三段式）

一张参考图往往"既要又要"：要它的脸，不要它的衣服；要它的场景，不要它的人。**必须显式拆开**，否则模型平均分配。

### 三段式写法

```
① 只取什么：「〔图X〕只用来确定〔脸型、五官、发型、发色〕」
② 完全不取什么：「衣服、姿态、背景完全不按这张图」
③ 目标怎么写：「本次服装为〔正面详细描述：浅色棉质连衣裙、圆领、无拉链、无条纹〕，
   画面中人物不穿〔原款标志性特征：校服 / 拉链外套 / 条纹〕」
```

**为什么第 ③ 段要写"新款特征"而不是只说"换衣服"**：只给"不要旧的"，模型会给一个模糊的中间态；给出"新的具体长什么样"，才有落点。

### 常见四类分工

| 场景 | 怎么分工 |
|---|---|
| 换装 | 图只取脸/发型；衣服全新描述；负面排原款特征 |
| 换场景 | 图只取人与服装；场景全新描述；负面排原背景元素 |
| 换姿态 | 图只取外观；姿态用动作句写；负面排原姿态 |
| 换画风 | 图只取构图与结构；风格由风格块承担；显式声明"转成〔风格〕，不保留原色彩/原质感" |

**彩图转线稿的写法**（最常翻车）：

```
所挂彩色参考图只用来取构图与布局，请转成纯黑白线稿，绝对不保留其颜色；
全部格子一律纯黑白，无平涂、无水彩、无彩色，特别注意第一格与最后一格。
```

## 五、in-scene 锚定：道具别用"单品图"

| 做法 | 模型的理解 | 结果 |
|---|---|---|
| 喂一张道具单品图 | "这是个素材，我来摆一下 / 重新设计" | 走样、变普通款、加奇怪装饰 |
| 喂一张"道具已摆在场景里"的合成图 | "照抄这个既成画面" | 一致 |

**做法**：先用图片模型把道具合成进目标场景，拿**合成图**当参考，提示词写"和图中〔位置〕上那个〔物体〕一模一样，位置、样式、大小都照图不变，不要重新设计"。

**同理适用于**：产品 + 包装 + 模特同框、菜品 + 器皿、房间 + 家具布局。

---

## 六、数量铁律（防多主体 / 分身）

可数实体必须**写死总数 + 逐个点名 + 封顶**：

```
画面中的〔主体〕总数严格等于 〔N〕：〔A 的特征〕、〔B 的特征〕。
不允许出现第 〔N+1〕 个，不允许分身，不允许背景里多出同类。
```

**配套两条**

- 参考图要用"**恰好 N 个**"的干净图，**不要用多姿态拼图**
- 反向/禁令里不写"不要 X"（会召唤），改为"画面里有且只有 …"（见 07 正面穷举）

---

## 七、按图式选模型

多格图不是所有模型都能做：有的会给你**单人图**，有的会给你**一张拼贴**。

| 图式 | 首选 | 次选 | 说明 |
|---|---|---|---|
| 3–9 格多视图 / 故事板 | **Nano Banana Pro** | Seedream 5.0 Pro | 一次出多主体的能力目前最稳 |
| 分区排版 + 中文文字（档案页/信息图） | **GPT Image 2** | Seedream 5.0 Pro | 排版服从性与中文字准 |
| 多图参考下的人物一致性 | **Nano Banana Pro** | Seedream 5 Pro + 固定 seed | 多参考槽位语义成熟 |
| 单图高质量写实 | Seedream 5 Pro / MJ `--style raw` | Flux | 不必用多格模型 |
| 精确构图复刻 | SDXL + ControlNet | Flux + 参考图 | 多格图别用 SD 硬拼 |

**给不支持多主体的模型写"共 4 格"，它照样给你单人图或拼贴。** 图式选错模型，提示词写得再对也白费。

## 八、多格图 QC 清单（出图后必过）

- [ ] 格数是否正确，有没有多出第 N+1 格
- [ ] 每格职责是否落实（该是侧面的没变成正面）
- [ ] 同一造型在各格是否一致（配饰有没有换边、衣服有没有变）
- [ ] 有没有混入格号、箭头、标签、图注
- [ ] 是否等高、等宽、间距一致
- [ ] 背景是否统一（不该出现某格带环境）
- [ ] 每格分辨率是否够（小格最容易糊脸与裁头）

**小格必糊的对策**（三条一起上）：

1. 出图分辨率提到 2K 以上（4K 更稳）
2. 显式写年龄与头身比：`成年人体比例约 6.5–7 头身`
3. 禁项写死：`禁幼态、禁娃娃脸、禁 Q 版、禁大头娃娃、头部完整在画面内不裁切`

---

## 九、重绘/清理版必查

用图生图做"去标注 / 去文字 / 转线稿"的清理版，**不是无损操作，是重画一遍**：

```
清理版 = 重绘 → 可能顺手加戏（多一只动物、多一个人、凭空加的道具）
```

**纪律**：清理版出来后**逐格看一遍**，确认没有多出来的元素，再拿它当参考图。否则下游会照抄这个加戏，而且你会以为是提示词的问题。

---

## 十、多格图六种常见崩法

| 现象 | 根因 | 改法 |
|---|---|---|
| 多出一格 / 角落有小图 | 只写"共 N 格"没封顶 | 加"仅此 N 格，不增加任何额外画格" |
| 各格造型不一致 | 造型写在每格分别描述 | 造型写进**共用造型句**，每格只写视图差异 |
| 侧面/背面认不出 | 认人特征只在正脸可见 | 每个视图指定一个**该视图可见**的特征 |
| 图里出现"①②③" | 标注层没排除 | 写"无格号、无箭头、无图注" |
| 某格带环境背景 | 背景只在开头写一次 | 每格都写或统一写"统一纯色背景" |
| 小格脸糊 / 头被裁 | 分辨率不足 + 未禁幼态 | 提分辨率 + 写年龄头身比 + 禁裁头 |
