# 01 意图解析与缺省推断

## 一、意图分类（先分类，再动手）

| 类 | 用户原话特征 | 你要做的第一件事 |
|---|---|---|
| **造画面** | "画个…""来一张…""有…的图" | 补场景与光，选风格族 |
| **给用途** | "做海报""要封面""电商主图" | **先定版式**，再填画面 |
| **改现成** | "把这条改一下""太花了""再干净点" | 定位是哪一格的问题（走 08 诊断） |
| **换平台** | "搬到即梦怎么写" | 走 03 方言矩阵重写 |
| **要思路** | "这种图怎么描述" | 先给方法论 3 行，再给示例词 |
| **批量** | "一篇文章配 5 张" | 先建锚点表（风格/色/主体），再逐张 |

分类错了全盘错：**"给用途"的需求先写画面必翻车**——因为没有留白区，海报没法用。

---

## 二、只问两项（其余全推断）

### 必问项

**① 投哪个模型？**

```
不知道 / 没说 → 出两份：中文自然语言版（Seedream·即梦·豆包）+ MJ 参数版
说了 MJ / Midjourney → 英文短句 + --ar + --style raw
说了 SD / ComfyUI / 本地 → 标签串 + 权重 + 独立反向
说了 即梦 / 豆包 / Seedream / 即梦4.0/5.0 → 中文自然语言，版式优先
说了 Nano Banana / Gemini / 香蕉 → 结构化长指令，英文更准
说了 GPT Image / DALL·E → 自然语言，正向禁令
说了 通义万相 → 中文，可用负向提示词
```

**② 图干什么用？**

用途决定三件事：**画幅、留白、文字策略**。见下方映射表。

### 可问可不问（有则用，无则推）

画面主体是什么、什么风格、有没有字、要不要人、什么色。**这几项用户通常已经在描述里给了，没给就按推断表补。**

## 三、缺省推断表（照表补，补完标注）

| 项 | 触发条件 | 缺省值 | 理由 |
|---|---|---|---|
| **画幅** | 没写比例 | 社媒竖图 `3:4`；公众号头图 `2.35:1`；PPT `16:9`；电商主图 `1:1`；海报 `3:4` 或 `2:3`；壁纸 `9:16`；横幅 `16:9` | 平台原生比例，避免二次裁切 |
| **风格族** | 没写风格 | 有真人/产品 → **写实摄影**；有人物但抽象 → **电影感**；纯概念 → **插画/3D 二选一按行业猜** | 写实是最不会翻车的默认 |
| **光** | 没写光 | 室内 → `柔和窗光侧 45°`；户外白天 → `黄金时刻侧逆光`；夜景 → `实用光源 + 环境光`；产品 → `大面积柔光箱 + 单侧轮廓光` | 光位缺失 = 平光 = 廉价感 |
| **机位** | 没写机位 | 人像 `85mm 中近景平视`；产品 `50–85mm 略俯 15°`；空间 `24mm 平视`；食物 `50mm 45° 俯拍` | 行业默认视角 |
| **色** | 没写色调 | 商业图 `低饱和 + 单一强调色`；生活方式 `暖中性`；科技 `冷青 + 高对比` | 低饱和最耐看 |
| **文字** | 没提文字 | **不写文字**，并在反向/禁令里排除文字 | 除少数模型外文字不可控 |
| **人** | 画面需要人但没描述 | 只给"背影/手部/局部"或直接省略人，用环境叙事 | 人脸是最容易崩的元素 |
| **禁区** | 无 | 加通用反向：变形肢体、多余手指、水印、模糊、低分辨率 | 兜底 |

**推断标注格式**（写在交付物里，一行）：

```
推断：画幅 3:4（社媒竖图）｜风格 写实摄影｜光 黄金时刻侧逆光｜85mm 中近景｜低饱和暖调
```

用户看到这一行就知道你补了什么，改起来一秒定位。

## 四、用途 → 版式映射

| 用途 | 画幅 | 必须留白 | 主体位置 | 文字策略 |
|---|---|---|---|---|
| 公众号头图 | 2.35:1 | 左侧或右侧 40% | 偏一侧 | 后期叠标题，图内不放字 |
| 小红书封面 | 3:4 | 上部 25% | 中下 | 可赌大标题（Seedream/GPT Image） |
| 抖音/视频封面 | 9:16 | 上下各 15% | 中心偏上 | 大字必须后期 |
| 电商主图 | 1:1 | 四周 15% 纯色 | 正中 | 不放字（平台禁止） |
| 详情页 banner | 3:1 或 16:9 | 一侧 35% | 另一侧 | 后期 |
| 活动海报 | 3:4 / 2:3 | 顶部 30% + 底部 12% | 中区 | 主标题可赌，副文案后期 |
| 信息图 | 4:5 / 1:1 | 页边 8% | 网格分区 | 内容型模型可赌，需引号 |
| PPT 配图 | 16:9 | 无（靠版式） | 中心或三分点 | 不放字 |
| 头像 | 1:1 | 无 | 正中偏上 | 不放字 |
| 壁纸 | 9:16 / 16:9 | 无 | 中心留空给图标 | 不放字 |
| 游戏/动画资产 | 1:1 | 无 | 正交居中 | 不放字 |
| 文章插图 | 16:9 / 4:3 | 无 | 叙事性 | 不放字 |
| Logo / 图标 | 1:1 | 无 | 正中 | **不要**赌文字，走"图形 + 后期字" |
| 电商场景图 | 1:1 / 4:5 | 无 | 产品占 45–65% | 不放字 |

**"留白"必须写进提示词**，否则模型会把画面填满：

```
顶部 30% 保持纯净留白、无任何元素，用于放置标题文字
top 30% clean negative space reserved for headline, no elements
```

## 五、判定"要不要人"

| 信号 | 处理 |
|---|---|
| 明确说"一个女孩/模特/手" | 给锚点：年龄段 + 发型 + 服装 + 姿态，**不给正脸建议**（除非要人像） |
| 说"生活场景""办公室里" | 人是背景元素，写"虚焦人物剪影"比写具体人稳 |
| 说"产品图""海报" | 默认无人；需要人时写"手部特写持握" |
| 说"人像/写真/证件照" | 转「人物模式」（`references/character/body-parts.md` 等） |

## 六、需求歧义时怎么办

| 歧义 | 处理 |
|---|---|
| "画个 3D" | 默认 **3D 写实渲染**，一句话说明可切卡通 3D |
| "动漫风" | 默认 **日系赛璐璐**，说明可切厚涂/韩漫 |
| "高级感" | 默认 **低饱和 + 硬光侧逆 + 大留白**（商业摄影语言） |
| "国风" | 默认 **工笔重彩 + 宣纸肌理**，可切水墨/敦煌/新中式 |
| "赛博朋克" | 默认 **霓虹青紫 + 湿地面反射 + 夜景** |
| 前后矛盾（"极简但元素很多"） | 按**主诉求**（第一个形容词）执行，另一条降为局部 |

## 七、反例（这些解析方式会让你返工）

- ❌ 用户说"做个海报"，你直接出画面词 → 没留白，交付即废
- ❌ 用户说"随便来一张"，你追问五轮 → 直接按"社媒配图 3:4 写实摄影"出，末尾问要不要换
- ❌ 用户说"要高级"，你加 `masterpiece, best quality, 8k` → 加光位与焦段
- ❌ 用户说"参考这张图"（给了图），你只在文字里写"like this" → 要么用图生图，要么把参考图拆成具体语言特征
- ❌ 用途是电商主图，你写了场景背景 → 平台要求纯白/纯色底
