# 图 → 视频：把出好的图动起来

> 本 skill 只负责出图。**但当用户说"让它动 / 做个 5 秒 / 分镜能连贯吗"时，图之后的那一步要接得住。**
> 这里只写"从图到视频"的接缝，不写完整影视流程（那是另一套）。

---

## 一、运动五要素（写全才稳）

普通文生图讲"六句"，图生视频讲**五要素**：

| 要素 | 写什么 | 不写会怎样 |
|---|---|---|
| **主体** | 谁，长什么样（可简写，图里已有） | 可省，图已定 |
| **场景** | 在哪，环境怎么变 | 背景会自己乱动 |
| **镜头语言** | 推/拉/摇/移/跟，**一个** | 全自动，随机运镜 |
| **光影** | 光是否变、从哪来 | 光会跳 |
| **运动方式** | 主体怎么动，**一次一个动作** | 又走又转又抬手，必崩 |

**核心纪律**：**一条视频只写一个动作 + 一个运镜。** 动作幅度与形变正相关——手抬得越高，手指越容易糊。

---

## 二、三种输入方式，写法不同

| 方式 | 怎么给 | 提示词该写什么 | 不该写什么 |
|---|---|---|---|
| **首帧（图生视频 I2V）** | 一张图 | 只写"要从这张图**变成**什么"：动作 + 运镜 + 时长 | 别再描述图里已有的东西 |
| **首尾帧（FL2V）** | 两张图 | 写"从 A 到 B 中间发生了什么" | 别写结尾画面（尾帧已给） |
| **纯文字（T2V）** | 无图 | 五要素全写 | 别指望精细设计 |

**首帧方式的铁律**：**图已经携带了全部视觉信息，提示词只写"变化"。**
把整段画面重描述一遍，等于让模型重画一张，原图白给。

---

## 三、四个可粘骨架

### 3.1 微动（最稳，失败率最低）

```
主体保持静止，仅衣摆与发丝随风轻摆；镜头固定，时长 5 秒。
```

### 3.2 单动作

```
人物缓缓抬头，视线从低处移到镜头；镜头固定，浅景深，时长 5 秒。
其它一切不变：构图、光位、服装、背景。
```

### 3.3 单运镜

```
镜头缓慢推近至半身，人物保持站立不动；光位不变，时长 5 秒。
```

### 3.4 首尾帧过渡

```
从首帧的姿态出发，人物转身向右并迈出一步，到达尾帧姿态；
镜头轻微跟随，全程一个连续镜头，不切不跳。
```

## 四、崩坏点（六条，按出现频率排）

| # | 崩坏 | 根因 | 写法 |
|---|---|---|---|
| 1 | 脸变了 | 视频模型重绘强度大 | 写"面部结构保持不变"，或改用首尾帧锁脸 |
| 2 | 手糊 / 多指 | 动作幅度过大 | 一次一个动作；手部动作改"镜头推近"代替 |
| 3 | 背景乱飘 | 没写背景静止 | 写"背景保持静止，只有主体运动" |
| 4 | 服装换款 | 没锁服装 | 把服装锚点段整段复制进提示词 |
| 5 | 运镜乱跳 | 写了两个以上运镜 | 只留一个：推 **或** 拉 **或** 摇 |
| 6 | 时长不够 / 太长 | 没写秒数，或动作塞太多 | 明确"5 秒"；一个动作配 3–5 秒 |

**反向必备**：`形变、脸部扭曲、手指错误、背景变形、镜头抖动、瞬移、多个人物`

## 五、与分镜的关系（做系列时）

```
分镜表（文本）→ 出图（本 skill）→ 图生视频（本文）→ 剪辑配音
```

**接缝处的三条规矩**：

1. **同一镜头只出一张主图**，视频从这张长出来；不要为视频重出一张"更动态"的图——那会变人。
2. **相邻镜头的运动方向要同轴**：上一镜向右推，下一镜别向左拉，观众会晕。
3. **运动幅度按镜头功能分配**：交代环境用微动，情绪用单动作，高潮才给运镜。

---

## 六、和本 skill 的边界

| 用户说 | 走哪 |
|---|---|
| "画一张 / 出图 / 立绘 / 三视图" | 本 skill 主路径 |
| "让它动 / 5 秒 / 首尾帧" | 本文 |
| "分镜脚本 / 多镜头连贯 / 配音剪辑" | 不在本 skill 范围，交短剧/视频流程 |

**别越界**：本 skill 不产出分镜时序表与音频指令——那是视频工程，硬塞进来会把生图这一步也搞乱。
