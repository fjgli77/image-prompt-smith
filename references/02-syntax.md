# 02 十一格画面语法

> 十一格是**检查清单**，不是拼装顺序。真正的语序见每格末尾的"位置"说明。
> 一格不填不等于漏 —— 但**②③④⑤⑥⑦** 六个核心格必须有对应信息，否则出图必漂。

```
① 交付形态  ② 主体  ③ 动作/状态  ④ 场景  ⑤ 风格族  ⑥ 光
⑦ 镜头/机位  ⑧ 构图/版式  ⑨ 色彩/材质  ⑩ 画面文字  ⑪ 画幅与参数
```

---

## ① 交付形态（Deliverable）

**作用**：先告诉模型"这是什么东西"，它会切换成对应的成图习惯。信息图 vs 照片 vs 海报，模型内部走的是不同分布。

**写法**：一个名词短语，放最前。

| 类型 | 可用短语 |
|---|---|
| 商业摄影 | `商业产品摄影`、`电商主图`、`lookbook 实拍` |
| 广告 | `广告主视觉`、`品牌 KV`、`户外广告牌 mockup` |
| 编辑类 | `杂志跨页`、`editorial 大片`、`新闻纪实照片` |
| 平面设计 | `海报设计`、`活动海报`、`社媒封面`、`banner` |
| 信息型 | `信息图`、`信息图表`、`步骤图`、`对比图` |
| 插画 | `单幅插画`、`绘本内页`、`editorial illustration` |
| 3D/CG | `3D 渲染图`、`产品渲染`、`概念设计图` |
| 资产 | `角色资产图`、`场景概念图`、`道具设定图`、`UI 界面稿` |
| 影像感 | `电影剧照`、`电影感画面`、`纪录片截图` |

**常见错误**：省略这一格 → 模型默认"一张好看的图"，海报就没了版面，信息图就没了网格。

**位置**：第 1 位。

---

## ② 主体（Subject）

**作用**：全图权重最高的格。**必须在前 20 字内出现。**

**写法公式**：

```
[数量/年龄/性别/物种] + [形态特征] + [材质或服饰] + [可识别标识]
```

| 层级 | 反例 | 正例 |
|---|---|---|
| 数量 | "一些杯子" | "三只" |
| 特征 | "好看的女孩" | "二十七八岁东亚女性，短齐耳黑发，瘦削下颌" |
| 材质 | "一个瓶子" | "磨砂琥珀玻璃瓶，铝制泵头" |
| 标识 | "一只猫" | "橘白相间短毛猫，左耳缺一角" |

**主体类型与要点**：

| 主体 | 必须给的 | 常被漏掉的 |
|---|---|---|
| 产品 | 品类 + 材质 + 颜色 + 状态（满/空/打开） | 容量感、标签位置 |
| 食物 | 菜品名 + 温度/状态 + 器皿 | 汁水、蒸汽、断口 |
| 建筑空间 | 类型 + 材料 + 新旧 | 尺度参照物（人/家具） |
| 动物 | 品种 + 姿态 + 毛色 | 眼神方向 |
| 人（非人像） | 年龄区间 + 服装 + 姿态 | 手在做什么 |
| 抽象概念 | **必须实体化**："焦虑"→"缠绕在头部的黑色丝线" | 缺实体化就出不了图 |

**常见错误**：
- 主体太抽象（"科技感"）→ 必须落到具体物体
- 主体太多（"城市、人群、车、灯、广告牌、鸽子"）→ 主次不分，改成一个主 + 两个陪衬
- 主体带主观评价（"漂亮""精致"）→ 换成可测量的形体词

**位置**：第 2 位（自然语言）；标签模型放最前段。

---

## ③ 动作 / 状态（Action & State）

**作用**：决定画面"正在发生什么"。**一张图只讲一个动作。**

**写法**：动词 + 宾语 + 副词性身体细节

```
倒（咖啡）→ 咖啡液从壶嘴落入杯中，液面起细密气泡
走（路）→ 侧身迈步，风衣下摆被风掀起
看（窗外）→ 侧脸朝右，视线越过窗框
```

**状态词（静物必备）**：`刚开封`、`结了水珠`、`微微融化`、`冒着热气`、`落了一层薄灰`、`磨损边角`

**动词预算**：

| 动词数 | 结果 |
|---|---|
| 1 | ✅ 稳 |
| 2 | ⚠️ 可接受，需明确主次（"主体在…，背景有人…"） |
| ≥3 | ❌ 必抢戏，改成分图或只保留一个 |

**常见错误**：用抽象情绪代替动作（"表现孤独"）→ 改成可拍的动作（"独自坐在空荡车厢里，手扶行李箱"）。

**位置**：紧接主体。

---

## ④ 场景 / 环境（Setting）

**作用**：给主体一个可信的空间与世界观。

**四件套**：

```
地点 + 时间/天气 + 前中后景元素 + 空间尺度线索
```

| 层级 | 例 |
|---|---|
| 地点 | 老式公寓厨房 / 雨后高架桥下 / 敦煌戈壁 |
| 时间天气 | 清晨六点 / 阴天小雨 / 沙尘将起 |
| 前中后景 | 前景水洼倒影 / 中景主体 / 远景楼群虚化 |
| 尺度线索 | 地砖缝、栏杆间距、人物身高比例 |

**背景控制词**（避免背景抢戏）：

- `背景简洁` `背景虚化` `纯色背景` `背景低对比`
- `无杂物` `single subject, uncluttered background`

**常见错误**：
- 背景写太长（超过主体字数）→ 主体会被稀释
- 场景与用途冲突（电商主图要求纯底，却写了街景）→ 回到 01 的用途表
- 缺尺度线索 → 建筑/产品大小不可判

**位置**：第 4 位。

---

## ⑤ 风格族（Style）

**作用**：定调性。**这是最容易写错的一格**，因为它不是一个词，是三层。

```
风格族（写实度）× 介质（怎么画）× 情绪（什么味道）
```

三层各选一个，见 `05-styles.md`。这里只给铁律：

| 铁律 | 说明 |
|---|---|
| 风格词 ≤3 个 | 多了互相抵消 |
| 必须同族 | 写实 + 动漫 = 崩，不是"混搭" |
| 混合要指定主风格 | 主风格定底层规则，次风格只影响局部元素（如"写实摄影为主，局部霓虹赛博配色"） |
| 用专有名词比形容词准 | `Kodak Portra 400` > `胶片感`；`Octane 渲染` > `3D 感` |

**风格形容词分级**（越往下越不可靠）：

| 级 | 例子 | 可靠性 |
|---|---|---|
| A 专有名词 | Kodak Portra 400 / Studio Ghibli / Bauhaus / Rembrandt lighting / Octane | 高 |
| B 流派术语 | editorial photography / flat design / risograph / cel shading | 高 |
| C 通用形容词 | minimalist / cinematic / vintage | 中 |
| D 主观评价 | 高级 / 大气 / 有质感 / 唯美 | **低，等于没说** |

**位置**：第 5 位。SD 标签模型放中段（主体标签之后）。

---

## ⑥ 光（Lighting）

**作用**：**高级感的最大杠杆**。99% 的"图很平"都是这一格没写。

**六要素**：

```
光位 + 光质 + 光比 + 色温 + 时间 + 特殊效果
```

| 要素 | 词表 |
|---|---|
| 光位 | 顺光 / 45° 侧光 / 90° 侧光 / 侧逆光 / 正逆光 / 顶光 / 底光 / 伦勃朗光 / 蝴蝶光 / 分割光 / 环形光 |
| 光质 | 硬光（小光源、清晰影） / 柔光（大面积漫射） / 混合（主硬补柔） |
| 光比 | 1:2 柔和 / 1:4 立体 / 1:8 戏剧 / 1:16 强反差 |
| 色温 | 2700K 烛光 / 3200K 钨丝暖 / 4000K 暖白 / 5600K 日光 / 6500K 阴天冷 / 9000K 蓝调 |
| 时间 | 蓝调时刻 / 黄金时刻 / 正午硬光 / 阴天柔光 / 深夜 |
| 特效 | 体积光（丁达尔） / 窗棂投影 / 水波反射 / 霓虹溢色 / 柔焦光晕 / 实用光源入画 |

**按场景直接抄**：

| 场景 | 光配方 |
|---|---|
| 产品白底 | 大面积柔光箱正上方 + 左右补光，光比 1:2，5500K，地面自然软阴影 |
| 产品暗调 | 单侧硬光 90° + 黑旗挡反光，光比 1:8，背景压到近黑 |
| 人像 | 45° 窗光 + 反光板补暗部，1:3，5600K，眼神光可见 |
| 食物 | 侧逆光 45°（透出蒸汽与汁水）+ 白卡补正面，暖 4000K |
| 室内空间 | 窗外自然光为主 + 室内实用灯点缀，冷暖对比 |
| 夜景街拍 | 霓虹 + 湿地面反射 + 单一实用光源，青紫对撞 |
| 电影感 | 单一动机光源 + 大面积暗部，光比 1:8 以上 |
| 国风 | 顶部柔光模拟天光 + 侧向补光，低对比，暖灰 |

**常见错误**：
- 只写"柔和的光"→ 缺光位，等于没写
- 同时写"逆光"和"正面光"→ 冲突（机检会抓）
- 夜景写了"明亮"→ 模型会做成白天

**位置**：第 6 位。

## ⑦ 镜头 / 机位（Camera）

**作用**：控制"从哪看、看多近、压缩多少"。细节见 `04-visual-language.md`。

**三件套**：`景别 + 机位角度 + 焦段/光圈`

| 景别 | 用途 |
|---|---|
| 大远景 | 世界观、孤独感 |
| 全景 | 主体与环境关系 |
| 中景 | 动作与交互 |
| 中近景 | 表情 + 上半身（最常用） |
| 特写 | 质感、情绪 |
| 大特写 | 材质细节（产品/食物） |

| 机位 | 效果 |
|---|---|
| 平视 | 客观、可信 |
| 略俯 15–30° | 产品/食物/桌面（最讨喜） |
| 俯拍 90° | 平铺、knolling、信息图 |
| 仰拍 | 崇高、压迫 |
| 鸟瞰 | 场景全貌 |
| 荷兰角 | 不安、动感 |

| 焦段 | 效果 |
|---|---|
| 14–24mm | 夸张透视、空间感 |
| 35mm | 纪实、带环境 |
| 50mm | 接近人眼 |
| 85mm | 人像标准、压缩背景 |
| 100mm 微距 | 纹理、水珠 |
| 135–200mm | 强压缩、背景奶油化 |

**相机语言（写实摄影必加 1–2 个）**：`f/1.8 浅景深`、`f/8 全景深`、`快门 1/1000 凝固水花`、`长曝光拖影`、`移轴`、`机顶直闪`。

**常见错误**：
- "特写"与"大场景"同时写 → 冲突
- 只有景别没有焦段 → 透视不可控
- 手机竖构图却写 85mm → 视角与画幅打架

**位置**：第 7 位。

---

## ⑧ 构图 / 版式（Composition）

**作用**：决定"东西摆哪"。**这是"设计图"与"随手图"的分水岭。**

**摄影构图词**：

```
三分法 / 中心对称 / 黄金分割 / 对角线 / 引导线 / 框架式（门框窗框）
前景遮挡 / 负空间 / 视线方向留白 / 重复韵律 / 俯视平铺
```

**版式词（海报/信息图/UI 必用）**：

| 版式 | 写法 |
|---|---|
| 上下分割 | `上下 6:4 分割，上部主视觉，下部色块承载标题` |
| 左右分割 | `左右 5:5 分割，左侧图像右侧文字区` |
| 中心放射 | `主体居中，四周元素呈放射状排布` |
| 网格 | `3 列 × 2 行等距网格，每格一个独立元素` |
| 杂志跨页 | `跨页构图，中缝留白，左下角页码区` |
| 卡片式 | `圆角卡片浮于背景，投影分离` |

**留白必须显式写**：

```
顶部 30% 纯净留白，无任何元素，用于标题
底部 12% 纯色条，用于品牌信息
主体左侧保留 1/3 负空间
```

**常见错误**：
- 只说"构图好看" → 无信息
- 要留白但没写比例 → 模型填满
- 版式写了但元素顺序没写 → 元素乱放

**位置**：第 8 位。

---

## ⑨ 色彩 / 材质（Color & Material）

**作用**：把画面从"能看"拉到"能卖"。

**色彩三件套**：`主色调 + 强调色 + 饱和度/对比`

| 写法 | 例 |
|---|---|
| 主色 | 米白 + 浅木色为主 |
| 强调色 | 单个番茄红点缀（面积 <5%） |
| 饱和/对比 | 低饱和、中对比、奶油调 |

**配色公式（直接套）**：

| 味道 | 配方 |
|---|---|
| 高级克制 | 90% 中性色（米/灰/白）+ 10% 单一饱和色 |
| 复古胶片 | 暖黄 + 青绿阴影 + 低对比 |
| 赛博 | 深蓝黑底 + 青 + 品红 + 高对比 |
| 治愈 | 奶白 + 浅杏 + 雾蓝 + 极低对比 |
| 商务 | 深蓝 + 灰 + 一点金 |
| 国风 | 宣纸米 + 墨黑 + 朱砂一点 |
| 食品 | 暖橙 + 奶油白 + 新鲜绿点缀 |

**材质词表**（产品/静物必备其一）：

```
磨砂玻璃 / 亮面不锈钢拉丝 / 哑光陶瓷 / 粗粝混凝土 / 未刨木纹
小羊皮 / 重磅棉 / 尼龙网格 / 黄铜氧化 / 亚克力透明 / 磨砂塑料
水珠凝结 / 指纹油光 / 织物绒毛感 / 石材颗粒
```

**常见错误**：写了颜色没写材质 → 出"塑料感"；写了材质没写光泽 → 出"哑火"。

**位置**：第 9 位（塞在光与镜头之间或紧接主体都可以，自然语言模型放后段更稳）。

## ⑩ 画面文字（Text in Image）

**作用**：明确"图上要不要字、什么字、在哪"。**不写就默认没有；写了就要赌模型能力。**

**三档策略**（详见 `06-text-in-image.md`）：

| 档 | 做法 | 适用 |
|---|---|---|
| **零文字** | 直接排除：`画面中不出现任何文字、字母、数字、水印` | 绝大多数图（推荐） |
| **假文字** | `书籍封面有抽象排版纹理，但不可辨认` / `pseudo-text, illegible` | 需要"有字的感觉"但不能赌 |
| **真文字** | 文案用**引号**写出 + 指定字号层级 + 禁止翻译 | Seedream 5 / GPT Image / Nano Banana Pro / Ideogram |

**真文字写法模板**：

```
画面中央放置标题 "秋日限定"，最大字号；下方副标题 "9.20 起 全国门店"，字号为标题的 1/3；
所有文字保持原文，不翻译、不改写、不添加其他字母
```

**中文注意**：即使模型支持中文，**竖排长句、书法体、复杂字形仍高频出错**，海报类建议"图上只放 6 字以内的主标题"，其余后期。

**位置**：第 10 位（放最后，模型会把它当覆盖层处理）。

## ⑪ 画幅与参数（Params）

| 项 | 写法 |
|---|---|
| 画幅 | `3:4` `1:1` `16:9` `2.35:1` `9:16`（不要写"竖版"） |
| 分辨率 | `2K` / `4K`（Seedream、Nano Banana 支持；MJ 用 `--ar` 决定比例，尺寸靠 upscale） |
| 平台参数 | MJ：`--ar 3:4 --style raw --stylize 250 --no text`；SD：CFG 4–7、steps 25–35、DPM++ 2M Karras |
| 种子 | 需要复现时固定 seed；改词对比时固定 seed 只改一处 |

**常见错误**：把平台参数写进正文（`--ar 3:4` 出现在 SD 提示词里会被当标签）。

## 三种骨架模板

### A. 叙事句（MJ / Flux / Nano Banana / GPT Image / Seedream）

```
[交付形态]，[主体]，[动作]，[场景]，[风格族]，[光：光位+光质+色温]，[镜头：景别+机位+焦段+光圈]，[构图/留白]，[色与材质]。
```

示例：

```
商业产品摄影，一只磨砂琥珀玻璃精华瓶，立在浅米色洞石台面上，瓶身凝结细密水珠，背景为干净的暖灰墙面，极简主义广告风格，左侧 45° 大面积柔光加右侧克制的轮廓光，光比 1:3，5600K 日光，85mm 镜头 f/5.6，略俯 15°，主体占画面 55%、右下保留大面积负空间，低饱和暖中性色。画面中不出现任何文字与标志。
```

### B. 标签串（SDXL / ComfyUI）

```
positive:
commercial product photography, (frosted amber glass serum bottle:1.2), on travertine slab,
water droplets on glass, warm grey seamless background, minimalist advertising,
large softbox from left 45deg, rim light, 1:3 lighting ratio, 5600K,
85mm lens, f/5.6, slightly high angle, generous negative space,
low saturation warm neutral palette, highly detailed glass refraction

negative:
text, watermark, logo, extra objects, cluttered background, plastic look,
oversaturated, deformed, blurry, lowres, jpeg artifacts
```

### C. 版式蓝图（海报 / 信息图 / 电商主图 / UI）

```
版面：3:4 竖版，上下 6:4 分割
上区（60%）：[主视觉内容 + 主体 + 光]
下区（40%）：[纯色块 + 标题区]
文字：标题 "×××" 居中，字号占下区高度 1/3
保留：下区左右各留 8% 边距；顶部 5% 安全区不放元素
材质与光：[...]
排除：任何多余文字、二维码、水印
```

### D. 角色立绘（人物模式的六句版）

人物模式不用十一格逐格写，压六句。**这一节是两套骨架的唯一映射表**，别再各写一套。

| 六句 | 来自十一格 | 写什么 |
|---|---|---|
| ① 形状与介质 | ⑤ 风格族 + 人物【形状语言】 | 主形（圆/方/三角）+ 介质 + 头身比 |
| ② 主体与服装 | ② 主体 + 特色【服装】 | 年龄/身份 + 主件 + 材质 + 主色 |
