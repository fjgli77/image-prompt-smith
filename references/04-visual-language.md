# 04 摄影与视觉语言

> 这一份是**换词表**：把用户嘴里的"好看/高级/电影感"换成模型认识的摄影语言。
> 原则：**能用专有名词就不用形容词。**

---

## 一、景别（Shot Size）

| 景别 | 画面含什么 | 典型用途 | 常用焦段 |
|---|---|---|---|
| 大远景 Extreme Wide | 环境为主，主体极小 | 世界观、孤独、史诗 | 16–24mm |
| 远景 Wide | 主体全身 + 大量环境 | 场景交代、建筑 | 24–35mm |
| 全景 Full | 主体全身，环境次要 | 服装、空间关系 | 35–50mm（**全身立绘用 50mm**，见下） |
| 中景 Medium | 膝盖以上 | 动作、交互 | 50mm |
| 中近景 Medium Close | 胸以上 | **最通用**（人/产品皆可） | 50–85mm |
| 近景 Close | 肩以上 / 主体局部 | 情绪 | 85–135mm |
| 特写 Close-up | 面部 / 单品 | 质感、细节 | 85–100mm |
| 大特写 Extreme Close | 眼睛 / 水珠 / 纹理 | 材质说服力 | 100mm 微距 |

**搭配禁忌**：大远景 + 85mm（压缩过头，看不出宏大）、大特写 + 16mm（畸变到认不出）。

### 全身立绘该用哪支镜头（这条历史上写过两个数，现统一）

| 用途 | 焦段 | 理由 |
|---|---|---|
| **全身立绘 / 立绘设定稿** | **50mm f/4** | 保住全身透视关系，脚与头不被压缩；85mm 拍全身会把腿拍短、鞋拍扁 |
| 半身 / 中近景 | 85mm f/1.8–2.8 | 人脸最舒服，背景虚化干净 |
| 头像 / 特写 | 85–100mm f/2 | 五官不变形，皮肤质感最好 |

**一句话**：**全身用 50，半身以上用 85。** 想"高级"却把全身写成 85mm，是最常见的自相矛盾。

## 二、机位（Camera Angle）

| 机位 | 画面效果 | 什么时候用 |
|---|---|---|
| 平视 Eye level | 客观、平等、可信 | 纪实、人像、访谈感 |
| 略俯 15–30° | 舒适、可控、显干净 | **产品、食物、桌面** |
| 俯拍 90°（顶视） | 平面化、信息清晰 | flat lay、信息图、knolling |
| 仰拍 15–45° | 崇高、压迫、力量 | 建筑、英雄感、巨物 |
| 鸟瞰 Bird's eye | 全貌、秩序感 | 场景俯瞰、地图感 |
| 低角度贴地 | 夸张透视、动感 | 运动、街头 |
| 荷兰角 Dutch | 失衡、不安 | 惊悚、张力 |
| 过肩 Over the shoulder | 代入、主观 | 对话、观看 |

## 三、焦段（Focal Length）

| 焦段 | 透视特征 | 用途 |
|---|---|---|
| 14–18mm | 极强夸张，边缘拉伸 | 空间、室内、冲击 |
| 24mm | 强空间感，轻微畸变 | 建筑、环境人像 |
| 35mm | 纪实视角，带环境 | 街拍、叙事 |
| 50mm | 接近人眼，自然 | 通用 |
| 85mm | 轻压缩，背景柔 | **人像 / 产品标准** |
| 100mm 微距 | 1:1 放大 | 纹理、水珠、织物 |
| 135mm | 强压缩，背景奶油 | 特写、分离 |
| 200mm+ | 极强压缩，空间扁平 | 远景压缩、野生动物 |

**光圈配景深**：

| 光圈 | 景深 | 用途 |
|---|---|---|
| f/1.2–1.8 | 极浅（背景糊成色块） | 人像、氛围、夜间 |
| f/2.8–4 | 浅 | 产品特写、食物 |
| f/5.6–8 | 中（全景清晰） | 产品全身、空间 |
| f/11–16 | 深 | 建筑、风景 |
| f/16+ | 极深 + 星芒 | 光源星芒、大场景 |

**快门语言**：`1/2000s 凝固水花`、`1/60s 轻微拖影`、`2s 长曝光车流`、`B 门光绘`。

## 四、光位（Light Direction）

| 光位 | 描述 | 效果 | 适合 |
|---|---|---|---|
| 顺光 | 光源在机位后方 | 平、无立体 | 证件照、电商白底 |
| 45° 侧光 | 斜前方 | 立体 + 保留细节 | **最通用** |
| 90° 侧光 | 正侧方 | 强立体、分割脸 | 戏剧人像、质感 |
| 侧逆光 | 斜后方 | 轮廓光 + 发丝光 | 氛围、秋日 |
| 正逆光 | 主体后方 | 剪影 / 光晕 | 情绪、日出 |
| 顶光 | 正上方 | 压抑 / 食物透光 | 餐厅（注意眼窝阴影） |
| 底光 | 下方 | 恐怖 / 神秘 | 惊悚、舞台 |
| 伦勃朗光 | 45° 上侧，暗部呈三角光 | 古典肖像 | 高级人像 |
| 蝴蝶光 | 正前上方 | 鼻下蝶形阴影 | 美妆、女性人像 |
| 分割光 | 90° 硬光 | 半明半暗 | 强对比时尚 |
| 环形光 | 环闪正前 | 无阴影、均匀 | 美妆、医美 |

**光质**：`硬光（小光源、边缘锐利）` / `柔光（大面积漫射、过渡柔和）` / `混合（主硬补柔）`。

**光比**：`1:2 柔和` / `1:3 自然` / `1:4 立体` / `1:8 戏剧` / `1:16 强反差（接近剪影）`。

## 五、色温（Color Temperature）

| 色温 | 感觉 | 典型场景 |
|---|---|---|
| 1800–2200K | 烛火橙红 | 烛光晚餐、篝火 |
| 2700–3000K | 暖黄，居家 | 客厅台灯、卧室 |
| 3200K | 钨丝灯暖 | 老室内、酒吧 |
| 4000K | 暖白中性 | 咖啡馆、餐厅 |
| 5000–5600K | 日光白 | 户外正午、产品标准 |
| 6500K | 阴天冷白 | 阴雨、北欧 |
| 8000–10000K | 蓝调 | 蓝调时刻、夜雪 |

**冷暖对比**是廉价提升质感的最快手段：`暖色主体 + 冷色环境` 或 `冷色环境 + 单一暖色实用光源`。

## 六、时间 / 天气

| 时段 | 光特征 | 关键词 |
|---|---|---|
| 蓝调时刻 | 天空深蓝，人造光刚亮 | blue hour, city lights on |
| 黄金时刻 | 低角度暖金，长影 | golden hour, raking light |
| 正午 | 顶光硬，短影 | harsh noon sun, hard shadows |
| 阴天 | 巨大柔光箱，无影 | overcast, soft even light |
| 雨后 | 反射、饱和度提升 | wet ground, reflections |
| 雾天 | 层次分离，空气感 | fog, atmospheric depth |
| 雪天 | 高反光，蓝阴影 | snow, blue shadows |

## 九、常用视觉套路（一句话就能锁住的成熟范式）

| 套路 | 写法 |
|---|---|
| 产品悬浮 | `产品悬浮于画面上方，下方投柔和椭圆阴影` |
| 平铺 knolling | `顶视平铺，所有物件等距正交排列，间距一致` |
| 分层剖面 | `画面分为三层，由近至远依次为…每层之间薄雾分离` |
| 双联对比 | `画面左右五五分割，左侧…右侧…，中间细白线分隔` |
| 框架式 | `透过门框/窗框观看主体，前景边框虚化` |
| 镜像反射 | `主体置于湿润深色反光地面，倒影清晰但略暗` |
| 微缩模型 | `移轴效果，画面呈现微缩模型质感，人物如玩具` |
| 图文叠加 | `主体右侧 40% 为纯净浅色区域，供排版使用` |
| 时间序列 | `同一画面内四个圆形切片，展示由生到熟的四个阶段` |
| 手部入画 | `一只手持握产品，仅露出手腕以下，指甲干净` |

## 十一、三条视觉常识（省一次返工）

1. **暗部不是黑的。** 写 `shadow detail retained, deep but not crushed` 而不是"很暗"。
2. **眼神光决定活气。** 人像/动物加 `catchlight in eyes`，否则像标本。
3. **地面要有落影。** 产品/静物写 `soft contact shadow under the object`，否则像贴图。
