# 06 画面文字（Text in Image）

> 一句话原则：**文字是奢侈品。能用后期就别赌生成；真要赌，就按能力分级赌。**
> 90% 的"海报不好用"，根源是提示词里塞了文案，模型画出一堆乱码。

---

## 一、能力分级（2026）

| 级 | 模型 | 能赌什么 | 不能赌什么 |
|---|---|---|---|
| **S** | Ideogram、Seedream 5.0 Pro、GPT Image 2、Nano Banana Pro | 6–12 字短标题、单词、数字、简单英文排版 | 长段落、竖排、书法体、复杂汉字 |
| **A** | Midjourney v7、Flux.2 | 3–6 个英文单词、单个 Logo 字 | 中文、长句 |
| **B** | 通义万相、可灵图像 | 短英文/短中文（不稳） | 一切长文本 |
| **C** | SDXL / 老版模型 | 基本不能 | 全部 |

**结论**：
- 中文标题 → Seedream 5 / GPT Image / Nano Banana Pro 值得试 1–2 次，失败立刻转后期
- 英文标题 → Ideogram 首选
- 多行文案、价格、地址、二维码 → **一律后期**

---

## 二、三档文字策略

### 策略 A：零文字（默认推荐）

正向写清"纯净"，并在反向/禁令里排除：

```
中文：画面中不出现任何文字、字母、数字、标志、水印
英文：no text, no lettering, no watermark, no logo, clean unmarked surfaces
```

> ⚠️ 自然语言模型（Flux / GPT Image / Seedream）不要只写 `no text`，要写完整句：
> `The image contains no lettering of any kind; all surfaces are blank.`

### 策略 B：假文字（需要"有字的感觉"）

```
中文：包装上有抽象排版纹理与色块，但文字不可辨认
英文：pseudo-text on the packaging, illegible, abstract typographic texture
```
适用：书籍封面、包装、报纸、屏幕 UI、街景招牌。  
好处：**永远不会出现乱码观感**，后期叠真字时也不会冲突。

### 策略 C：真文字（赌）

**四件套必须齐全**，缺一件就废：

1. **文案用引号逐字写出**（不加引号模型不知道那是"要写的字"）
2. **指定位置**（上/中/下、左/右、占画面百分比）
3. **指定层级**（主标题最粗最大，副标题 1/3，标签最小）
4. **禁止翻译与增删**

模板：

```
画面下方 25% 区域内放置标题 "秋日限定"，黑色粗体无衬线，字号占该区域高度 1/2，居中；
其下 8px 处放置副标题 "9.20 起 全国门店"，字号为主标题 1/3；
所有文字严格保持上述原文，不翻译、不改写、不添加任何其他字母或数字。
```

英文版：

```
Place the headline "AUTUMN LIMITED" in the lower quarter, bold condensed sans-serif,
centered, occupying half the height of that zone. Below it, "SEP 20 — ALL STORES" at
one third the size. Keep the copy exactly as written; no translation, no extra words.
```

## 三、中文处理三策（按风险从低到高）

| 策 | 做法 | 风险 | 适用 |
|---|---|---|---|
| **后期叠字** | 图内留白，PS/稿定/Canva 加字 | 0 | **海报、封面、banner（首选）** |
| **假文字 + 后期** | 图内有排版感，字不可辨 | 极低 | 包装、书籍、街景 |
| **真文字生成** | 引号写法 + 短文案 | 中高 | 社媒封面、单字 KV |

**中文四大坑**：

1. **竖排**：几乎全崩，除极少数模型
2. **书法/宋体细节**：笔画粘连、缺笔
3. **多行对齐**：行距乱、错行
4. **繁简混排**：随机变体

**降险写法**：`图上只有四个字"秋日限定"，超大字号，占画面宽度 60%` —— 字数越少越稳。

## 四、版式安全区

| 用途 | 安全区 | 说明 |
|---|---|---|
| 竖版海报 3:4 | 顶部 25–30% + 底部 10% | 标题区 + 品牌信息区 |
| 小红书封面 3:4 | 上部 22% | 平台会压标题 |
| 抖音封面 9:16 | 上下各 15% | 评论区与进度条遮挡 |
| 公众号头图 2.35:1 | 左或右 40% | 标题常压在左侧 |
| 电商主图 1:1 | 四周 12–15% | 平台裁切与角标 |
| 信息图 4:5 | 四边 8% | 印刷出血与装订 |

**写进提示词的句式**：

```
顶部 28% 为纯净浅米色留白，无任何元素与纹理，供后期排版
the top 28% is clean unmarked negative space
```

> 只写"留白"不够，必须给**比例 + 颜色**，否则模型会理解成"稍微空一点"。

## 五、排版词汇（让模型"排得像设计过"）

| 词 | 中文写法 | 英文 |
|---|---|---|
| 字重 | 超粗黑体 / 细体 | ultra-bold / light weight |
| 字族 | 无衬线 / 衬线 / 等宽 / 手写 | sans-serif / serif / monospace / script |
| 字距 | 大字距 / 紧排 | wide tracking / tight tracking |
| 对齐 | 左对齐 / 居中 / 两端对齐 | left-aligned / centered / justified |
| 层级 | 主标题 / 副标题 / 正文 / 角标 | headline / subhead / body / caption |
| 版式 | 上下分割 / 网格 / 跨页 / 卡片 | split layout / grid / spread / card |
| 印刷 | 烫金 / 压凹 / 丝印 / UV | gold foil / deboss / screen print / spot UV |

## 六、常见失败与对策

| 现象 | 根因 | 对策 |
|---|---|---|
| 乱码笔画 | 模型不认字形 | 转策略 A/B；或降字数到 4 字内 |
| 中文变英文 | 未指定语言 | 加 `文字为简体中文，不得出现英文字母` |
| 文字被裁 | 未给安全区 | 加 `文字距画面边缘 ≥8%` |
| 文字重复多份 | 未指定数量 | 加 `标题仅出现一次` |
| 文字压在杂乱背景上 | 未给承载区 | 加 `标题置于纯色色块上` |
| 排版挤成一坨 | 未给层级与间距 | 给字号比例 + 间距 |
| 文字歪斜 | 未指定水平 | 加 `文字水平居中，不倾斜` |

## 七、信息图专用写法（文字密度最高）

信息图是唯一"文字必须多"的场景，写法与海报不同：**先网格，后内容，再层级**。

```
4:5 竖版信息图，顶部标题区占 15%，主体为 3 行 × 2 列等距网格（间距 3%），
每个网格含一个圆形图标 + 一行说明文字（不超过 8 字），底部 10% 为品牌条。
配色：米白底 + 深墨绿主色 + 赭石强调。
所有说明文字为简体中文，字号统一，左对齐于图标下方。
```

**推荐模型**：Seedream 5.0 Pro（信息密度与中文渲染最稳）、Nano Banana Pro（英文信息图）。  
**必须做的**：出图后逐字校对，**任何一处错字都要局部重绘或后期修**，不要整张重生成。
