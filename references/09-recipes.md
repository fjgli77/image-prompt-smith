# 09 十八张配方卡

> 每张卡：**画幅 → 骨架 → 必写约束 → 可抄示例 → 专属陷阱**。
> 拿到需求先找卡，不要从零拼。

---

## 1｜小红书 / 社媒封面（3:4）

**骨架**：交付 → 主体 → 场景 → 风格 → 光 → 构图（上部留白）→ 色  
**必写**：上部 22% 纯净留白｜主体居中偏下｜低饱和 + 单一强调色｜`画面无文字`

```
3:4 竖版社媒封面，主体为一只刚做好的可颂，放在浅米色亚麻布上，旁边一杯黑咖啡，
生活化场景，清新生活方式摄影，晨光从右侧窗进来，45° 侧逆，柔光，4000K，
主体位于画面下部 60%，上部 25% 保持纯净米白留白，浅杏与奶油色调，低饱和。
画面中不出现任何文字、标志与水印。
```
**陷阱**：平台会压标题 → 上部留白不足直接废；可颂容易画成"面包块"→ 写 `层次分明、可见酥皮断口`。

---

## 2｜公众号头图（2.35:1）

**骨架**：交付 → 主体 → 场景 → 光 → 构图（一侧留白 40%）→ 色  
**必写**：2.35:1｜左右一侧 40% 纯净区｜主体不居中

```
2.35:1 横版头图。左侧为一张老式木质书桌，桌面有一本摊开的笔记本、一支钢笔、一杯清茶，
右侧 40% 为纯净的暖灰墙面留白。侧逆窗光，柔和光比 1:3，4500K，低饱和暖中性色。
画面无任何文字。
```
**陷阱**：2.35:1 在多数平台要单独设置，别忘参数；桌面物件别超过 4 件。

---

## 3｜活动海报（3:4）

**骨架**：版式蓝图（上下 6:4）→ 上区主视觉 → 下区色块 → 文案层级  
**必写**：顶部 30% 标题区｜下区纯色块｜主标题 ≤6 字｜文字引号 + 层级

```
3:4 竖版活动海报。上区（60%）：秋日市集主视觉，木质摊位、南瓜与干花、暖黄串灯，
黄昏时分，生活方式摄影，暖调低对比，50mm f/2.8 浅景深。下区（40%）：深墨绿色纯色块。
下区居中放置标题 "秋日市集"，暖白色粗衬线体，字号占下区高度 1/2；
其下小字 "10.12—10.15 · 中央公园"，字号为主标题 1/3。文字保持原文，不翻译、不添加。
```
**陷阱**：主标题 >6 字中文必错；写"秋日市集"比写"2026 秋季限定市集嘉年华"稳十倍。

---

## 4｜电商主图（1:1 白底）

**骨架**：交付 → 主体 → 光（无影棚）→ 构图（居中 60%）→ 材质  
**必写**：纯白 `#FFFFFF`｜主体占 55–65%｜软接触阴影｜无道具无文字

```
1:1 电商主图。一只磨砂琥珀色玻璃精华瓶，圆柱瓶身，金属滴管盖，居中直立。
纯白无缝背景，大面积柔光箱正上方 + 左右补光，光比 1:2，5600K，
瓶身有清晰的高光带与柔和渐变，底部自然接触软阴影。主体占画面高度 62%。
画面中只有这一件产品，无道具、无文字、无水印。
```
**陷阱**：白底要写"纯白无缝"否则出灰底；瓶身标签位置要写，否则标签随机生成。

---

## 5｜电商场景 / 氛围图（1:1 或 4:5）

**骨架**：交付 → 主体 → 场景（与产品调性一致）→ 光 → 色 → 构图  
**必写**：产品占 45–55%｜场景元素 ≤3 件｜色调与品牌一致

```
4:5 电商场景图。一瓶磨砂琥珀精华瓶立在浅米色洞石台面上，
后方是同色系墙面与一枝干枯尤加利，右下有一小块亚麻布。
晨间侧光 45°，柔光，光比 1:3，5000K，暖中性低饱和。产品占画面高度 50%。
无文字、无人物、无其他产品。
```
**陷阱**：场景元素抢主体 → 强制数量上限；石材与产品同色会糊在一起 → 加"产品边缘清晰"。

---

## 6｜产品悬浮 KV（16:9 / 1:1）

**骨架**：交付 → 主体（悬浮）→ 背景 → 光（硬边高光）→ 投影 → 色  
**必写**：悬浮高度｜下方椭圆阴影｜背景渐变或纯色

```
16:9 广告主视觉。一瓶黑色磨砂香水悬浮于画面中央，略微倾斜 15°，
背景为深墨绿到近黑的径向渐变，产品下方有柔和的椭圆投影。
左上方硬质轮廓光勾勒瓶身边缘，右下方柔和补光，光比 1:6，
瓶盖金属拉丝质感清晰。深绿 + 黑色 + 一点香槟金。无文字、无水印。
```
**陷阱**：悬浮不写投影 = 贴图；背景纯黑会让产品消失 → 用近黑渐变。

---

## 7｜信息图（4:5 / 1:1）

**骨架**：网格 → 分区内容 → 文案层级 → 配色 → 排除  
**必写**：行列数｜间距｜每格元素｜字号统一｜无照片无景深

```
4:5 竖版信息图。顶部 15% 为标题区，下方为 3 行 × 2 列等距网格，格间距 3%。
每格含一个线性图标（统一 2px 描边）与一行不超过 6 字的说明文字，左对齐。
底部 10% 为品牌条。配色：米白底 + 深墨绿主色 + 赭石强调。
扁平矢量风格，无照片、无渐变、无阴影。
```
**陷阱**：格子越多越崩 → 上限 6 格；图标风格不统一 → 显式写"统一线宽"。

---

## 8｜文章配图 / 观点图（16:9）

**骨架**：概念实体化 → 主体 → 空间 → 风格（编辑插画/概念摄影）→ 光 → 构图  
**必写**：一个视觉隐喻｜主体 ≤2 个元素｜大量负空间

```
16:9 编辑配图。一个白色陶瓷小人站在巨大的迷宫一角，迷宫由浅灰色混凝土墙构成，
从上方 45° 俯视，35mm 镜头 f/8，柔和顶光，画面右侧 40% 为空白浅灰背景。
概念化编辑插画，极简，低饱和，色彩仅白、浅灰、一点砖红。
无文字。
```
**陷阱**：抽象概念不实体化 = 出不来；元素超三个 = 隐喻失效。

---

## 9｜视频 / 播客封面（16:9 或 9:16）

**骨架**：交付 → 主体（人物或物件）→ 背景 → 强对比光 → 留白区  
**必写**：高对比｜主体大｜一侧留白

```
16:9 播客封面。一位三十岁上下的男性侧脸剪影，深色背景，
右侧 45% 为纯净的炭灰色留白。单侧硬光从左侧勾勒轮廓，光比 1:8，
冷蓝色环境光 + 一点暖色轮廓。高对比、低饱和。无文字。
```
**陷阱**：缩略图尺寸下细节全丢 → 主体必须大、对比必须高。

---

## 10｜食物摄影

**骨架**：交付 → 菜品（状态）→ 器皿 → 表面 → 光（侧逆透光）→ 机位  
**必写**：温度/状态｜汁水或蒸汽｜45° 或顶视｜暖 4000K

```
食物摄影。一碗刚出锅的牛肉面，汤面浮着红油与葱花，热气可见，
粗陶碗，放在深色木桌上，旁有一双木筷。
45° 侧逆光透出热气，白卡补正面，4000K 暖光，光比 1:3，
汤面有油脂高光，面条断口清晰。低饱和暖调。
无文字、无人物。
```
**陷阱**：不写"热气/汁水"= 冷掉的道具；顶视拍汤面会失去层次 → 用 45°。

## 11｜建筑 / 空间

**骨架**：交付 → 空间类型 → 材料 → 时间光 → 焦段（24mm）→ 尺度参照  
**必写**：垂直线校正｜材料具体名｜人体尺度参照

```
建筑摄影。一间混凝土住宅的起居室，清水混凝土墙面与浅橡木地板，
大面积落地窗朝西，午后低角度阳光在地面拉出长影，
24mm 广角，垂直线保持垂直，地平线水平，f/8 全景深。
一把布艺单椅与一盏落地灯作为尺度参照。冷灰 + 暖木，低饱和。
无人物、无文字。
```
**陷阱**：不写"垂直线垂直"→ 必歪；无参照物 → 看不出层高。

## 12｜头像（1:1）

**骨架**：主体（半身/胸像）→ 简洁背景 → 柔光 → 85mm → 眼神光  
**必写**：中近景｜背景单色或虚化｜自然皮肤质感｜正脸或 3/4 侧

```
1:1 头像。一位二十七八岁女性的半身像，齐肩黑发，浅灰色针织衫，
正面略微 3/4 侧，自然微笑，眼睛有眼神光。
浅米灰纯色背景，45° 柔光窗光 + 反光板补暗部，光比 1:3，5500K，
85mm f/2.0，皮肤保留自然纹理与毛孔。低饱和暖调，背景简洁。
无文字、无水印。
```
**陷阱**：写"绝美/精致"→ 变网红脸；背景带元素 → 头像显乱。

## 13｜壁纸（9:16 / 16:9）

**骨架**：氛围为主 → 中心留空 → 低对比 → 无主体焦点  
**必写**：中心 40% 简洁｜低对比｜暗色或柔和（不刺眼）

```
9:16 手机壁纸。深蓝到墨紫的夜空，稀疏星点与薄云，
画面中心 40% 区域为平滑渐变，无任何主体；
右下角有一小片极简的山脊剪影。极低对比、柔和、昏暗，
无文字、无人物、无强光源。
```
**陷阱**：高对比花纹会让图标看不清；中心放主体 → 挡图标。

## 14｜游戏 / 动画场景概念（16:9）

**骨架**：交付 → 场景类型 → 建筑语言 → 时间天气 → 光 → 氛围层  
**必写**：尺度（远景/全景）｜前中后景分层｜体积光或雾

```
16:9 场景概念图。一座建在悬崖边的废弃观测站，锈蚀钢架与破碎玻璃穹顶，
黄昏，海雾从下方涌上，远处海面反射橙红光。
远景构图，前景岩壁、中景建筑、远景海面三层分离，层间薄雾。
侧逆光，体积光穿过破洞，光比 1:8，青灰 + 橙红对比。
无人物、无文字。
```
**陷阱**：不给分层 → 糊成一团；不给尺度 → 像模型玩具。

## 15｜Logo / 图标（1:1）

**骨架**：图形概念 → 几何构成 → 单色或双色 → 纯背景 → **不要文字**  
**必写**：`矢量标志，无文字`｜几何化｜负空间运用

```
1:1 标志设计。一个由两片叶子交叠构成的抽象图形，几何化、极简、对称，
仅用深墨绿单色，纯白背景，矢量风格，边缘干净，线条等粗。
负空间形成一条向上的箭头。无任何文字、无字母、无水印。
```
**陷阱**：**永远不要赌模型写字**，Logo 字一律后期排；复杂渐变 → 缩小后糊。

## 16｜书籍封面（2:3）

**骨架**：版式（上图文下书名）→ 主视觉 → 纸感 → 文字层级  
**必写**：2:3｜书脊留位｜标题区｜纸张肌理

```
2:3 书籍封面。画面上部 65% 为一张模糊的海边礁石照片，冷蓝灰调，阴天；
下部 35% 为米白色纸面，有细微纤维肌理。
下部居中放置书名 "潮汐"，黑色衬线体，字号占下区高度 40%；
其下作者名 "林川"，字号为书名 1/4。文字保持原文，不翻译。
整体低饱和、安静、文学感。
```
**陷阱**：书名 >4 字风险高；写"设计感"无用 → 写纸感与字号比例。

## 17｜前后对比 / 步骤图（16:9 或 1:1）

**骨架**：分割版式 → 左右各自内容 → 分隔线 → 统一光与色  
**必写**：五五分割｜细线分隔｜两侧光一致

```
16:9 对比图。画面左右五等分，中间一条 2px 浅灰竖线分隔。
左侧：使用前的旧皮革沙发，表面开裂、颜色暗沉；右侧：同款沙发翻新后，皮面柔亮、缝线整齐。
两侧使用完全相同的侧光与色温（45° 侧光，5000K），相同背景浅灰墙面。
写实摄影，低饱和。无文字。
```
**陷阱**：两侧光不一致 → 对比失效；不写"同款" → 出现两个不同产品。

## 18｜节日 / 节气图（3:4 或 1:1）

**骨架**：节气元素（具体物候）→ 场景 → 光 → 国风或现代 → 留白  
**必写**：具体物候（不是"秋天"）｜传统色名｜留白

```
3:4 竖版节气图。白露：清晨草地上的露珠特写，狗尾草叶尖挂着水珠，
背景虚化的浅金色田野，顶部 30% 为雾白色留白。
微距 100mm，f/2.8，逆光透出水珠高光，色温 4500K，
月白、秋香、一点赭石。极简、安静。
画面中不出现任何文字。
```
**陷阱**：写"秋天"→ 满屏南瓜枫叶；写物候（露珠/桂香/稻穗）才准。

## 19｜东方玄幻 / 仙侠神域（3:4 竖幅 / 16:9 横）

> 这类图最容易出的不是"不好看"，是**空**：一句"云雾仙山"被填成一张灰底，
> 人物站在上面像贴纸。根因是**场景只写了"是什么"，没写"由几层构成"**。

**骨架**：主体 → 精简法袍 → 法器 → 场景三层 → 特效两层 → 光 → 镜头

**场景三层（缺一层就空）**：

| 层 | 写什么 | 例 |
|---|---|---|
| **前景压角** | 一件离镜头最近的东西，占画面 10–20% | 半透明的冰晶柱 / 断裂的石栏 / 垂落的云气 |
| **中景主景** | 人物所在的那块"地"与背后的主体建筑 | 悬浮石台 + 断裂的神阙柱廊 |
| **远景** | 给尺度与世界观 | 云海中的山峰剪影、远处悬浮的宫阙 |

**必写**：三层分离 + 层间大气（薄雾/尘/光柱）｜尺度参照（远景山峰占画面 1/10）｜法器位置（在手里 / 悬浮在侧）

```
3:4 竖幅，东方玄幻仙侠神域。
主体：一名女法神立于悬浮石台边缘，银白长发被气流带起，右手持杖点地。
服装：主件两件——冰蓝法袍（内）+ 银白披风（外）；裙缘一道冰晶光缕游走，
袖口符文依次亮起（只此两处发亮，其余不发）。配饰三件：发冠、腕环、腰佩。
场景三层：前景左下角一根半透明冰晶柱压角；中景石台与断裂的白玉柱廊；
远景云海中三座山峰剪影，最远那座只占画面高度 1/8。层间一层薄雾过渡（不加其他介质）。
特效：主特效为冰晶尘自裙缘向上升腾，稀疏、米粒大小，不遮挡面部；
辅为杖尖一点冷光晕，高光保留细节。
光：右后方侧逆光穿过云层形成体积光，尘在光柱里可见，光比 1:5，6500K 冷调，
面部由左侧微弱反射光提亮，不死黑。
镜头：全身，相机略低于腰线，50mm f/4，人物占画面高度 70%；
披风与左臂之间留出可见空隙，无相切轮廓。
风格：3D 动漫半写实（国漫向），painterly shading，体积光 + 手绘感过渡。
画面中不出现任何文字、水印、标志、地面投影。
```

**四条陷阱**：

1. **只写"云雾仙山"** → 灰底。必须三层 + 层间大气。
2. **没有尺度参照** → 山像假山。给"最远山峰占画面 1/8"这类比例。
3. **法袍堆到四五件** → 看不出人形。主件 ≤2、配饰 ≤3（见 `outfit-design.md` §一.5）。
4. **全身发光** → 过曝、剪影消失。发亮只留两处（裙缘 + 袖口），其余写"布纹仍可见"。

**同族变体**：仙门宗派（改为"山门 + 弟子阵列"）、魔域（配色转墨紫/暗红，光比 1:8）、
废墟神域（前景改断壁，远景改塌陷的浮空岛）。

## 20｜宗门 / 帝庭全景（16:9 或 3:4 竖）

> 场景类配方的通用毛病是"只有一层"：一座山、一座殿，人放上去就完。
> 宗门/帝庭要的是**纵深**——柱列、台阶、云海三层，让人显得"小"。

**骨架**：纵深方向 → 中轴主体 → 两侧秩序 → 层间大气 → 光轴 → 尺度差

**必写**：柱列向纵深收敛｜台阶级数｜层间薄雾｜一道光轴｜人物占画面比例

```
16:9 宗门帝庭全景，东方玄幻。
纵深：九级白玉台阶自下而上，两侧各一列蟠龙柱，共十二根，柱列向远处收敛于一点。
```
