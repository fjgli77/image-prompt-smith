# 11 风格块：把风格写成可检查的区间

> 来源：`manju-laoli-skill` 的 `style-bible/`（九槽 STYLE 块 + 11 槽参数库 + 互斥对机检）。
> 核心判断：**风格不是形容词，是一组带上下限的参数。** 写"电影感"是许愿，写"光比 [1:5,1:9]、镜头 [24mm,85mm]、饱和度 [低,中]"才是施工图。

---

## 一、为什么必须用「区间」而不是单值

| 写法 | 后果 |
|---|---|
| `光比 1:4` | 一张图能看，十张图必然有一半不对——因为每张的 1:4 都实现得不一样 |
| `光比 [1:3, 1:5]` | 模型在区间内自由，但不会越界；系列图有回旋余地，又不会漂 |

**区间的作用是"给弹性但设边界"**：太死的单值会逼模型每次重掷一个随机点；太松的词（"电影感"）等于没边界。区间是唯一能同时满足"稳定"和"不僵"的写法。

**可机检性**：区间能被脚本检出越界（比如要求 `[1:4,1:8]`，提示词里写 `1:16` → 画风漂移）。形容词不能。

## 二、九槽 STYLE 块（整段逐字粘贴）

```
【STYLE｜视觉风格 · 锁定】
成像底层：〔采集/渲染的技术底层，决定颗粒、滚降、是否像实拍〕
形体骨相：〔头身比 + 骨相倾向 + 是否真人质感〕
影调区间：光比 [A, B]，〔暗部处理〕，〔禁止项〕
色彩区间：主调〔…〕，点缀〔…〕，色温 [X K, Y K]，饱和度 [低/中/高, 低/中/高]
空气介质：〔雾/尘/雨/光柱〕（≤2 层）
光学区间：镜头 [X mm, Y mm]，〔畸变/景深/焦段分工〕
材质响应：〔3–5 种关键材料各自的高光与纹理反应〕
特效语言：〔用什么物理现象替代什么虚拟效果〕
针对性禁项：禁〔这套风格最容易漂成的东西〕
```

**七条填写规则**

1. **每槽至少一个可测量项**：头身比、光比、色温、焦段、层数。全形容词的槽等于空槽。
2. **色温与光比写区间**，钢性数值越少越稳。
3. **空气介质 ≤2 层**：雾 + 尘 + 雨 三层齐上，画面必糊。
4. **光学区间要与用途匹配**：海报主视觉给 `[24mm, 85mm]`，产品图给 `[85mm, 100mm]`。
5. **材质响应写"反应"不写"材料"**：不是"金属"，是"金属冷硬高光 + 边缘镀边反射"。
6. **针对性禁项 3–5 条，不说通用废话**：`禁塑料感三渲二` 有效，`禁低质量` 无效。
7. **同一系列只写一份**，每条提示词逐字复制，只改主体/动作/构图。

## 三、五个成品块（可直接抄，改主调即可）

### A｜写实商业摄影（产品 / 生活方式 / 电商）

```
【STYLE｜视觉风格 · 锁定】
成像底层：数字中画幅采集，高光柔顺滚降，颗粒强度 [极低, 低]
形体骨相：真实比例，不做美化变形，皮肤保留毛孔与细纹
影调区间：光比 [1:2, 1:4]，暗部保留细节，禁止死黑与死白
色彩区间：主调中性（米/灰/白），点缀单一饱和色（面积 <5%），色温 [5000K, 5800K]，饱和度 [低, 中低]
空气介质：无雾或极薄（≤1 层），仅在产品边缘留空气感
光学区间：镜头 [85mm, 100mm]，f/5.6–f/8 全景深，略俯 15°
材质响应：磨砂玻璃内散射、金属拉丝高光带、织物绒毛倒顺、石材颗粒
特效语言：无特效，靠光位与材质说话
针对性禁项：禁塑料感、禁网红滤镜、禁过饱和、禁 HDR 光晕、禁柔光美颜
```

### B｜电影感叙事（剧照 / 概念海报）

```
【STYLE｜视觉风格 · 锁定】
成像底层：宽银幕数字采集，高光溢出柔化，颗粒强度 [低, 中]
形体骨相：6.5~7.5 头身写实骨相，面部有结构不锐利
影调区间：光比 [1:5, 1:9]，大面积暗部配局部强光斑，禁止平均亮度
色彩区间：主调冷青灰，点缀暖琥珀（实用光源），色温 [3200K, 5600K]，饱和度 [低, 中]
空气介质：薄雾或雨丝（≤2 层），侧逆光下轨迹可见
光学区间：镜头 [35mm, 85mm]，大光圈浅景深，允许前景遮挡
材质响应：湿滑反光地面、玻璃反射、布料起皱、皮肤潮润
特效语言：几乎无特效，只允许光晕与霓虹闪烁
针对性禁项：禁平光、禁均匀布光、禁干净锐利数码感、禁大场面全景
```

## 四、互斥对：不可"主 + 辅"混用

风格能混，但**底层互斥的不能混**。下面八对踩中任一对，出图必然"半张一半"：

| 互斥对 | 为什么互斥 |
|---|---|
| 硬光 / 柔光 | 同一画面不能既锐利阴影又无阴影 |
| 高反差 / 柔光装饰 | 影调逻辑相反 |
| 厚写实 / 动画平涂 | 解剖与描边规则冲突 |
| 留白极简 / 大色块满幅 | 空间占用相反 |
| 冷峻低照度 / 温暖高调 | 色温与曝光逻辑相反 |
| 颗粒胶片 / 零颗粒数字 | 成像底层相反 |
| 实拍真实皮肤 / 动漫五层眼睛 | 五官字段不同套（见 `references/character/anime-3d.md`） |
| 精密机械秩序 / 手绘粗粝随性 | 线条控制相反 |

**唯一正确的混合式**：

```
以【主风格】为底层，仅在【具体元素/局部】采用【副风格】的【某一种特征】
```

✅ `以写实商业摄影为底层，背景采用赛博朋克的霓虹青紫溢光`
❌ `写实摄影 + 动漫风格`（底层互斥，不能混）
❌ `硬光高反差 + 柔光美颜`（影调互斥）

## 五、专有名词：探索可用，交付要转译

风格块里写"王家卫风格""吉卜力风""MAPPA 打斗"，在**单图探索**阶段有效；但**生产稿/系列稿**应当转译成参数。

**三重理由**

1. **不可复现**：模型对专名的理解随版本漂移，今天像明天不像
2. **不可检查**：机检无法判断"够不够王家卫"，但能判断"光比有没有落在 1:4–1:7"
3. **版权与合规**：作品名/导演名进入最终交付稿，在商用与海外投放场景有额外风险

**转译对照（照这个思路自己拆）**

| 专名 | 拆成参数 |
|---|---|
| 王家卫 | 手持微晃 + 抽帧残影 + 钨丝暖黄与霓虹青绿交错 + 前景遮挡 + 光比 [1:4,1:7] + 颗粒 [中,高] |
| 徐克 | 硬边高光滚降 + 无颗粒 + 广角 [21mm,28mm] 轻微桶形畸变 + 体积雾 + 光比 [1:6,1:10] |
| 吉卜力 | 手绘水粉背景 + 饱和绿意 + 柔软云层 + 无描边硬线 + 低对比 + 暖调 |
| 芬奇 | 零颗粒数字 + 实用光源低照度 + 冷青绿 + 定焦零畸变 + 中轴稳定 + 光比 [1:4,1:8] |
| MAPPA 打斗 | 厚涂高反差 + 重黑线描边 + 明暗交界排线 + 逆光镀高光色带 + 广角贴脸畸变 |

**规则**：探索稿可留 1 个专名（方便沟通）；交付稿把专名换成上表右列，一个不留。

## 六、风格候选卡（给用户选，不要替他决定）

系列图/生产项目里，风格一旦定错，后面全部重做。所以**先给卡再动手**：

```
请选本次视觉风格：

A【推荐】写实商业摄影 · 产品向
   看得见：中性主调 + 单一强调色 · f/8 全景深 · 大面积负空间
   易跑偏：塑料感 · 过饱和 · 网红滤镜
   适配：电商主图 / 品牌 KV / 详情页

B 电影感叙事 · 情绪向
   看得见：冷青灰 + 暖实用光 · 光比 1:5–1:9 · 35–85mm
   易跑偏：平光 · 环境展示片 · 过暗
   适配：概念海报 / 短剧剧照 / 品牌故事

C 潮流 3D · 传播向
   看得见：糖果色 · 圆润几何 · 软硬混合光
   易跑偏：廉价塑料 · 玩具感过重
   适配：社媒 KV / 潮玩 / 活动主视觉

D 自定义 → 你描述，我按九槽建块

回复 A/B/C/D；不想挑就回「按你推荐走」。
```

**卡片三要素**：看得见（具体参数）· 易跑偏（最可能出的错）· 适配（什么用途别选它）。

## 七、风格块的使用纪律

1. **一份块管一个系列**，逐字复制，一个标点不改。
2. **改风格 = 重开**，不要在系列中途换块（会导致前几张作废）。
3. **块里不放主体**：主体、动作、构图是每条提示词的变量，风格块只放常量。
4. **块尾必有针对性禁项**：这是这套风格最需要的"预防针"。
5. **越界即判漂移**：光学区间写 `[24mm,85mm]`，提示词里出现 `16mm` → 风格漂了，不是构图问题。
