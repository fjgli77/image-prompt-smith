# 跨模型适配：一次写词，90% 的模型能用

> 用户不会只在一个平台出图。同一条描述搬到 MJ、SD、即梦、Flux、Nano Banana，效果天差地别。
> **解法不是记十套语法，而是把"描述"和"控制"分开**：描述用通用的，控制按平台换。

---

## 一、三层结构（先记住这张图）

```
① Brief（模型无关）  ← 主体/场景/动作/构图/光/色/材质/镜头术语
② Controls（六旋钮）  ← 画幅/风格强度/种子/参考图/反向/画质
③ Adapter（方言）    ← 语言、语序、权重、参数位
```

**Brief 是资产，Controls 是设置，Adapter 是翻译。**
换平台只换 ②③，①不动。这样一条词能活很久，也不会因为模型换代就废。

---

## 二、通用 Brief：11 个字段（照这个写，谁都读得懂）

| # | 字段 | 写什么 | 例 |
|---|---|---|---|
| 1 | 主体 | 什么、几个、什么姿态 | 一名二十多岁女性，半身，正面略侧 |
| 2 | 场景 | 地点、时间、天气 | 雨夜街道，霓虹招牌，湿地面 |
| 3 | 动作 | 在做什么 | 抬手扶住领口，视线看向画外 |
| 4 | 风格 | 媒介与调性 | 写实摄影，低饱和，轻微颗粒 |
| 5 | 镜头 | 焦段、景深、机位 | 85mm，f/2，平视略仰 5° |
| 6 | 光 | 方向、硬软、光比、色温 | 右侧 90° 霓虹主光，左侧弱暖补光，1:6，9000K |
| 7 | 构图 | 取景、主体位置、留白 | 半身取景，主体偏右，左侧负空间 |
| 8 | 材质 | 表面怎么吃光 | 哑光皮革、镀铬件锐利高光、湿发 |
| 9 | 用途 | 干什么用（决定留白） | 小说封面，下部留书名区 |
| 10 | 约束 | 必须做到 | 完整入画、不裁脚、不出现文字 |
| 11 | 排除 | 不要什么 | 多余手指、水印、第二个人 |

**4–5 个字段能出图，8–9 个字段能稳定复现，11 个字段能交给别人复用。**

## 三、全平台矩阵（20 个，按方言分四类）

### 3.1 自然语言派（写完整句，讲清关系）

| 模型 | 语言 | 长度 | 特点 | 避坑 |
|---|---|---|---|---|
| **Nano Banana Pro**（Gemini 3 Pro Image） | 中英皆可，英文更精确 | 长（100–300 词） | 强指令跟随、强文字、强编辑、最多 14 张参考图、21:9 4K | 别堆标签；官方明确"描述场景，不要罗列关键词"；编辑要写「只改 X，其余不变」 |
| **Nano Banana 2**（Flash 系） | 同上 | 中长 | 同族语法，更快，推理略弱 | 同上 |
| **GPT Image 1.5 / 2** | 英文优先 | 中（50–150 词） | 指令跟随最强、数量与位置准、编辑强 | 别用 MJ 参数；数量要写死；编辑先写"保持不变的部分" |
| **Imagen 4** | 英文 | 长（像小说） | 自然语言越好越好，少用相机黑话 | 别塞参数 |
| **Seedream 5 / 即梦 / 豆包** | **中文原生** | 中（60–150 字） | 中文语境强、海报与文字排版强、国风强、多参考 | 过长英文技术词收益低；别用权重括号 |
| **可灵 / 通义万相 / 混元 / 文心** | 中文 | 中 | 中文友好；部分支持独立负向 | 型号与功能差异大，以官方为准 |
| **Grok Imagine** | 英文 | 短中 | 快，偏创意 | 细节控制弱 |

**写法**（Nano Banana / GPT Image 官方口味）：

```
一张〔景别〕的〔主体〕，正在〔动作〕，位于〔环境〕。
光线来自〔方向与性质〕，形成〔氛围〕。以〔镜头/焦段〕拍摄，强调〔材质〕。
```

### 3.2 短句 + 参数派

| 模型 | 语言 | 长度 | 特点 | 避坑 |
|---|---|---|---|---|
| **Midjourney v7** | 英文优先 | **20–60 词** | 美学与氛围强；`--ar` `--style raw` `--stylize` `--sref`（风格参考）`--cref`（角色参考）`--no` | **不吃长句**；`--no` 很弱；权重用 `::`；技术黑话不如美学词 |

**写法**：主体 + 场景 + 光 + 风格，一句读完，末尾挂参数。

### 3.3 标签 + 权重派

| 模型 | 语言 | 长度 | 特点 | 避坑 |
|---|---|---|---|---|
| **SDXL / SD3 / ComfyUI / Forge** | 英文 | 40–80 标签 | 独立 negative 字段、权重量化、LoRA/ControlNet | 必须英文标签；权重 0.8–1.4；CFG 4–7 |
| **Flux.1 / Flux.2** | 英文 | 中长 | 字面理解强、手部好、空间介词灵 | **多数实现没有真负向**；`(x:1.2)` 非原生，视 UI |
| **Ideogram V3** | 英文 | 中 | **唯一图内文字可靠**，引号内照排 | 别指望中文长句 |

### 3.4 设计/商用派

| 模型 | 语言 | 特点 | 避坑 |
|---|---|---|---|
| **Recraft V4** | 英文 | 矢量/品牌/图标/文字 | 写实不是强项 |
| **Leonardo / Firefly** | 英文 | 中等，偏商用素材 | 参数在 UI 里，不进词 |

## 四、兼容性分级（哪些词能跨 90% 模型）

### S 级：几乎全通用（放心写）

```
主体 / 数量 / 动作 / 场景 / 时间天气 / 构图取景 / 主体位置 / 留白
光的方位与硬软 / 色温 / 光源类型 / 材质与其反光方式
镜头术语：85mm、f/2.8、浅景深、广角、微距、俯拍、仰拍、三分构图
画幅：3:4、16:9（写进正文或设置，别写"竖版"）
```

### A 级：多数吃（可以写，别依赖）

```
胶片型号：Kodak Portra 400 / Cinestill 800T / Tri-X 400
相机机身：Leica M6 / Hasselblad
双引号内文字（Ideogram / Seedream / Nano Banana / GPT Image 可靠，MJ 一般）
"高光保留细节""暗部不死黑"这类约束句
```

### B 级：少数吃（换平台要删）

```
(x:1.3) 权重括号 → 只有 SD 系原生
--ar / --style / --sref → 只有 MJ
BREAK 分段 → 只有 SD 系
真实导演/摄影师名 → MJ 最强，Flux 削弱，国产模型基本无感
```

### C 级：基本全废（**别写**）

```
masterpiece / best quality / award-winning
8k / 4k / ultra-HD / ultra-detailed / hyperrealistic
trending on artstation / cgsociety
very very very detailed（重复强调）
一长串 negative 词块（只有少数模型有独立负向字段）
```

> **2026 年的共识**：这一整类"咒语"在新一代模型上要么被忽略，要么被惩罚。
> 想提升质感，写光和镜头，不写 8K。

## 五、六旋钮对照（同一个控制，各家怎么写）

| 旋钮 | MJ | SD | Flux | Nano Banana | GPT Image | Seedream/即梦 |
|---|---|---|---|---|---|---|
| 画幅 | `--ar 3:4` | 宽高数值 1024×1365 | 参数字段 | 正文写「3:4 竖版」 | 选 size 或正文写 | 正文写「比例 3:4」 |
| 风格强度 | `--stylize 0–1000` | CFG 4–7 | guidance | 用词控制（"克制/浓烈"） | 用词控制 | 用词控制 |
| 种子 | `--seed` | seed 字段 | seed 参数 | 无 | 无 | 支持 |
| 参考图 | `--sref`/`--cref`/图 URL | img2img / ControlNet / IP-Adapter | 图生图 | 最多 14 张 | 直接附图 | 多参考 |
| 反向 | `--no`（弱） | 独立 negative | 多数无 | 无字段，写正面禁令 | 无字段，写正面禁令 | 末尾排除项 |
| 画质 | `--q` / upscale | steps + sampler | 步数 + 模型版本 | 1K/2K/4K | low/medium/high | 分辨率档 |

**只有"画幅"和"参考图"是真正跨模型通用的两个旋钮**，其余都要按平台落位。

## 六、一次出多版（默认交付形态）

不要再给"一条词"，给**一核多壳**：

```
【通用核心】中文，90% 平台可直接用（即梦/豆包/万相/可灵/Nano Banana/Imagen）
【英文版】给 MJ / Flux / SD / GPT Image
【适配说明】只列"要改的地方"（3 行以内）
```

示例交付：

```
〔中文核心提示词〕

英文版（MJ 用，删掉中文里的解释性短语，末尾加 --ar 3:4 --style raw --no text）
〔英文提示词〕

适配：SD 系把括号权重加回来并补独立 negative；即梦直接粘中文版，删掉英文参数。
```

**默认给中文核心 + 英文版两条，就覆盖了 90% 的使用场景。**

---

## 七、迁移六条（换平台必走）

1. **语言**：中文平台用中文；其余英文
2. **语序**：叙事句 ↔ 标签串；MJ 砍到 60 词内
3. **权重**：SD 加 `(x:1.2)`；其他平台删掉，改用词序前移
4. **反向**：独立字段 ↔ `--no` ↔ 正面禁令句 ↔ 末尾排除段
5. **参数**：搬出正文，落到平台的设置位
6. **删咒语**：`masterpiece/8k/trending` 一律删；质量靠光与镜头

## 八、一分钟自检

- [ ] Brief 与 Controls 分开了吗（描述里没有 `--ar`、没有 `(x:1.3)`）
- [ ] 主体在前 20 字 / 前 40% 内
- [ ] 光的方位+硬软+光比+色温齐
- [ ] 镜头有焦段 + 景深
- [ ] 画幅是数字比例
- [ ] 没有 C 级咒语
- [ ] 中文版能给即梦/豆包，英文版能给 MJ/SD
- [ ] 平台专属语法只在对应版本里出现

---

## 九、一句话

**描述写得通用，控制落到位。**
90% 的模型差异不在"你描述得对不对"，而在"你把控制放错了地方"。
