# 万物四视图：非人主体也能出设定表

> `image-types.md` 的三视图 / 四视图默认说的是**人**。
> 但用户挂上来的可能是一辆车、一件大衣、一把枪、一个手办。
> **人有人的人的解，物体有物体的解——物体的四个视角是专业判断，判错整张作废。**

---

## 〇、先判主体类型（五支，判错后面全错）

| 类型 | 判据 | 走哪一节 |
|---|---|---|
| **人类人物** | 有明确人脸五官与体型（真人照、人物立绘、写实头身） | §二 人物基线 |
| **非人物体** | 车辆、服装单件、枪械工具、箱包、家具、电子设备、雕塑手办、机械装置 | §三 物体视角表 |
| **动物 / 生物** | 有毛或有鳞、有非人五官 | §四 动物分支 |
| **一图多主体** | 画面里有两个以上完整主体 | §五 多主体处理 |
| **识别不出** | 图糊、遮挡严重、主体不完整 | **不猜**，说清看不到什么，请补一张 |

**真人照片走哪条**：如果想要"锁住这个真人的脸去做影视定妆"，走 `live-action-sheet.md`（那份专门处理真实身份保真）；如果只是"按这个人的造型做个角色设计"，走本文 §二。

---

## 一、两种节奏：人直接出，物先报方案

这是本文件最容易被违反、也最影响体验的一条。

| 主体 | 节奏 | 为什么 |
|---|---|---|
| **人类人物** | **直接出图，不问** | 正面 / 侧面 / 背面 + 全身 / 头肩，几乎是行业唯一解。多问一轮只是拖时间 |
| **非人物体** | **先报方案，等确认** | 车要看侧前 45°，大衣要看细节特写，枪要看顶部——视角选错，整张图没有参考价值 |

**物体方案的回复只写三件事**（多写一个字都是废话）：

```
主体：一件羊毛双面呢长大衣，驼色，双排扣
四格：正面 / 侧面 / 背面 / 领口与袖口细节特写
画幅与光：9:16，浅灰无缝棚，机位左前 45° 单硬主光
```

用户回"生成 / 可以 / 出图"即执行。**不要在方案里塞提示词**——他还没确认视角，提示词等于白写。

---

## 二、人物分支基线（2×2 四格）

不返回分析、不询问确认，直接出。

| 位置 | 视角标签 | 内容 |
|---|---|---|
| 左上 | `FACE FRONT` | 头肩特写，正面朝镜头，平静中性表情 |
| 右上 | `FACE SIDE` | 同等头肩画幅，干净侧面轮廓，表情与发型与左上一致 |
| 左下 | `BODY FRONT` | 全身正面站姿，双臂自然垂于体侧，**面部做低细节处理**（留给后期） |
| 右下 | `BACK` | 全身背面站姿，展示背部发型、服装背缝、鞋跟，**站位与左下完全同一处** |

**光**：单硬主光源，机位左前方 45°，中性色温，不打补光，只留地面自然接触阴影。

**基线禁止项**（这些是"改坏"的典型路径，不是风格偏好）：美颜滤镜｜油亮影视妆｜塑料假皮｜瘦脸大眼磨皮｜改站姿｜加配饰｜改身高体型。

**覆盖规则**：用户明确提的要求只要与某条基线冲突，**替换那一条**，其余继续生效。没有哪条是铁锁——他说换光就换光，说加墨镜就加墨镜；**只有他没提的部分**才按基线走。

> 面部低细节只在"人物 BODY FRONT"这一格用。**动物不要套这条**——毛发与五官就是主体信息，压掉就白做了。

## 三、非人主体：视角分配表（本文件核心）

按行业惯例迁移，不限于列出的品类。

| 品类 | 四格分配 | 关键点 |
|---|---|---|
| **汽车 / 摩托车** | 前 45° 斜侧 / 正侧 / 正前 / 正后 | 斜侧给体量与型面，正侧给轴距与轮位 |
| **大衣 / 外套** | 正面 / 侧面 / 背面 / 细节特写（领口·袖口·五金） | 细节格必须点到五金；面料垂坠靠侧面看 |
| **长袍 / 连衣裙** | 45° 斜侧全貌 / 正侧 / 正面 / 背面 | 斜侧看廓形与体量，正侧看厚度 |
| **枪械 / 工具** | 斜侧全貌 / 正侧 / 顶部 / 局部功能特写 | 顶部视角给操作逻辑，别省 |
| **背包 / 箱包** | 正面 / 侧面 / 背面 / 开口内部 | 内部格给分层与容量，是采购方最关心的 |
| **电子产品** | 斜侧全貌 / 正面屏幕面 / 背面 / 接口特写 | 接口特写决定这张图能不能给结构工程师 |
| **家具 / 座椅** | 正 45° / 正侧 / 正前 / 底面或榫接细节 | 底面格给结构，家具最容易漏 |
| **雕塑 / 手办** | 正面 / 侧面 / 背面 / 细节特写 | 与人物同源，但**不压细节** |
| **鞋靴** | 外侧 45° / 正侧 / 顶部俯视 / 鞋底 | 鞋底是隐藏信息，做产品图必须给 |
| **武器 / 冷兵器** | 全貌 / 刃面特写 / 护手与柄 / 重心比例 | 刃面看研磨与开刃线 |

**通用规则**：**四格里必须有一格是"细节特写"或"非常规视角"**（顶部 / 底部 / 内部 / 接口）。
四个都是"斜侧 45°"的组合没有意义——它只证明模型会转圈，不提供任何新信息。

### 材质导致的光位调整（允许，但要说明）

默认沿用统一棚拍单硬 45° 主光。遇到下列材质可自动调光位与背景反差，**并在交付时一句话说明为什么**：

| 材质 | 问题 | 调整 |
|---|---|---|
| 透明玻璃 | 单硬光会把玻璃拍成"实体块" | 改逆光 + 深色背景勾边，让透光显出来 |
| 镜面金属 | 硬光会出死白高光斑 | 改大面积柔光 + 黑卡，保留渐变 |
| 深色绒面 | 会吸光成一团黑 | 加一盏低强度侧辅，只勾轮廓不压光比 |
| 白色陶瓷 | 会过曝丢细节 | 降 1 档曝光，背景改中灰 |

## 四、动物 / 生物分支

版式沿用人物（正面 / 侧面 / 背面 / 头部特写），但**规则相反的一处必须改**：

| 项 | 人物 | 动物 |
|---|---|---|
| 面部细节 | `BODY FRONT` 格**压低细节** | **完整保留**——五官与毛色就是主体信息 |
| 姿态 | 站姿，双臂垂于体侧 | 写清**四足落点**或 `sitting, tail curled to the left` |
| 毛发起伏 | 不强调 | 必须写 `fur direction, layered tufts`，否则糊成毡 |
| 视角 | 正面 / 侧面 / 背面 | 加一格**俯视或头部特写**（看头骨与耳位） |

## 五、一图多主体怎么办

| 情况 | 处理 |
|---|---|
| 画面里好几个完整主体 | 以**最大、最完整、最居中**的为准，其余当环境舍弃；**在回复里说明选了哪个** |
| 用户就要全部 | 拆成 N 条，每条一个主体，**不要拼进同一张图**（拼了就是平均分配权重，谁都不像） |
| 主体被遮挡一半 | 说明"只看到正面，侧面与背面均为推断" |

## 六、画幅口径（与 `image-types.md` 对齐，别混）

四视图的画幅不是随手写 16:9。**格子的形状由主体形状决定**：

| 布局 | 画幅 | 每格形状 | 适合 |
|---|---|---|---|
| **3 格横排**（三视图） | **16:9** | 竖向长方形 | 人物全身三视图 |
| **2×2 四格 · 含全身** | **9:16** 或 **4:5** | 竖长条 | 人物四视图、大衣、长袍（垂坠需要纵向空间） |
| **2×2 四格 · 横向主体** | **16:9** 或 **1:1** | 横向长方形 | 汽车、枪械、家具、电子产品 |
| **2×2 四格 · 通用** | **1:1** | 正方形 | 手办、鞋靴、箱包 |

**判定句**：**主体在画面里是"高"还是"宽"？** 高的用竖画幅，宽的用横画幅，说不清的用 1:1。

> 现有 B 族三视图用 16:9 是因为"3 格横排、每格竖长条"。四格 2×2 如果还用 16:9，每格会被压成横条，全身站姿必然裁脚。**这不是风格问题，是几何问题。**

## 七、共用硬规则（两分支都守）

这几条一旦破了，产物就不再是"参考底稿"，而是"重绘创作"。

1. **参考图是唯一设计源**：外形轮廓、结构、材质纹理、磨损痕迹、五金接缝，逐项复刻。
2. **NO redesign / NO style drift**：不美化、不改造型、不换风格；禁止 CG 感、插画、动漫、手绘、油画质感。
3. **四格共享同一棚拍环境与同一套光源**：光位、色温、曝光**完全一致**。不一致的设定表不能当参考用。
4. **无缝纯色背景**：无道具杂物、无戏剧轮廓光、无彩色溢光。
5. **唯一的文字是四格角落的英文视角标签**（`FACE FRONT` / `FACE SIDE` / `BODY FRONT` / `BACK`，物体换成 `FRONT` / `SIDE` / `BACK` / `DETAIL`），小号无衬线大写。**除此之外不要任何文字、logo、水印**。
6. **不出现畸形、破损、多肢、断面的结构**。

## 八、英文骨架（改主体段即可用）

```
Photorealistic 2x2 reference sheet of <主体精确描述>, on a seamless light-gray studio
background, four equal panels divided by thin gutters, each panel carrying a small clean
sans-serif capital label in its corner.
Lock strictly to reference image 1: <外形/结构/材质/纹理/磨损/五金 — 逐项列出>.
Top-left panel, label "<VIEW 1>": <该视角拍什么>.
Top-right panel, label "<VIEW 2>": <该视角拍什么>.
Bottom-left panel, label "<VIEW 3>": <该视角拍什么>.
Bottom-right panel, label "<VIEW 4>": <该视角拍什么>.
One hard key light from 45° front-left, neutral color temperature, even exposure and identical
white balance across all four panels, natural contact shadow on the floor only.
No text other than the four corner labels, no logo, no watermark, no props, no background clutter,
no color spill, no dramatic rim light, no beautification or skin smoothing, no illustration or
CGI look, no structural deformation, no missing or extra parts.
```

**四格各写一句，不要合并成"四个视角"**。合并了模型就自由发挥，四格常常变成三个角度加一个重复。

**中文平台写法**：把 `2x2 reference sheet` 换成 `一张 2×2 四格参考图，四格等大，细分割缝，每格角落小号英文标签`，其余逐项照写。

## 九、二改与止损

| 用户说 | 只改什么 |
|---|---|
| 换视角 | 只改那一格的 `label` 与描述，其余三格逐字复制 |
| 换背景 | 只改背景句，加一句 `背景变更不影响主体造型与光位` |
| 只重拍某一格 | **拆成单张出**，别整张重画（整张重画会连另外三格一起漂） |
| 改约束（加墨镜 / 去配饰） | 在 `Lock strictly to` 段里点名增删，其余不动 |

**止损纪律**：

1. **先判缺陷来源**。参考素材本身糊、缺角、遮挡——**换提示词救不回来**，如实告诉用户卡在哪。
2. **同一缺陷重做一次仍不解决，停下**。说明试过什么、还剩哪些办法，交用户决定。
3. 不要连续重画烧额度。
