# 角色美学六轴（书上的顺序）

> 依据：`Anatomy for Sculptors` 的"形状—节奏—块面—构造单元"、动画角色造型卷的"几何形概括→剪影→夸张→表情"、
> 《让画面会讲故事》的"动态线→基本形→体块→重心→剪影与负空间"。
>
> 这些书的共同顺序是：**先几何形，再剪影，再体块，最后才是五官。**
> 而多数人写提示词是反的——上来就写"凤眼、柳叶眉、唇珠"。**五官是结果，形状才是原因。**

---

## 零、为什么必须先定形状

同一个"凤眼 + 柳叶眉 + 鹅蛋脸"，配圆形身体的角色是温柔，配三角形身体的角色是阴狠。

**形状语言先于五官**：它决定观众在 0.5 秒内对这个人的判断（亲和 / 可靠 / 危险），五官只是把这个判断说清楚。

| 顺序 | 做法 | 结果 |
|---|---|---|
| ❌ 五官 → 身体 | 先写眼鼻唇，再拼身材 | 各部分都对，整体没性格 |
| ✅ 形状 → 剪影 → 体块 → 五官 | 先定主形，再验剪影，再分块，最后填五官 | 一眼认得出是谁 |

---

## 一、轴一：形状语言（Shape Language）

**三原形**：圆 / 方 / 三角。每个角色选**一个主形**，配一个副形做对比。

| 主形 | 性格暗示 | 提示词写法 |
|---|---|---|
| **圆** | 亲和、无害、柔软、孩子气 | `rounded forms dominate, soft curves, no sharp corners` |
| **方** | 可靠、厚重、力量、固执 | `blocky forms, strong horizontal shoulders, squared jaw` |
| **三角** | 危险、迅捷、狡诈、攻击性 | `angular forms, sharp tapering limbs, pointed silhouette` |

**写法公式**：

```
主形占 70% + 副形占 20%（做对比）+ 一处破形占 10%（做记忆点）
```

示例：

```
整体以圆形为主形（圆润肩线、圆柱四肢、圆头），肩部用一块方形护肩打断，
脚部收成一个锐三角。圆润中带一处硬边。
```

**三条铁律**

1. **一个角色只用一个主形**。圆 + 三角各占一半 = 没有性格。
2. **副形必须放在"关键部位"**（肩、手、脚、头饰），不能随便撒。
3. **破形只留一处**。处处不同 = 没有重点。

**常见错误**

| 错 | 为什么 |
|---|---|
| 只写"可爱/帅气/凶" | 这是评价，不是形状 |
| 全身都是圆 | 亲和到没有记忆点（等于吉祥物） |
| 圆脸 + 三角身体 + 方手 | 三个主形打架，观众读不出性格 |

## 二、轴二：剪影（Silhouette）

**测试法**：把图填成纯黑，还认得出是谁吗？认不出 = 造型失败。

**剪影靠三样东西**：轮廓的**独特性**、肢体间的**负空间**、关键部位的**凸起**。

| 要素 | 写法 |
|---|---|
| 可读剪影 | `readable silhouette, distinct outline even in black` |
| 负空间 | `clear negative space between the arms and the torso` |
| 关键凸起 | `distinctive silhouette break at the shoulder / hair / weapon` |
| 避免粘连 | `limbs separated from the body, no merged contours` |

**AI 高频崩点：手臂粘进躯干**。原因是没写负空间，模型把手臂和身体画成一整块。

修法三句（任选两）：

```
手臂与躯干之间留出可见空隙 / 一侧手臂离开身体 / 轮廓线不粘连
clear gap between arm and torso, no tangent lines
```

**切线（tangent）**：两个轮廓刚好相切，会让形体读不出来（手指贴着大腿、武器贴着背、头发贴着肩）。写 `no tangent lines where shapes meet`。

---

## 三、轴三：体块（Construction）

`Anatomy for Sculptors` 的核心方法：**把人体拆成圆柱、方块、球体，再逐步过渡到真实解剖**。

| 部位 | 体块 |
|---|---|
| 头 | 球 + 楔形下颌 |
| 颈 | 圆柱（略前倾） |
| 胸廓 | 蛋形/箱形（上宽下窄） |
| 骨盆 | 倒梯形箱体 |
| 上臂/前臂 | 两个渐细圆柱（中间肘部为铰链） |
| 大腿/小腿 | 两个渐细圆柱（膝为方形块） |
| 手 | 方块掌 + 五个小圆柱 |
| 足 | 楔形 |

**为什么对提示词有用**：写体块词，模型会给你"结构清楚"的图；写解剖细节词，模型给你"糊成一团"的图。

```
structured volumes: spherical head, cylindrical neck, egg-shaped ribcage,
inverted trapezoid pelvis, tapered cylindrical limbs
```

**和 3D 动漫的接点**：3D 动漫要的就是"块面清楚"——`planar facial structure` / `clean silhouette` / `simplified geometric anatomy` 都是体块思路的延伸。

---

## 四、轴四：动态线与重心（Line of Action / Balance）

**动态线**：一条从头顶贯穿到承重脚的弧线。没有它，人物是"立牌"。

| 写法 | 效果 |
|---|---|
| `single flowing line of action from head to supporting foot` | 姿态有势 |
| `weight on the right leg, hip tilted, left knee relaxed` | 对立式平衡（contrapposto） |
| `shoulder line and hip line tilt in opposite directions` | 身体有扭转 |
| `center of gravity over the supporting foot` | 站得住 |

**重心三条**

1. 承重脚必须写（不写就两只脚都虚）
2. 骨盆倾斜方向要写（决定腰线）
3. 肩线与髋线**反向倾斜**（这是"松弛感"的来源）

**错法**：写"自然站立"——模型给你一个僵直站姿。要写"重心在右腿、左膝微屈、骨盆右高左低"。

---

## 五、轴五：比例节奏（三分法 / 三庭五眼）

| 规则 | 数值 | 写法 |
|---|---|---|
| 头身比 | 写实 7.5–8 / 半写实 7 / 动漫 6.5–7 / Q 版 3–4 | `7-head proportion` |
| 三庭 | 发际→眉 / 眉→鼻底 / 鼻底→下巴，各 1/3 | `three equal facial thirds` |
| 五眼 | 脸宽 = 5 个眼宽 | `face width equals five eye-widths` |
| 肩宽 | 男 ≈ 2 头宽 / 女 ≈ 1.6 头宽 | `shoulder width 1.6 head-widths` |
| 上下身 | 会阴为界，约 1:1（腿长型 0.9:1.1） | `leg length 52% of body height` |
| 手臂 | 指尖到大腿中段 | `fingertips reach mid-thigh` |

**"三分法"的第二个意思**（动画角色造型卷）：**同一角色的三个部位用三种不同比例处理**，避免全身一个节奏。比如：头偏大、手偏大、腿偏细——有节奏才有风格。

---

## 六、轴六：夸张（一处原则）

**核心**：夸张只放在一个地方，其余全部收敛。

| 档 | 夸张幅度 | 适用 |
|---|---|---|
| R1 写实 | 几乎不夸张，靠骨相区分 | 写实、剧集 |
| R2 风格化 | 一处夸张 20–30%（头/手/肩/眼四选一） | 3D 动漫、游戏 |
| R3 卡通 | 一处夸张 50%+（大头、大手、长腿） | Q 版、潮玩 |

**写法**：

```
仅夸张头部（头身比 3.5），其余部位保持写实比例；手与脚不夸张。
```

**三条铁律**

1. 一处夸张 + 其余写实（"每处都夸张"= 没有重点，且比例必崩）
2. 夸张要说明**夸张什么、夸张多少**
3. 夸张方向要与性格一致：圆头=可爱，方肩=可靠，长腿=优雅，大手=力量

**常见错误**：写"头大、手大、腿长、肩宽"——四个都放大，等于没放大，而且模型会把比例彻底搞乱。

---

## 七、负空间与切线（AI 出图的重灾区）

这一节单独拎出来，因为它是"图看起来对但用不了"的头号原因。

| 问题 | 表现 | 提示词修法 |
|---|---|---|
| 手臂粘躯干 | 手臂轮廓与身体连成一片 | `clear gap between arm and torso` |
| 手指粘大腿 | 手放腿上时糊成一块 | `hand resting on the thigh with visible separation` |
| 武器贴背 | 刀剑与背线重合 | `weapon offset from the back, visible gap` |
| 头发贴肩 | 发型吃掉肩线 | `hair falling in front of the shoulder, distinct edge` |
| 双腿并死 | 两腿间无缝隙 | `slight gap between the legs, weight on one leg` |

**统一句**（全身图建议常备）：

```
轮廓清晰，肢体之间留出可见空隙，无相切轮廓
clean silhouette with visible negative space, no tangent contours
```

## 八、视觉重量与明暗结构

| 概念 | 写法 | 作用 |
|---|---|---|
| 主体最亮或最暗 | `subject holds the highest contrast in frame` | 观众先看主体 |
| 背景中间调 | `background kept in mid-tones, low contrast` | 不抢戏 |
| 视觉重量平衡 | `large dark mass on the left balanced by a small bright accent on the right` | 画面不歪 |
| 明暗三段 | `three value groups: highlight, mid, shadow` | 结构清楚 |

**这条对"高级感"的贡献远大于画质词**：主体对比最高 + 背景压平 = 天然的高级。

## 九、六轴组合示例

### A｜圆润治愈（奶凶小法师）

```
主形：圆形为主（圆肩、圆柱四肢、圆头），副形：脚部一个锐三角
剪影：头大、袖口外扩，轮廓像一颗水滴
体块：球头 + 蛋形胸廓 + 短圆柱四肢
动态线：微微前倾，重心在左脚
比例：4.5 头身，手偏大（R3 夸张仅在手）
色彩：奶白 + 浅杏 + 一点雾蓝
```

### B｜锐利刺客

```
主形：三角形为主（尖肩、锥形袖、窄腰），副形：方形腰带
剪影：上宽下窄，四肢细长，武器形成第二重心
体块：楔形躯干 + 细圆柱四肢 + 方形护腕
动态线：S 形，重心前移，后脚跟离地
比例：7.5 头身，腿长 55%
色彩：墨黑 + 冷灰 + 一点朱红
```

### C｜厚重守卫

```
主形：方形为主（方肩、箱形躯干、方靴），副形：圆形头盔
剪影：横向体积大，头盔形成顶部圆
体块：箱形胸廓 + 方形骨盆 + 粗圆柱四肢 + 方块手
动态线：近乎垂直，重心下沉，双脚与肩宽
比例：7 头身但肩宽 2 头宽，手偏大
色彩：铁灰 + 暗铜 + 磨损亮边
```

## 十、反例清单（写完自查）

- ❌ 只写"可爱/帅气/有气势"，没有形状词
- ❌ 三个主形混用（圆脸 + 三角身 + 方手）
- ❌ 剪影测试不过（填黑后认不出）
- ❌ 手臂与躯干无负空间（必粘连）
- ❌ 写"自然站立"而非具体重心
- ❌ 多处同时夸张（头大手大肩宽腿长）
- ❌ 只写五官细节，没有体块
- ❌ 主体与背景对比相同（画面平）

---

## 十一、八项自检

- [ ] 定了主形（圆/方/三角），且只定一个
- [ ] 有一个副形做对比，且落在关键部位
- [ ] 剪影测试能过（填黑可辨）
- [ ] 写了负空间/无切线
- [ ] 有动态线 + 承重脚 + 骨盆倾斜
- [ ] 比例给了数字（头身比 + 肩宽 + 腿长）
- [ ] 夸张只在一处，且说明幅度
- [ ] 主体对比高于背景
