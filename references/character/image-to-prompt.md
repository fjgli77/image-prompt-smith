# 图 → 词：反推提示词

> 用户丢来一张图说"照这个画""这图怎么生成的""给我这条提示词"。
> 你要做的是**重建一条能再生成相似图的提示词**——不是原作者的原始 prompt（那在图里不存在）。

---

## 零、先把边界说清（三句话，交付时带上）

1. **反推得到的是"能复现效果的词"，不是"原始 prompt"。** 相似度通常 80–95%，不会一字不差。
2. **图里没有的信息，反推不出来**：用的是哪个模型、什么种子、有没有后期、作者是谁。
3. **后期痕迹会被当成"画面内容"**：调色、拼贴、排版、放大都会留下"从未被生成过"的细节。

> 对用户只说一句：「这是重建版，能出相近效果，不是原作者那条。」

---

## 零·五、反推三把锁（借自扒剧引擎的逆向纪律）

> 这三条来自 `short-drama-teardown`（扒剧引擎 V3.1）的「裸视频防乱人三把锁」。
> 它原本治的是"一部剧被拆成五个人、台词安错人"，改到反推上，治的是**同一件事：把不确定的东西说成确定的**。

### 锁一 · 同人归并：一个角色只能有一个身份

**铁律**：同一张脸 + 同一套主体服装，即使出现下列变化，**也是同一个人，严禁拆成两个角色**：

| 变化 | 反例（错） | 正例（对） |
|---|---|---|
| 瞳色/发光 | 拆成「黑衣女」和「金瞳女」 | 同一角色 + `施法时瞳色转为金色` |
| 特效/形态 | 拆成「狐女」和「九尾真身」 | 同一角色 + `对敌时身后展开九条尾` |
| 战损/妆造 | 拆成「白衣女」和「血衣女」 | 同一角色 + `吐血后衣襟染红、披发` |
| 换角度/裁切 | 拆成「正面女」和「侧影女」 | 同一角色，只是视角不同 |

**多图反推时尤其重要**：用户发 5 张同一角色（不同角度/状态/服装），你要归并成 **1 个角色 + 5 个状态**，不能给 5 条各自独立的人物设定。

**检查法**：反推稿里出现了几个"人物名"？如果人物名数量 > 用户说的人数，就是拆人了。

### 锁二 · 唯一代号：一次命名，全篇不改

**铁律**：反推开始就给这个角色定一个**唯一代号**，之后所有描述都用它，**禁止混用外貌代称**。

| 错（同一人三个叫法） | 对 |
|---|---|
| 开头「黑衣女子」，中段「金眼女子」，结尾「狐族少女」 | 全程 `玄青战袍女（金瞳形态）` |

**代号写法**：`主色/主件 + 性别`（如「玄青战袍女」「褐衣随从男」「黑皮衣寸头男」），够辨识即可，不必编名字。

**为什么重要**：混用代称时，模型会把它们当不同人，一致性直接崩。

### 锁三 · 逐项 1:1 绑画面：每条描述都要指得到位置

**铁律**：**每一条写进提示词的描述，必须能在图上指出具体位置。指不到的，删掉或标为推断。**

| 描述 | 能不能绑 | 处理 |
|---|---|---|
| 「左侧 45° 侧逆光，发丝边缘发亮」 | ✅ 能指到头发边缘 | 保留 |
| 「她性格冷峻」 | ❌ 图上无法指认 | 改写成可见证据：`嘴角平直、眼下无笑纹、眼神直视` |
| 「背景是一座古城」 | ⚠️ 只能看到一角墙 | 写 `背景为石墙一角，其余虚化`，不要扩写成"古城" |
| 「她左手握剑」 | ❌ 左手在画外 | 删掉，或标 `推断：左手持物（画外）` |

**自检法**：反推稿逐句问「这句在图上哪儿？」——答不出来的句子，就是幻觉。

> 原版的反例很典型：因为每 15 秒才抽一帧，把逃跑反派的狠话安到了早钻进地洞的配角头上。
> 换到图上就是：**图里看不到的部分，你替它编了。**

## 一、先修图，再反推（最容易被跳过的一步）

**模型看到什么，就会写什么。** 图上有水印、边框、UI、平台 logo，反推结果里就会出现 `watermark, text, frame`，然后生成时被忠实复刻。

| 先做 | 为什么 |
|---|---|
| 裁到主体与关键背景 | 去掉平台边框、聊天截图边 |
| 去掉水印 / 作者签名 / 字幕 | 否则会进正向词 |
| 模糊处不要硬猜 | 糊的细节反推出来也是错的 |
| 多主体图先确定主次 | 否则平均分配权重，谁都不像 |

## 二、两遍法（核心方法）

### Pass 1｜事实盘点（只写看得见的）

按十项清点，**当 checklist 用，不要当描述用**：

| # | 项 | 要写什么 | 高频错 |
|---|---|---|---|
| 1 | 主体 | 是什么、**几个**、什么姿态 | **数错数量**（模型最容易错这项） |
| 2 | 构图 | 取景（特写/半身/全身）、机位高度、主体位置、留白在哪侧 | 只写"居中" |
| 3 | 镜头感 | 广角/标准/长焦、景深浅深、有无畸变 | 凭感觉写"电影感" |
| 4 | 环境 | 场所、时间、天气、道具 | 脑补画面外的故事 |
| 5 | 光 | 方向、硬/软、光比、色温、有无实用光源 | 只写"柔和光线" |
| 6 | 色彩 | 主色、强调色、饱和度、对比 | 写"色彩丰富" |
| 7 | 材质 | 每种表面怎么吃光（哑光/镜面/透光/绒感） | 只写材料名 |
| 8 | 文字 | 逐字照录，标出位置 | 编造看不清的字 |
| 9 | 风格 | **只有图上有证据才写**（笔触/网点/描边/颗粒） | 硬套"吉卜力/赛博" |
| 10 | 媒介 | 照片 / 3D 渲染 / 2D 手绘 / 版画 / 拼贴 | 混着写 |

**两条轨分开盘（别混着看）**：

| 轨 | 盘什么 | 注意 |
|---|---|---|
| **视觉轨** | 主体/构图/光/色/材质/镜头 | 只写看得见的形状与光影 |
| **文字轨** | 图内文字、招牌、水印、UI、字幕 | **逐字照录**；看不清就写「不可辨」，不要猜 |

> 文字轨是反推里最容易被忽略、又最容易污染结果的一条：把水印当内容写进正向，生成时会被复刻。

**三条禁令**：不虚构镜头型号｜不虚构艺术家或工作室｜不虚构品牌与文字。

### Pass 2｜工艺层（description 与 prompt 的分界）

事实盘点只是"图里有什么"，工艺层回答"怎么拍的"：

| 六问 | 落到什么词 |
|---|---|
| 机位在哪？平视 / 略俯 / 仰拍 | `略俯 15°` |
| 景深多浅？ | `f/1.8 浅景深` / `f/8 全景深` |
| 光硬还是软？方向？ | `90° 硬侧光` / `大面积柔光` |
| 光比多大？暗部还有细节吗？ | `光比 1:6，暗部保留细节` |
| 材质怎么吃光？ | `磨砂玻璃内部散射` / `金属拉丝高光带` |
| 色温多少？冷暖怎么对撞？ | `4200K 冷调 + 一点暖色实用光` |

**这一步是自动反推工具跳过的地方**，也是"像不像"的关键。

## 三、输出结构：核心 + 适配器

**先写平台无关的 Brief**，再套平台语法（Adapter）。换平台只换外壳。详见 `cross-model.md`。

```
【核心】形状/介质 + 主体 + 服装 + 关键部位 + 动作场景 + 光 + 镜头 + 构图 + 色材
【适配器】按平台改：语言 / 语序 / 权重 / 反向 / 参数
```

**默认交付两条**（覆盖 90% 模型）：中文核心版 + 英文版；再附 3 行适配说明。

| 去向 | 适配要点 |
|---|---|
| 中文平台（即梦/豆包/Seedream/万相/可灵） | 中文自然语言，主语在前，逐项写清；删掉英文参数 |
| Midjourney | 压到 60 词内，短句 + `--ar` + `--style raw` + `--no` |
| SDXL / ComfyUI | 英文标签 + 权重 + 独立 negative |
| Flux / Ideogram | 英文完整句；**多数 Flux 实现无负向**，改正面禁令 |
| Nano Banana / GPT Image / Imagen | 英文结构化长句，可分段；支持参考图时优先"图 + 文字指令" |

完整 20 个模型的方言、六旋钮对照、兼容性分级（哪些词 90% 通用、哪些全废）见 `cross-model.md`。

## 四、确定性标注（防幻觉）

交付时把三项分开写（对应三把锁的第三锁）：

```
可见：主体、构图、光位、色温、画幅
可推：焦段（按透视推）、材质（按反光推）、风格流派（有证据才推）
不可知：模型、种子、是否后期、作者、画外空间
```

**宁可写「可推：约 50mm」，也不要写死「50mm」。**

**缺口预警**（对应原版的"时间断层预警"）：图上哪块看不见，就明写出来——

```
缺口：手在画外（未画）；左侧脸被头发遮住；背景只露一角墙
```

**不许用编造填补缺口**。这是反推与"瞎写一段漂亮话"的唯一区别。

## 五、五步流程 + 迭代环

```
① 修图 → ② 事实盘点（数清数量）→ ③ 补工艺层 → ④ 套平台语法 → ⑤ 出词
```

出图后如果不像，**不要整条重写**，问"哪一层差得最多"：

```
参考图 → 重建词 → 生成 → 对比 → 找最大差异层 → 只改那一层 → 再生成
差异层：主体 / 姿势 / 构图 / 机位 / 光 / 色 / 景深 / 风格
```

| 差在哪 | 只改什么 |
|---|---|
| 姿势不对 | 只改动作句：`侧身三分之四，左肩靠近镜头，回头看向镜头` |
| 构图不对 | 只改构图句：`半身取景，主体略偏右，左侧大面积负空间` |
| 光不对 | 只改光句：`后方主轮廓光，前方弱暖补光，背景压暗` |
| 太"AI 味" | 删风格形容词，换具体物理属性：`自然皮肤纹理 + 可控影棚对比 + 轻胶片颗粒` |

## 六、顺手判图型（反推也要判）

| 图上看到 | 图型 | 反推时要补的规格 |
|---|---|---|
| 单一头肩，方形 | 头像 | 1:1、85mm、纯色底 |
| 半身，3:4 | 半身写真 | 3:4、85mm、浅景深 |
| 全身，留白多 | 立绘 | 2:3、50mm、写重心 |
| 一格多角度 | 多视图 | 16:9、格数、正交、平光 |
| 有多块分区 + 文字 | 档案页 | 2:3、分区、文字后期 |
| 大场景人物很小 | 概念图 | 16:9、24–35mm、环境光 |

**图上有多格却没写格数**，反推出来的词会继续多格——记得补"仅此 N 格"。

---

## 七、五种失效场景（先说清，别硬吹）

| 场景 | 为什么失效 | 怎么处理 |
|---|---|---|
| 有后期调色/合成 | 反推的是"成品"，不是"生成过程" | 说明"后期痕迹无法用词复现" |
| 多张拼贴 | 词会被平均分配 | 拆成多张分别反推 |
| 图内有大段文字 | 文字是后期加的 | 反推画面，文字另做 |
| 极简图（纯色/单物体） | 信息太少，反推不出确定词 | 只给 3–5 个核心词，别硬凑 |
| 风格无证据 | 硬套流派名会跑偏 | 只写可见的笔触/颗粒/描边 |

## 八、完整示例

**输入**：一张赛博雨夜里的机械少女特写（半身，霓虹，湿反光）

### Pass 1 事实盘点

```
主体：1 名年轻女性，机械义肢左臂，半身，正面略侧，视线看向镜头外
构图：半身取景，主体略偏右，左侧大面积霓虹虚化背景
镜头感：中长焦、浅景深、无广角畸变
环境：雨夜街道，霓虹招牌，湿地面反射，背景行人虚化
光：右侧霓虹青紫为主光，左侧弱暖色补光，暗部偏蓝
色彩：青紫 + 品红，低明度、高对比
材质：金属义肢哑光+局部镀铬、湿发、皮革外套、雨水反光
文字：招牌上有模糊字符，不可辨
风格：写实摄影质感，轻微颗粒
媒介：照片（或照片级渲染）
```

### Pass 2 工艺层

```
机位：平视略仰 5°
景深：f/2 浅景深，背景奶油化
光：90° 侧光硬化 + 霓虹溢色，光比 1:6，暗部保留细节
材质：镀铬件高光锐利、皮革哑光、皮肤有雨水薄光
色温：9000K 冷调 + 后方 3200K 暖色点缀
```

### 输出（中文平台）

```
写实电影感半身特写。一名二十多岁女性，左臂为机械义肢（哑光金属 + 局部镀铬），
黑色皮革外套领口立起，湿发贴在颊侧；她正面略侧，视线看向画外右侧。
雨夜街道，背景是青紫霓虹招牌与虚化的行人，湿地面反射霓虹。
右侧 90° 霓虹青紫主光，左侧一点 3200K 暖色补光，光比 1:6，9000K 冷调，
暗部保留细节；85mm f/2 浅景深，平视略仰 5°，主体偏右，左侧留出霓虹虚化负空间。
青紫 + 品红为主，低明度高对比，轻微胶片颗粒。3:4，画面中不出现任何可读文字。
```

> **为什么它保留"不出现文字"，而上面的文字轨要求"逐字照录"？**
> 两者不在同一轨上：**文字轨是分析产物，交付词是生成指令。** 详见下面的分轨规则。

### 图内文字：两条轨，别混

| 轨 | 用途 | 怎么处理图里的字 |
|---|---|---|
| **分析轨**（Pass 1 事实盘点） | 搞清图上到底有什么 | **逐字照录**；看不清写「不可辨」，绝不猜 |
| **生成轨**（交付的提示词） | 让模型再画一遍 | **默认禁文字**；确需文字时见下面三档 |

**生成轨的三档策略**（按载体选，不要一律禁）：

| 载体 | 策略 | 写法 |
|---|---|---|
| 纯立绘 / 头像 / 场景图 | **禁文字** | `画面中不出现任何可读文字、水印、标识` |
| 角色设定稿 / 档案页（本该有姓名、种族、视图标注） | **禁 AI 文字 + 后期叠字**（推荐） | 提示词写 `留出上下标题区，画面本身不含文字`，排版在 PS/即时设计里做 |
| 海报 / 封面（文字就是主体） | **赌真文字** | 用引号写死文案 + 字号层级；文案短的胜率高，长的必崩 |

**判定一句话**：**字是"要被复刻的内容"还是"要被排上去的标签"？** 前者进分析轨，后者进后期，几乎只有海报才让 AI 真写。

### 输出（MJ 版）

```
cinematic half-body portrait, a young woman with a mechanical left arm
(matte metal, chrome accents), black leather jacket, wet hair, rainy neon street,
cyan-magenta neon key light from the right at 90 degrees, faint 3200K warm fill from left,
1:6 lighting ratio, 9000K, dark shadows with detail, 85mm f/2 shallow depth of field,
subject right of center, neon bokeh negative space on the left, subtle grain
--ar 3:4 --style raw --no text, watermark, logo, extra limbs
```

**交付附注**：

```
确定：主体/构图/光位/色温/画幅
推断：85mm（按透视）、f/2（按背景虚化）
不知：模型、种子、是否后期
```

## 九、八项自检

- [ ] 先裁剪去水印了吗
- [ ] 数量数对了吗（人/手/道具）
- [ ] 光写了方向 + 硬软 + 光比 + 色温
- [ ] 镜头写了焦段感 + 景深
- [ ] 有没有虚构镜头型号/艺术家/品牌
- [ ] 风格词有图上证据吗
- [ ] 多格图补了格数与封顶吗
- [ ] 交付时标了「可见 / 可推 / 不可知」吗
- [ ] **人物名数量 = 实际人数**（多图反推没拆人）
- [ ] **代号唯一**（没有「黑衣女/金眼女」混用）
- [ ] **每条描述都能在图上指到位置**（指不到的删了或标推断）
- [ ] **缺口写出来了**（手在画外/脸被遮/背景只露一角）

## 十、版权与用途红线

反推他人作品时，交付首行加一句：

> 拆解学习用途 · 可迁移的是结构、光位与镜头语言；不复刻具体角色。

| 可以 | 不建议 |
|---|---|
| 学它的光位、构图、配色关系 | 复刻同一个角色形象做商用 |
| 把参数结构迁移到自己的原创角色 | 用反推词生成"几乎同款"的成品投放 |
| 拆风格、拆镜头、拆材质 | 拆品牌标识、拆有版权的角色设计 |

**一句话**：反推的价值是"学会怎么拍"，不是"拿到别人的角色"。
