## 一、搭配的底层逻辑（写提示词前先想清这四件）

### 1. 先定人设，再谈搭配（顺序错了必翻车）

还没想清角色是什么性格就开始堆衣服，是搭配失败的头号原因。先回答：

- 活泼还是高冷？战士还是法师？古代、现代还是幻想世界？
- **性格 → 服饰大方向**：
  - 高冷系 → 深色、剪裁利落、线条极简
  - 活泼系 → 亮色、层叠设计、俏皮小配饰
  - 神秘系 → 斗篷、长袍等遮掩感强的单品
  - 力量系 → 肩甲、腰带、厚重靴

### 2. 三色原则（面积配比）

**全身颜色不超过三种**，按面积分配：

| 角色 | 占比 | 出现在哪 | 色例 |
|---|---|---|---|
| **主色** | 60%–70% | 外套、长裙、裤子（大面积件） | 黑/白/米/灰/藏青/驼 |
| **辅助色** | 20%–30% | 内搭、上衣、半身裙 | 与主色同色系深浅，或柔和对比色 |
| **点缀色** | 5%–10% | 丝巾、包、鞋、腰带、首饰 | 亮红/宝蓝/翡翠绿/金属色 |

> **误区**：① 黑白配不算"无彩色"，仍占两色；② LOGO 印花的底色和字色都要算；③ 配饰虽小，但鞋包丝巾的色块面积足以破坏整体，必须收在点缀色里。

### 3. 三种配色公式（新手到进阶）

| 公式 | 做法 | 效果 | 例 |
|---|---|---|---|
| **同类色**（最稳） | 同色相深浅变化 | 和谐、显高、高级 | 浅灰毛衣 + 深灰裤 + 白鞋 |
| **邻近色** | 色环相隔 30–60° | 有层次但不夸张 | 牛油果绿衬衫 + 米色裙 |
| **对比色**（进阶） | 色环相对，**小面积用** | 吸睛不翻车 | 黑衣 + 橙色靴 |

> **万能公式**：`基础色打底 + 一个亮色提亮`。全身黑白灰容易闷，加一双红鞋/一条黄围巾就活了。

### 4. 轮廓要有对比 + 材质要混搭

- **轮廓**：上宽下紧，或上紧下宽。全身宽大 = 臃肿；全身紧身 = 没变化。
- **腰线**：想显腿长就把腰线提高（腰带系高）；
- **材质**：软布衣配硬皮护具、乖巧裙装配做旧皮靴——**材质反差让角色立体**。

**材质词汇表**：`leather 皮革 / silk 丝绸 / linen 亚麻 / wool 羊毛 / denim 牛仔 / knit 针织 / cotton 棉 / metal 金属 / brass 黄铜 / glass 玻璃 / plastic 塑料 / velvet 天鹅绒 / lace 蕾丝 / mesh 网纱 / fur 皮草`

## 二、A · 服装拆解图（环绕式）

**长什么样**：中心是角色全身立绘，四周环绕拆下来的服装单品、表情、材质特写。用引导线把单品连到身上对应部位。

> 这是"像素级拆解"的做法——透视角色的**穿着层级**。

### 版式规范

```
【中心位】角色全身立绘（或主要动态姿势），作为视觉锚点。
【环绕位】四周空白处排列拆解元素，用手绘箭头/引导线连到对应部位。
【拆解内容】
  · 服装分层：外套、内搭、下装、鞋靴逐件拆出（多层穿搭要展示脱下外套后的内层）
  · 内着拆解：独立展示内层衣物，突出设计感与材质
  · 表情集：角落 3–4 个头部特写
  · 材质特写：1–2 个关键部位放大
  · 物品质感特写：小物件的材质
  · 关联物品：随身包袋（可"打开"展示内容物）、饰品、道具
【风格】高质量 2D 插画或概念设计草图风，线条干净利落
【背景】米黄色 / 羊皮纸 / 浅灰纹理，营造设计手稿氛围
【文字】每个拆解元素旁手写体注释（装饰性占位文字）
```

### 完整提示词

```
角色服装拆解设定图，character outfit breakdown sheet：
中心为角色全身动态立绘，四周有序环绕拆解元素，用细引导线连接到对应部位。
拆解内容：
① 服装分层——外套、内搭、内层衣物、下装、鞋靴逐件单独展示；
② 情绪头像 3–4 个，置于角落；
③ 关键部位材质放大特写 2 处；
④ 随身包袋（可打开呈现内容物）、首饰、饰品、道具；
⑤ 每件单品旁标注材质说明（装饰性手写体注释）。
【外貌锚点：<逐字复制>】
【服装：<逐件写清，如 深红皮革长风衣/米色高领针织内搭/棕色皮质腰带/同色系短靴，共用银色金属扣件>】
【人物风格：<从 character-styles.md 抄>】
【渲染介质：<从 render-styles.md 抄>】
背景：米黄色羊皮纸纹理，设计手稿氛围，线条干净利落。
光照：柔和均匀，塑造材质但不过曝。
画质：8K，透视准确，注释清晰，版式像高级概念设计稿。
```

## 三、B · 单品平铺图（Coordinated Outfit Flat Lay）

**长什么样**：**没有人**，只有一套搭配的各个部件，按穿着位置上下排列。

> **铁律**：这描述的是**一套搭配**，不是多套备选。不要把法师袍、骑士甲、盗贼装混在一张里——会互相污染。

### 排列规则

| 部件 | 位置 | 检查点 |
|---|---|---|
| 头饰 | 最上 | 完整，不遮住领口 |
| 上装 | 中上 | 与下装无重叠、无替代设计 |
| 下装 | 中下 | 与上装呼应 |
|  footwear | 最下 | 左右分开，成对，轮廓完整 |

- **留可见间隙，不重叠**——每件都要能独立读清
- **共用设计语言**：同色系 + 共同金属件 + 重复扣件，把整套串起来（不要求颜色完全相同）
- 不要模特、不要身体、不要第二套

### 完整提示词

```
服装搭配单品平铺图，coordinated outfit flat lay / clothing item breakdown：
一套完整搭配的单品，按穿着位置自上而下排列，无人物、无身体：
头饰在上、上装居中偏上、下装居中偏下、鞋靴在下、左右分开；
每件单品完整独立、互不重叠、留清晰间隙，轮廓完整可读。
【整套设计规则】<共用色系 + 共同材质 + 重复扣件，如 深红羊毛+棕色皮革+统一银色金属扣件>
【单品清单】<逐件列，如 深红长款羊毛风衣 / 米色高领针织衫 / 棕色皮质宽腰带 / 深棕直筒长裤 / 同色系皮质短靴>
【人物风格：<从 character-styles.md 抄>】
【渲染介质：<从 render-styles.md 抄>】
背景：纯白或浅灰，高级产品图布光，干净留白。
光照：柔和均匀产品光。
画质：8K，版式整齐，像服装品牌的产品规格图。
```

## 四、C · 穿搭方案图（同角色 × 多套搭配）

**长什么样**：同一个角色，横向列出多套不同搭配。**换装系统 / 剧情造型 / 周边企划**用这个。

### 三种组织方式

| 方式 | 排布 | 适合 |
|---|---|---|
| **横向换装** | 同一角色 × 4 套，横排 | 换装系统、季节造型 |
| **场景穿搭矩阵** | 按场合分行：日常 / 战斗 / 正式 / 居家 | 剧情、乙女向 |
| **套装进化** | 同一套的等级递进（布衣→皮甲→板甲），剪影逐级变强 | RPG 装备线 |

### 完整提示词（横向换装）

```
角色换装设定图，character outfit lineup / wardrobe sheet：
同一角色横向排列 4 套不同搭配，同一中性站姿、同一比例尺、同一光照、脚底对齐；
保持同一脸型、发型、瞳色、身形完全不变，只更换服装。
套装 1 日常装：<描述>
套装 2 战斗装：<描述>
套装 3 正装：<描述>
套装 4 居家装：<描述>
每套上方标注名称（装饰性占位文字），每套单一配色不超过三色。
【外貌锚点：<逐字复制>】

```

> **配色三选一，写进提示词**：
> - 同色系：`monochromatic palette, tonal variation of a single hue`（最稳、最高级）
> - 邻近色：`analogous color scheme, adjacent hues on color wheel`
> - 对比色：`complementary accent, one dominant color with a small contrasting accent`

## 六、换装分层规范（做"换装预览"时的图层规则）

如果要出**可叠加的换装素材**（身体+多套衣服），必须守这套规则，否则永远对不齐：

1. **统一中心基准**：身体、上装、下装、鞋放**同一画布**，以**脚底或角色中心线**为定位参照。
2. **按遮挡关系排序**（自下而上）：身体 → 后衣片/裤装 → 前衣片 → 围巾 → 手持物 → 发饰。
3. **保留阴影归属**：衣服褶皱阴影归对应服装组；角色共有投影单独设"光影层"，防换衣时残留阴影。
4. **颜色与材质分层**：纯色可加覆盖层；布料纹理、金属装饰、高光分开保存（改色不动轮廓）。
5. **导出预览**：每套至少存一张完整预览，检查领口/袖口/腰线/鞋底/头发遮挡处有无断线、白边、透明缺口。
6. **统一命名与画布尺寸**：单次拆图成功≠后续能组合；命名+尺寸+锚点三者必须规范。

**常见失败与修正**：

| 问题 | 原因 | 修法 |
|---|---|---|
| 衣服边缘有白边 | 选区过大带入背景 | 收缩选区 + 蒙版软边修整 |
| 换衣后位置不一致 | 画布或基准点不同 | 统一画布尺寸，按脚底/中心线对齐 |
| 关闭衣服后身体有空洞 | 遮挡区原本无身体像素 | 用同角色可见区补绘 |
| 头发/手臂/饰品穿插 | 图层顺序错 | 按遮挡关系重排上下层 |

## 七、服装描述的写法（决定模型能不能画对）

| ❌ 别写 | ✅ 要写 |
|---|---|
| 漂亮的裙子 | 及膝百褶裙，腰部皮质束带，前开扣 |
| 蓝色外套 | 深藏青羊毛外套，哑光表面，阴影中偏灰蓝，银色金属扣件，不带青绿偏色 |
| 帅气的装备 | 皮质胸甲 + 肩甲，铆钉装饰，磨损边缘 |
| 一整套衣服 | 逐件列：外套 / 内搭 / 下装 / 腰带 / 鞋 / 配饰，各写清颜色+材质+结构 |

**服装描述四要素**：**部件名 + 颜色 + 材质 + 结构细节**（闭合方式、层次、装饰）。
