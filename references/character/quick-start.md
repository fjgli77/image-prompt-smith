# 一句话 → 一条提示词（主路径）

> 这是本 skill 的**默认工作方式**。
> 用户丢来一句「画个穿黑风衣的冷面女杀手」，你就回一条能直接粘贴出图的提示词。
> **如果用户发的是图**（「照这个画」）→ 不走这条，走 `image-to-prompt.md`。
> **不追问、不落文件、不列大纲。** 深度内容（资产图/建模/特效/多视图）按需再展开。

---

## 一、五步走（30 秒内完成；描述太薄才多一轮）

```
① 拆句 → ② 判密度 → ③ 补全/提问 → ④ 拼装 → ⑤ 交付
```

### ① 拆句：只提取四样

| 提取 | 用户可能说的 | 落到哪个参数 |
|---|---|---|
| **谁** | 少女 / 大叔 / 女杀手 / 精灵 / 机器人 | 主体 + 年龄段 + 身份 |
| **穿什么** | 黑风衣 / 校服 / 铠甲 / 白裙 | 服装主件 + 主色 |
| **什么气质** | 冷、酷、温柔、清冷、御姐、凶、可爱 | **形状语言 + 风格 + 光** |
| **干什么用** | 头像 / 立绘 / 海报 / 小说封面（可缺） | 画幅 + 景别 |

**只提这四样。** 用户没说的，先看下方密度判定：够就默认补，不够才问。

#### ①.5 先认图型（决定画幅与景别）

| 用户说 | 图型 | 画幅 | 景别/焦段 |
|---|---|---|---|
| 头像 | 头像 | 1:1 | 胸像 / 85mm f/2 |
| 半身、写真 | 半身 | 3:4 | 中近景 / 85mm f/1.8 |
| 立绘、全身 | 立绘 | 2:3 | 全身 / 50mm f/4 |
| 三视图、转面 | 多视图 | 16:9 | 多格全身 / 平光 |
| 表情包 | 表情集 | 1:1 九宫 | 头肩 / 平光 |
| 档案、设定页 | 档案页 | 2:3 | 混合 |
| 封面 | 封面 | 2:3 | 半身 / 戏剧光 |
| KV、宣传图 | KV | 16:9 | 中景 / 戏剧光 + 特效 |
| 小红书封面 | 社媒 | 3:4 | 半身 |
| Q 版、潮玩 | Q 版 | 1:1 | 全身 3.5 头 |
| 给建模 | 正交图 | 16:9 | 正交 + A-Pose |

**没说要什么图** → 默认**半身 3:4**；只说「画个××」→ 默认**全身立绘 2:3**。
完整 17 种（含壁纸/阵容/服装拆解/概念图/口型图）见 `image-types.md`。

#### ② 判密度：什么时候该问

| 档 | 描述长什么样 | 动作 |
|---|---|---|
| **够** | 有主体 + 穿什么/什么样 + 气质或场景 | **直接出**，不问 |
| **偏薄** | 有主体与题材，缺场景/气质/用途 | 问 2–3 项 |
| **太薄** | 只有介质+题材+性别（如「3D 动漫玄幻女角色」） | **问 4 项** |

必问的四项：**场景 / 气质 / 脸型 / 用途**。其余（服装、发色、平台、背景）全默认。

提问卡长这样（一轮问完，回数字即可）：

```
出图前确认 4 件事，回序号即可（如「1 2 3 1」），或直接说「默认」：

1. 场景：① 山巅云海晨雾【默认】② 古殿残柱烛火 ③ 竹林夜雨 ④ 你描述
2. 气质：① 清冷疏离【默认】② 凌厉杀伐 ③ 温软灵动 ④ 你描述
3. 脸型：① 鹅蛋脸细长上挑眼【默认】② 圆脸大眼 ③ 尖下颌薄唇 ④ 你描述
4. 用途：① 全身立绘 3:4【默认】② 半身海报 ③ 三视图 ④ 头像
```

五套分题材卡（3D玄幻 / 写实写真 / Q版潮玩 / 赛博 / 古风）见 `intake-questions.md`。
**用户不答、说「随便」、说「直接出」→ 立刻按默认出，不再摆卡。**

### ② 补全：默认表（照抄，别自创）

| 缺什么 | 默认给 | 为什么 |
|---|---|---|
| 画幅 | 立绘 `3:4`；头像 `1:1`；海报 `3:4`；封面 `2:3` | 平台原生比例 |
| 头身比 | 写实 7.5 / 3D 动漫 7 / 二次元 6.5–7 / Q 版 3.5 | 不写必漂向可爱 |
| 介质 | 没提"3D/动漫" → **写实摄影**；提了 3D → **国漫 3D 半写实** | 最不容易崩 |
| 形状 | 按气质查第二节表 | 形状定性格 |
| 光 | 人物 `45° 侧光 + 光比 1:3 + 5600K`；情绪 `侧逆光` | 缺光位=平光=廉价 |
| 镜头 | 半身 `85mm f/2.8`；全身 `50mm f/4`；特写 `100mm f/2` | 行业默认 |
| 背景 | `简洁浅灰/纯色，低对比` | 不抢主体 |
| 文字 | **不写**，并在末尾排除 | 图内文字不可控 |
| 特效 | 不加；仅在气质需要时加一层（见第三节） | 特效默认是负担 |
| 平台 | 没说 → 出**中文自然语言版**（Seedream/即梦/豆包）+ 一行 MJ 英文要点 | 覆盖面最广 |

### ③ 拼装：十四段压成六句

不要按十四段逐条写，压成**六句**，读起来像一段描述而不是参数表：

```
① 形状与介质：以〔主形〕为主的〔介质〕角色，〔头身比〕
② 主体与服装：〔年龄/身份〕，穿〔服装，含主色与材质〕
③ 关键部位：〔发/眼/1–2 个识别特征〕
④ 动作与场景：〔一个动作〕，在〔场景〕
⑤ 光与镜头：〔光位+光比+色温〕，〔景别+焦段〕，〔构图/留白〕
⑥ 参数与排除：〔画幅〕，画面中不出现文字与水印
```

**六句之外的东西一律不写**（不要排比、不要形容词链、不要"高级感"）。

### ④ 交付：一条 + 一行 + 可选一条

```
〔主提示词代码块〕

补全：〔形状/介质/画幅/光〕均为推断，可改。
```

- **默认给一核多壳**：中文核心版 + 英文版（覆盖 90% 模型）；用户只要一个平台时只给那一条。详见 `cross-model.md`。
- **不落文件**，直接贴代码块。只有"资产图/系列图/建模"才写文件。
- 交付后**不追问**"要不要加特效"之类，除非用户明显在做系列。

## 二、气质 → 形状/风格/光（最常用的一张表）

| 用户说 | 主形 | 介质/风格 | 光 | 色 | 其他关键 |
|---|---|---|---|---|---|
| **酷 / 冷** | 三角 | 写实或电影感 | 90° 硬侧光，光比 1:6 | 冷灰 + 一点暗红 | 窄眼、薄唇、肩线利 |
| **温柔 / 治愈** | 圆 | 写实或插画 | 窗光柔光，光比 1:2 | 奶白 + 浅杏 | 圆下颌、眼神软、留白多 |
| **御姐 / 强势** | 方肩 + 长腿 | 半写实 | 侧逆光，光比 1:5 | 深色 + 金属 | 腿长 53%、尖下巴、高跟 |
| **少年感** | 圆 + 略方 | 写实或 3D 动漫 | 明亮自然光，高调 | 清爽蓝白 | 6.5–7 头身、短发、肩窄 |
| **清冷 / 仙气** | 修长（7.5） | 国漫 3D 或水墨 | 侧逆 + 薄雾体积光 | 月白 + 青灰 | 窄肩、长颈、衣袂轻 |
| **凶 / 压迫** | 方 | 写实或暗黑 CG | 顶光/底光，光比 1:8 | 铁灰 + 暗铜 | 宽肩 2 头宽、下颌方、手大 |
| **可爱 / Q** | 圆 | 3D 卡通或 Q 版 | 平光柔光，低对比 | 糖果色 | 3.5–4.5 头身、大眼、短肢 |
| **沧桑 / 故事感** | 方 + 瘦削 | 写实纪实 | 侧光露骨相，低照度 | 脏灰 + 土黄 | 眼袋、胡茬、颗粒感 |
| **神秘 / 邪气** | 三角 | 电影感或暗黑 | 单侧光，暗部占 70% | 墨绿 + 幽紫 | 半遮面、低头抬眼 |
| **华丽 / 妖异** | 曲 + 尖 | 国漫半写实 | 侧逆 + 强溢色 | 朱红 + 金 | 复杂纹样、金属反光、长指甲 |

> 这张表是"一句话需求"的主要翻译器。**先查表定形状，再填细节。**

## 三、什么时候加特效（默认不加）

| 气质/场景 | 加不加 | 加什么 |
|---|---|---|
| 日常、写真、头像 | 不加 | 最多一点环境光 |
| 清冷、仙气 | 加一层 | 薄雾 / 体积光 / 稀疏光尘 |
| 战斗、凶 | 加一层 | 火星 / 气浪 / 尘 |
| 科技、赛博 | 加一层 | 霓虹溢色 / 数据流 |
| 治愈 | 不加 | 花瓣最多两点 |

**一条提示词里粒子词只写一次**，且要依附主体（"火花勾出她的侧脸"）。

## 四、五个真实例子（一句话进 → 一条词出）

### 例 1｜"画个穿黑风衣的冷面女杀手"

```
以三角形为主形的写实电影感角色，7.5 头身。三十岁上下的东亚女性，
黑色长风衣领口立起，内搭深灰高领，衣料为哑光羊毛；
齐耳黑发、薄唇、窄眼，左眉尾一道细疤。她侧身站在雨后的巷口，
右手垂在身侧，指尖夹着一支未点的烟。
90° 硬侧光从右后方切入，光比 1:6，4200K 冷调，
轮廓光勾出肩线与风衣下摆；85mm f/2.8 中近景，浅景深，
主体偏左、右侧留出深色负空间。3:4，画面中不出现任何文字与水印。
```

### 例 2｜"要一个温柔的、会做甜点的姐姐"

```
以圆形为主的写实生活方式角色，7 头身。二十七八岁的东亚女性，
米白棉麻围裙罩在浅杏色针织衫外，袖口卷到小臂中段；
圆下颌、眼尾略下垂、发丝有几缕散在耳前。
她低头把糖粉筛在蛋糕上，手腕放松。
左侧窗光柔光入射，光比 1:2，5200K，桌面有柔和的接触阴影；

奶白与浅杏为主色，低饱和、低对比。3:4，画面中不出现任何文字。
```

## 六、三条纪律

1. **一句话需求 → 一条提示词，不问第二遍。** 缺的用默认表补，交付时用一行"补全"说明标出。
2. **不解释方法论。** 除非用户问"为什么这么写"，否则不写原理、不列清单。
3. **不主动加戏。** 不加特效、不加多视图、不加反向长列表；用户要了再加。
4. **一条提示词只服务一个图型。** 用户要「头像+立绘+三视图」，就分别给三条，不要混。
