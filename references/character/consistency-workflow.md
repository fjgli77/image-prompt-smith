# 跨平台一致性实战

> **本技能首选纯文字路线，不依赖参考图。** 核心方法见 `text-only-consistency.md`。本文件聚焦"把纯文字路线落到各平台的具体写法"，参考图部分放在最后一节作为**可选增强**。
>
> 一致性强度排序（**注意：本技能把纯文字提到首位**）：
> ```
> 纯文字锚点（首选，任何平台可用）  >  参考图（可选增强）  >  训练 LoRA（商用级，成本高）
> ```
> 纯文字锚点写好可提升 60%+ 稳定性；参考图是在此基础上再叠加，不是替代。

---

## 一、通用原则：固定 + 变量分离

把提示词拆成两块：

```
【固定块】锚点块 + 识别串 + 服装套装 + 风格块 + 光照  ← 逐字复制，永不改动
【变量块】动作 / 场景 / 表情 / 镜头                  ← 每次只改这一块
```

**每次只改一个变量**。同时改发型、服装、姿势、光线、背景，无法判断哪项修正有效。

**完整锚点块写法**（跨图原样粘贴）：

```
CHARACTER ANCHOR (do not alter):
<年龄性别种族>, <脸型>, <眼型+瞳色>, <眉>, <鼻>, <唇>, <特殊标记>,
<发型发色>, <身形+身高+头身比>, <默认服装套装>.
Signature features: <特征1> + <特征2> + <特征3>.
```

## 二、Midjourney

### 纯文字路线（首选）

```
[锚点块逐字复制] + [识别串] + [本次场景/动作] + [风格块] --ar 2:3 --seed 12345
```

- **固定 `--seed`**：系列图最关键的一招，同种子同提示词出同一个人。
- **锚点块放最前**：MJ 前面的词权重高。
- `--no` 排除干扰：`--no different face, extra person`
- 无需 `--cref` 也能保持角色一致，只要锚点写足。

### 可选增强（参考图）

只有追求像素级复刻时才加：

```
[锚点块逐字复制] + [场景描述] --cref [参考图URL] --cw 80 --ar 2:3 --seed 12345
```

| 版本 | 参数 | 说明 |
|---|---|---|
| V6 / Niji 6 | `--cref` + `--cw` | 原生支持 |
| V7 | `--oref` + `--ow` | Omni Reference |
| V8.x | `--oref`（回退 V7） | 无原生参考参数 |
| Niji 7 | 用 `--sref` + 文字描述 | cref/oref 均不支持 |

**权重心法**：`--cw` 30–80（低于 30 几乎不复用脸，高于 80 连服装姿态全锁死）。

> **纯文字路线下，参考图可省略。** 锚点块写足 + 固定种子，效果已经很好。

## 三、Stable Diffusion / ComfyUI

### 纯文字路线（首选）

无需任何适配器，靠提示词 + 固定种子：

```
Load Checkpoint (SDXL) → CLIP Text Encode [锚点块 + 场景 + 风格块]
→ KSampler [固定 seed: 12345 | steps 30 | cfg 7] → VAE Decode → Save
```

**Danbooru 标签式锚点块**（SD 吃标签，写法不同于自然语言）：

```
(1girl:1.1), (solo:1.1), oval face, (almond-shaped ice-blue eyes:1.2),
(beauty mark under right eye:1.3), (silver-grey long wavy hair:1.15),
center part, slim elegant build, white lace corset top, silver-blue sheer overlay,
high-slit skirt, crystal high heels, 7.5-head-tall
```

- **特征加权**：三不变特征给 1.15–1.3，别超 1.3（会焊死变形）。
- **固定 seed**：系列图全靠这个。
- 负面词必写"不许换脸"（见 text-only-consistency 第六节）。

### 可选增强 A：IP-Adapter

```
IPAdapter Advanced [参考图: 定妆脸裁切 | weight: 0.65–0.75]
```
- 纯文字路线下可将权重**降到 0.5**（文字已锁身份，参考图只补细节）。
- 高于 0.9：脸糊、"贴上去"感；低于 0.5：丢身份。

### 可选增强 B：ControlNet 锁姿势

```
OpenPose 骨架 → ControlNet OpenPose [weight 0.3–0.5]
```

### 可选增强 C：FaceDetailer 修脸（全身体建议）

```
UltralyticsDetectorProvider (face bbox) → FaceDetailer [guide_size 512 | denoise 0.4]
```
保留 denoise 0.4，锐化而非换脸。

### 可选增强 D：训练 LoRA（商用级）

- 数据集 **20 张精选 > 200 张杂乱**。
- 构成：5–8 特写 + 5–8 半身 + 3–5 全身 + 2–3 不同服装。
- 参数：学习率 SDXL 5e-5；步数 1500–3000；rank 32–64。
- **注意**：本技能默认不需要 LoRA，纯文字路线即可满足绝大多数需求。

## 四、即梦 Seedream / 豆包（自然语言派 · 纯文字可完全覆盖）

这类平台**最吃自然语言**，也最适合纯文字路线（很多版本不支持参考图）。

### 核心规则

1. **写自然语言短句**，不堆标签。
2. **锚点用描述句写全**，跨图复用。
3. **明确"保持不变"**："保持她的脸型、发型、瞳色、泪痣不变，只换场景"。
4. **单条提示词 < 600 英文词**（过长丢细节，脸就在细节里）。

### 纯文字模板

```
① 定妆（纯文字，无参考图）
半身肖像，一个 19 岁的东亚少女，鹅蛋脸，冰蓝色杏眼双眼皮，细直眉，
小巧鼻，柔和唇形，右眼下有一颗小痣，银灰色波浪长发中分带侧刘海，
纤细身形，穿白色蕾丝束胸上衣与银蓝色纱质外披，170cm。
正面，中性表情，柔和均匀光照，浅灰背景。3D 写实渲染，8K。

② 换视角（锚点块逐字复制，只改视角词）
[与①完全相同的角色描述，一字不改]，改为正侧面 90 度视图，
保持脸型、发型、瞳色、泪痣、服装完全不变。

③ 换场景（只改场景段）
[与①完全相同的角色描述]，她走在傍晚雨后的城市街道上，
霓虹灯倒映在湿漉漉的路面，微微回眸看向镜头，表情平静。
电影感光照，深夜蓝紫色调，竖版 2:3。[与①完全相同的风格描述]

④ 批量组图
[与①完全相同的角色描述]，生成一组 4 张同一角色的照片：
在咖啡馆窗边看书、走在城市街道、在家中做菜、日落时在阳台。
保持她的脸型、发型、身形完全一致。
```

**会飘 vs 会稳**：

| 飘 | 稳 |
|---|---|
| 女孩，沙滩，红裙，微笑，4k | [完整锚点块] + 她走在日落的海滩上 |
| 换个发型和背景 | 只换场景，保持脸型/发型/瞳色不变 |
| 把她画得漂亮点 | [三不变特征] 必须保留 |

## 五、一致性自查清单

出图后逐项检查，任一不符就回退改**锚点表**（而不是加参考图）：

- [ ] 脸型、眼型是否与锚点一致？
- [ ] 三不变特征（标记/特殊点）是否都在？
- [ ] 发色发型长度是否漂移（尤其背面视图）？
- [ ] 服装部件是否变了（正背面裙子长度/闭合方式）？
- [ ] 配色是否失控（主/辅/强调色是否守住）？
- [ ] 不同角度的肩线、身高、脚底是否对齐？
- [ ] 画风是否与系列前图一致？
- [ ] 光照方向是否统一？

> 10 项评分表见 `text-only-consistency.md` 第八节。

## 六、常见翻车与修法（纯文字路线）

| 现象 | 原因 | 修法 |
|---|---|---|
| 每次脸都变 | 锚点太少 / 形容词冲突 | 补足三不变特征 + 识别串；删相互冲突的描述 |
| 锚点明明写了还是变 | 锚点没放最前 / 写法每次不同 | 锚点块移到提示词首位，**逐字复制**，别改同义表述 |
| 服装漂移 | 只写风格标签 | 用部件+层次+闭合方式描述 |
| 配色失控 | 颜色没锚定位置 | 限定主色/辅色/强调色各一，注明位置 |
| 标志物消失 | 小饰品太多 | 减到 1–3 个高识别锚点，并加权重/负面锁定 |
| 不同角度不像同一人 | 直接做场景镜头 | 先完成定妆图 + 多视角，再做场景 |
| 设定稿三格变三张插画 | 把镜头描述写进了设定表 | 设定表只回答"长什么样"，动作情绪留给场景提示词 |
| 换了风格就认不出 | 锚点块跟着风格一起改了 | 锚点块不动，**只换风格块 + 头身比** |
