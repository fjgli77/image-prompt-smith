# 提问规约：什么该问、问几个、怎么问

> 一句话：**描述够就直接出，不够就问一轮（≤4 项，带默认，用户不答也照出）。**
> 问得好，用户答四个数字就够；问得差，会变成审问，用户直接跑。

---

## 一、先判密度（三档）

| 档 | 描述长什么样 | 处理 |
|---|---|---|
| **够** | 已有"谁 + 穿什么/什么样 + 气质或场景" | **直接出词**，不问 |
| **偏薄** | 有主体与题材，缺场景/气质/用途 | **问 2–3 项**，其余默认 |
| **太薄** | 只有介质 + 题材 + 性别（如"3D 动漫玄幻女角色"） | **问 4 项**，然后出 |

判定示例：

| 用户说 | 档 | 动作 |
|---|---|---|
| "画个穿黑风衣的冷面女杀手，站在雨巷" | 够 | 直接出 |
| "画个女剑客" | 偏薄 | 问 2 项（气质、场景） |
| **"给出一个 3D 动漫玄幻女角色的提示"** | **太薄** | **问 4 项** |

---

## 二、必须问的四项（其余都能默认）

| # | 问什么 | 为什么非问不可 | 影响哪一段 |
|---|---|---|---|
| 1 | **场景** | 决定光与环境，不问就只能给"纯色背景" | ④ 场景 + ⑥ 光 |
| 2 | **气质/性格** | 决定形状语言，不问就只能给中性圆润 | ① 形状 |
| 3 | **脸型或一个标志特征** | 决定五官锚点，不问就是"标准脸" | ③ 部位 |
| 4 | **用途/景别** | 决定画幅与裁切，不问可能给错比例 | ⑤ 镜头 + 参数 |

**只问这四项。** 服装可以默认（按题材给一套），发色可以默认，平台可以默认。

---

## 三、提问卡写法（四要素）

```
① 先说"确认 N 件事"，给出数量
② 每项 3 个具体选项 + 1 个"你描述"，第一项标【默认】
③ 明确"回数字即可"
④ 明确兜底："不回我就按默认出"或"想快就说'直接出'"
```

**标准卡（通用）**

```
出图前确认 4 件事，回序号即可（如「1 2 1 3」），或直接说「默认」：

1. 场景
 ① 山巅云海，晨雾逆光【默认】
 ② 古殿内景，烛火与柱影
 ③ 竹林夜雨，湿石阶反光
 ④ 你描述

2. 气质
 ① 清冷疏离【默认】
 ② 凌厉强势
 ③ 灵秀温软
 ④ 你描述

3. 脸型
 ① 鹅蛋脸 · 细长上挑眼【默认】
 ② 圆脸 · 大眼圆钝
 ③ 尖下颌 · 挑眉薄唇
 ④ 你描述

4. 用途
 ① 全身立绘 3:4【默认】
 ② 半身海报 3:4
 ③ 头像 1:1
 ④ 你描述
```

> **禁止空问题**："你想要什么风格？""有什么要求吗？"——这种问了等于没问，用户也不知道怎么答。

## 五、追问纪律（五条）

1. **一轮问完，不分次问。** 问完这一轮就出词，不要再补第二轮。
2. **最多 4 项。** 超过 4 项用户会烦；剩下的全部默认。
3. **每项必带默认，且标出来。** 用户可以说"默认"，也可以只说想改的那一项。
4. **用户不答 / 说"随便"→ 直接按默认出**，并在交付说明写一行"以下按默认补全"。
5. **用户说"直接出/别问了"→ 立刻出**，不要再摆卡。

## 六、答完怎么合并（把答案落进六句）

| 用户答的 | 落到哪 |
|---|---|
| 场景 | ④ 场景 + ⑥ 光（场景决定光源：山巅=逆光+雾，古殿=烛火+柱影，夜雨=霓虹/实用光） |
| 气质 | ① 形状（清冷→修长纵向；凌厉→三角；温软→圆）+ 光比 |
| 脸型 | ③ 关键部位（脸型词 + 眼型 + 一个识别特征） |
| 用途 | ⑤ 景别与焦段 + 画幅参数 |

**其余仍走默认**（服装按题材给、发色按气质给、背景按用途给）。

## 七、完整示例：从"太薄"到成品

**用户**：给出一个 3D 动漫玄幻女角色的提示。

**判定**：太薄（只有介质+题材+性别）→ 问 4 项（用 4.1 卡）。

**用户回**：`1 2 3 1`（山巅云海 / 凌厉杀伐 / 尖下颌薄唇 / 全身立绘）

**输出**：

```
3:4 全身立绘，国漫 3D 半写实的玄幻女角色，7.5 头身。
形状以纵向三角形为主：窄肩、收腰、锥形广袖，下摆向外张开成锐角。
二十岁出头的东方女性，尖下颌、薄唇、上挑长眼、瞳色偏金，
黑长发高束，一绺碎发垂在颊侧；月白与玄青配色的交领战袍，
肩甲为哑光玄铁，袖口与腰带为暗金织纹。
她立于山巅岩台，衣袂被强风带起，右手按剑。
背侧逆光穿过云海，光比 1:8，6200K 冷青，轮廓光勾出肩线与发丝；
薄雾在山腰处分层，脚下岩石有仰角透视。
50mm f/4 全身，略仰 15°，主体居中偏左，右侧留出云海负空间。
画面中不出现任何文字与水印。
```

补全说明：服装、发色、背景、平台均为推断，可改。

## 八、五个反面教材

| 错法 | 为什么错 |
|---|---|
| "你想要什么风格？" | 空问题，用户答不出；要给具体选项 |
| 一次只问一个问题，问四轮 | 用户会跑；一轮问完 |
| 问完不给默认，等用户全答 | 用户不回就卡住；必须能"默认出" |
| 问 8 项（连发色、瞳色、鞋都问） | 这些该自己补，问了显得不专业 |
| 用户答了 4 项，又追一句"还有别的吗" | 违反"一轮问完" |
