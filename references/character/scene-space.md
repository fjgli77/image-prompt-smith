# 场景与空间：把"背景"写成"地方"

> 场景失败从来不是"不够美"，是**没有纵深、没有接触、没有空气**。
> 一张图里如果人物是"贴"在背景上的，你写再多形容词也救不回来。
>
> **一句话：场景 = 三层 + 一处接触 + 一次反光 + 一道遮挡。**

---

## 零、先分清"背景"和"场景"

| 说法 | 是什么 | 结果 |
|---|---|---|
| 「背景：云雾仙山」 | **背景**＝一张图 | 人贴在图上，像证件照换了底色 |
| 「脚下石台被寒气冻裂，裂缝里结着霜；中景三根断裂玉柱；远景云海，最远山峰只占画面 1/8」 | **场景**＝一个空间 | 人站在一个"地方"里 |

**判据**：**能不能说出人物"站在什么上面"？** 说不出 = 你写的是背景，不是场景。

---

## 一、三段式：每层只回答一个问题

| 层 | 回答什么 | 占画面 | 放什么 | 常见错误 |
|---|---|---|---|---|
| **前景** | 镜头从哪看进去 | 8–20% | 一件离镜头最近的东西：冰柱、石栏、垂落的云气、飘雪、草叶、窗框 | 不放 → 画面没有"入口"，一眼平 |
| **中景** | 人站的地方 | 30–50% | 地面/台面 + 人物 + 身后的主体建筑 | 只写"云海" → 人悬空 |
| **远景** | 世界有多大 | 20–40% | 山影、宫阙、城市、云隙光 | 不写尺度 → 山像假山 |

**三条硬规矩**：

1. **三层之间必须有"空气"**：层间薄雾 / 尘 / 光柱。没有空气 = 三层被压成一张纸。
2. **远景必须有尺度参照**：`最远的山峰只占画面高度的 1/8`、`远处的塔尖不到人物头顶高度`。
3. **前景不许压在脸上**：`前景元素位于画面左下角，不遮挡人物`。

**成品骨架**：

```
前景：〔一件东西〕压在〔哪个角〕，占画面〔约 15%〕，不遮挡人物。
中景：人物站在〔什么地面/台面〕上，身后〔主体建筑/柱/门〕。
远景：〔山影/宫阙/城〕，最远处只占画面高度〔1/8〕。
层间：一层薄雾，只在层与层之间，不进入人物周围 1 米。
```

### 1.1 纵深四件：光靠"三层"还不够

三层只是分层，**纵深**要靠下面四件里至少三件同时出现：

| 件 | 干什么 | 写法 |
|---|---|---|
| **线性透视** | 线条朝消失点收束 | `地面石缝与栏柱朝画面右后方收束到同一消失点` |
| **尺度透视** | 同类物体越远越小 | `远处同类石灯依次缩小，最近一盏高过人物，最远一盏不到手掌大` |
| **空气透视** | 越远越淡、越蓝、越软 | `远景低对比、低饱和、偏冷蓝，被薄雾吞没` |
| **遮挡叠压** | 近物压住远物 | `前景石栏压住中景台阶边缘，台阶又压住远景地面` |

> **遮挡是最容易被忘、收益最大的一条**：没有叠压，三层就是三张纸片叠在一起。
> 光写 `layered composition` 不够，必须写出**谁压住谁**。

**分级清晰度写法（一次写完四件）**：

```
近景锐利、暖调、高对比；中景细节适中、中性色；远景虚化、低饱和、偏冷蓝、只剩剪影轮廓。
前景石栏压住中景台阶，台阶压住远景地面；地面石缝朝右后方收束；远处石灯依次缩小。
```

### 1.2 空间锚点：大场面的尺度基准

写"巨大 / 宏伟 / 辽阔"必出小场面——模型不知道以什么为单位放大。

**做法**：**先给一个可比对的具体物件**，再写主体。

```
【错】宏伟的仙宫矗立在云海之上，气势磅礴
【对】一座九重檐仙宫，正门高约三十人叠起，宫前一队修士只有门钉大小
```

| 锚点类型 | 写法 |
|---|---|
| 人体 | 门前守卫只有门钉大小 / 台阶一级高过人头 |
| 日常物 | 檐角铜铃比人还高一头 |
| 同类递缩 | 远处同类塔依次缩小，最近一座高过人物 |
| 地面纹理 | 广场砖缝间距约两步宽，向远处迅速收窄 |

### 1.3 光衰减：把深度写成明度梯度

```
侧前方 45° 主光；近处人物肩头高亮，中景石阶中间明度，远景墙面明显变暗、边缘柔化。
```

**光衰减曲线就是深度标尺**——只写"有纵深"没用，写"越远越暗越软"才落地。

**反向**：`flat illumination, uniform brightness, even ambient light` —— 均匀照明会把纵深直接抹平。

## 二、地面接触：人物"站得住"的唯一方法

**AI 最典型的破绽：脚下没有接触。** 人像贴纸、悬空 2cm、影子方向不对。

| 地面类型 | 必写 | 例 |
|---|---|---|
| 石台 / 地面 | 接触阴影 + 材质 | `feet firmly planted, soft contact shadow directly under the feet` |
| 冰面 | 接触阴影 + 倒影（弱） | `feet planted on ice, faint blurred reflection beneath, contact shadow` |
| 水面 | 涟漪 + 倒影（强） | `standing in shallow water, ripples around the ankles, mirrored reflection` |
| 雪地 | 压陷 + 边缘堆积 | `boots sinking slightly into snow, snow piled at the edges` |
| 沙土 | 扬尘 + 凹痕 | `dust settling around the feet, faint indentations in the sand` |
| 悬浮 | **必须解释为什么** | `hovering above the ground, small debris floating beneath her` |
| 空中 / 俯冲 | 无敌面 → 给"速度线索" | `falling with her robe trailing upward, wind lines around the body` |

**一句话**：**不写接触，人物就是贴纸。** 写了"悬浮"就必须给"为什么悬浮"（法阵/气流/碎片）。

## 三、环境反光：让场景"照到人身上"

这是**"合成感"与"真实感"的分界线**——也是审计里"背景像贴上去"的直接解药。

| 反光源 | 写在哪 | 写法 |
|---|---|---|
| 雪/冰面 | 下半身、下巴、装甲内侧 | `cold bounce light from the snow lighting the underside of the jaw` |
| 水面 | 侧脸、腿、裙摆内面 | `water reflections rippling across her legs and the inner robe` |
| 火光 | 面部一侧、金属边缘 | `warm firelight flickering on one cheek and along the armor edge` |
| 霓虹 | 轮廓、湿面、发梢 | `neon spill catching the rim of her shoulder and the wet hair` |
| 法阵 / 法术光 | 脚下向上、内侧、眼窝 | `the array's glow lighting her from below, edge light on the chin` |
| 天光 / 云隙 | 头顶、肩线 | `a cold shaft of light from the cloud gap falling on her shoulders` |

**每条反光都要写"照在哪个部位"**，否则模型只会给整体加一层滤镜。

---

## 四、遮挡关系：背景不许抢剪影

| 约束 | 写法 |
|---|---|
| 背景元素不压人物轮廓 | `background elements do not overlap the character's silhouette` |
| 雾从身侧分开 | `the mist parts around her body, leaving her outline clean` |
| 前景可以压肩、不可压脸 | `foreground may cross the shoulder, never the face` |
| 柱/门对称排布但不居中挡人 | `columns frame her on both sides, the centre kept clear` |
| 人群/兽群只做剪影 | `the crowd reads only as silhouettes, no facial detail` |

## 五、按图型分档：元素预算

`10-eval.md` 的"背景元素 ≤3 件"是**立绘**的规则，套到 KV 上会把人锁死。分档：

| 图型 | 背景元素上限 | 层次 | 说明 |
|---|---|---|---|
| **头像 / 半身写真** | 0–1 件 | 一层（虚化） | 纯色或单层 bokeh，多了抢脸 |
| **全身立绘（纯设定）** | ≤1 件 | 一层 | 纯色 / 极简地面 |
| **立绘 + 氛围** | 2–3 件 | 两层 | 地面 + 远景 |
| **KV / 主视觉** | 3–5 件 | **三层** | 前景 + 中景 + 远景，主体优先 |
| **场景概念图** | 环境为主，人物可缺 | **三层 + 天象** | 环境是主角 |

**判据**：**人物占画面越大，背景元素越少。** 人物占 70% → 背景最多 3 件；人物占 20% → 可以给 6 件。

## 六、题材场景包（六套，直接抄）

### 6.1 玄幻 · 帝庭 / 神阙

```
前景：左下角一根断裂的白玉柱头，占画面 12%，不遮挡人物。
中景：人物立于九级白玉台阶中段，身后是通透的殿门与两列蟠龙柱，柱列向纵深收敛。
远景：云海之上还有一层宫阙剪影，最远的檐角只占画面高度 1/10。
层间：殿内向外溢出的薄雾，只在柱与柱之间。
地面：白玉台阶有细密裂纹，台阶边缘有磨损；脚下柔和接触阴影。
反光：殿内暖金光从背后溢到肩线与发梢。
光：顶光从殿顶高窗斜下，形成一道光柱落在台阶上。
```

### 6.2 玄幻 · 山巅云海

```
前景：画面右下角一段被风削薄的岩脊，占 15%。
中景：人物立于孤峰顶的平整石面，身后三尺即是断崖。
远景：三层云海，最远一层之上有山尖剪影，只占 1/8 高度。
层间：云气在断崖处翻涌、被风拉出丝状边缘。
地面：石面有风蚀纹，脚边有碎石；接触阴影短而实（高位强光）。
反光：云海反光打在下巴与内衬上，形成冷白补光。
```

### 6.3 玄幻 · 古战场 / 城墟

```
前景：半埋的断戟与破旗，虚化，占画面下缘 18%。
中景：人物站在断裂石阶平台上（约 3 米高），身后三根内倾断柱，最高一根约 8 米。
远景：兽潮/军阵只作剪影，压在地平线上，密度高但无细节。
层间：扬尘与烟，贴地滚动，腰部以下更浓。
地面：石阶碎裂、缝隙积尘；脚步处有压痕与微尘。
反光：地平线橙红余烬映在甲片下缘与小腿。
```

### 6.4 校园 · 日系青春（参考实测：光向是命门）

```
前景：窗框或走廊立柱，压在一侧，占 10–15%。
中景：教室/走廊，课桌成列、公告栏、门牌；地面有窗格投下的光斑。
远景：操场树影 / 天台栏杆外的城市轮廓，虚化。
层间：空气里的浮尘（逆光可见），不进人物脸部。
地面：木地板或水磨石，有窗格亮斑；鞋底接触阴影。
反光：暖金光从侧后来，勾出发丝与制服边缘。
光：下午 4–5 点侧逆光直射入窗，色温 3200–3800K，光比 1:4，背景压 1.5 档。
风格：nostalgic youth anime / 新海诚式高光与云。
```

**校园风三条命门**（实测）：

1. **必须写 `backlit by golden afternoon sunlight streaming through windows`**，否则必出死平光。
2. 制服**必须写款式**：`navy sailor uniform with red ribbon, white collar, pleated skirt, knee-high socks`。只写 `school uniform` 得到通用白衬衫。
3. 别写 `realistic`，要写 `nostalgic youth anime style`——`realistic` 会往证件照跑。

### 6.5 赛博 · 雨夜街区

```
前景：湿漉的金属栏杆或霓虹招牌边缘，压在一角。
中景：巷口/天桥，人物立于积水前；管线、通风口、贴纸招牌。
远景：塔楼群与全息广告牌，虚化但保留色块。
层间：雨丝 + 地面蒸汽。
地面：积水形成倒影，波纹打散霓虹；接触阴影与倒影同时存在。
反光：洋红/青双色溢到轮廓、湿发、肩线（只两种）。
```

### 6.6 国风 · 庭院 / 竹林

```
前景：一枝斜出的竹/一枝花，占一角，虚化。
中景：月洞门或回廊，人物立于青砖地，白墙为背景板。
远景：墙外树冠与天空，留白。
层间：薄雾贴地。
地面：青砖有苔痕与积水；接触阴影柔和。
反光：墙面反射的柔光补在背光侧。
```

## 八、六个崩坏点

| 现象 | 根因 | 改法 |
|---|---|---|
| 背景像贴纸 | 没有三层、没有层间空气、没有反光 | 补三层 + 薄雾 + 一处环境反光 |
| 人物悬空 | 没写地面接触 | `contact shadow directly under the feet` |
| 场景像假山 | 没有尺度参照 | 写"最远山峰占画面 1/8" |
| 场景太杂抢主体 | 没写遮挡约束 | `background elements do not overlap the silhouette` |
| 光与环境不符 | 光位与场景光源来源矛盾 | 先定场景（光从哪来），再定光比 |
| 玄幻场景出成影楼 | 只有山云，没有"事件" | 补天象/法阵/残光（见 `fantasy-elements.md` §七） |

## 九、自检（七项）

- [ ] 能说出人物"站在什么上面"
- [ ] 三层齐全，层间有空气
- [ ] 远景有尺度参照
- [ ] 写了地面接触（或解释了为什么悬浮）
- [ ] 至少一处环境反光，且写了照在哪个部位
- [ ] 背景不压人物剪影
- [ ] 元素数量与图型匹配（人物越大，背景越少）
