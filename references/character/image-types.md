# 图型路由：用户要什么图，就给什么规格

> 同一个角色，用户说"要个头像"和"要张骨骼视图"，从画幅到光到姿态全都不一样。
> **先认图型，再写词。** 认错了，词写得再漂亮也交不了差。

图型不是一张清单，是**三族**。三族的规则互相冲突，先判族再选型：

| 族 | 给谁看 | 光 | 姿态 | 背景 | 判断句 |
|---|---|---|---|---|---|
| **A 展示族** | 人（甲方、读者、观众） | 可戏剧 | 可自由 | 可有场景 | "要好看" |
| **B 资产族** | 机器与下游（建模/绑定/打光/动画/美术） | **必须平** | **必须中性且统一** | **必须纯色** | "要能用" |
| **C 版式族** | 排版与投放 | 按版式 | 按版式 | 按版式 | "要放字" |

C 族（海报 / 封面 / 信息图 / 电商主图 / 头图）在 `references/09-recipes.md`，本文件不重复。

> **本文件管「要哪张图」，`view-specs.md` 管「这张图里用哪几个角度」。**
> 先在这里定图型（画幅 / 格数 / 光 / 布局），再去 view-specs 取角度写法（正面 0° / 45° / 90° / 135° / 180°、俯视、仰视）。

## 二、B 族的四条铁律（先立规矩，再谈骨架）

这四条和 A 族的直觉相反，所以最容易写错：

1. **一格一信息。** 造型与光不能在同一格；材质与配色不能在同一格。混了，下游读不出来。
2. **角度用标准集**：`正面 0° / 四分之三 45° / 侧面 90° / 背四分之三 135° / 背面 180°`。写"侧一点""稍微转过来"等于没写，模型每次随机。
3. **同一组图共享比例尺与地标线**：`头顶、眼线、下颌、肩、腰、髋、膝、踝`八条水平线贯通，脚底对齐同一水平线。
4. **光只有两种合法值**：`flat even lighting（平光，用于可比较）` 或 `single directional light（单向光，仅灯光参考图）`。B 族里出现"戏剧光/氛围光/体积光"，这张图就失去了参考价值。

**通用排除句**（B 族每条都带）：`画面内无格号、无箭头、无尺寸标注、无图注、无可读文字`。

## 三、A 族骨架（可抄，8 条主力）

### 1｜头像（1:1）

```
1:1 头像。二十七八岁女性半身胸像，齐肩黑发，浅灰针织衫，正面略 3/4 侧，
自然微笑，眼中有眼神光。浅米灰纯色背景，45° 柔光窗光加反光板补暗部，
光比 1:3，5500K，85mm f/2.0，皮肤保留自然纹理。写实摄影，低饱和暖调。无文字。
```
**常错**：写成全身（裁不成头像）｜背景带元素｜写"绝美"变网红脸。

### 2｜半身写真（3:4）

```
3:4 半身写真。二十多岁女性，中近景，侧脸朝右，手臂自然垂在身侧；
室内窗边，左侧窗光 45° 侧逆，光比 1:4，5200K，浅景深虚化背景；
85mm f/1.8。主体偏左，右侧留出墙面负空间。低饱和。
```
**常错**：手臂贴身体（粘连）｜背景太实（抢主体）。

### 3｜全身立绘（2:3 / 3:4）

```
2:3 全身立绘。角色全身完整入画，脚尖上方留 5% 余量；
50mm f/4 平视略仰 5°，重心落在右腿；侧光加背部轮廓光，光比 1:4；
主体居中，两侧留出等宽负空间；纯色或极简背景。
```
**常错**：脚被裁｜腿身比没写｜手臂粘躯干。

### 4｜Q 版（1:1）

```
1:1 Q 版角色。3.5 头身，头大身小，四肢短圆；圆脸、大眼、短眉，两颊腮红；
米白厨师服配橙围裙，双手举木勺；正面偏左柔光，光比 1:2，低对比高调；
50mm f/4 全身，主体居中，浅奶油色纯色背景。糖果暖色。无文字。
```
**常错**：头身比不写（出成 5 头身）｜写实解剖混入。

### 5｜KV / 主视觉（16:9 / 9:16）

```
16:9 游戏主视觉。角色中景居中略偏左，背景为环境化场景；
主光自左上 45° 打亮面部，右侧霓虹环境光作辅，光比 1:6；
一层主特效（气浪或光尘），不遮脸；角色占画面高度 70%；
右侧留出 25% 用于排版。
```
**常错**：特效糊脸｜背景比人亮｜留白没给。

### 6｜阵容图（21:9）

```
21:9 阵容图。四名角色一字排开，脚底对齐同一水平线，等高排布，彼此不遮挡、不留相切轮廓；
左起：…（逐个写：年龄段 / 主色 / 一句识别特征）；统一正面平光，光比 1:3，浅灰渐变背景；
比例关系按身高标注排布（170 / 155 / 182 / 165 cm 的相对高度）。写实摄影，50mm 平视；画面内无文字、无格号。
```
**常错**：只写"几个人"（数量不封顶）｜"同上"（后三个被合并成一个人）｜身高差不写。

> **人数必须逐个点名**：`总数严格等于 4，不允许第 5 人`。这是 B 族和 A 族共用的白名单写法。

### 7｜概念图（16:9）

```
16:9 场景概念图。24mm 广角，略仰；前景石阶与枯枝，中景人物背影占画面高度 18%，
远景云海与山脊三层分明；晨雾体积光，冷调 6000K，光比 1:5；空气透视使远景降对比。
低饱和，青灰为主。无文字。
```
**常错**：人物占比过大（变成人物图）｜前后景不分层（拍平）。

### 8｜封面 / 社媒封面

```
2:3 小说封面主视觉。半身，主角占画面高度 60%，主体偏右；
左下部 30% 为低对比暗区，留作书名与作者名排版；戏剧侧逆光，光比 1:6；
背景为雨夜街道虚化。图内不生成任何文字。
```
**常错**：让模型直接写字（乱码）｜没留文字区。

## 四、B 族骨架（15 条，重点看差异句）

### 9｜多视图 / 三视图（16:9，3 格）

```
16:9 多视图。正面、左侧面、背面三格并排，仅此 3 格，不增加任何额外画格；
全身，50mm，平视；orthographic projection, no perspective foreshortening；
同一 A-Pose，双臂外张 30°，手掌朝内，五指分开一指宽，neutral expression，mouth closed；
readable silhouette，三格等高等宽，脚底对齐同一水平线，八条地标线贯通；
flat even lighting，浅灰纯色背景；画面内无格号、无箭头、无图注、无可读文字。
```
**常错**：只写"共 3 格"不封顶（出 4 格）｜格内出现 ①②③｜各格光照不同。

### 10｜扩展视图（4–5 格）

在三视图基础上，角度集换成 `正面 / 四分之三 / 侧面 / 背面 / 头部特写`，并补一句：
`head close-up panel shows the same head from the front, at 1.5× the body scale`。

### 11｜正交建模图（16:9，3–5 格）

三视图 + 正交三件套 + 服装分层 + 材质数值。完整规范见 `modeling-handoff.md`。
核心不可省：`orthographic projection` **必须**配 `no perspective foreshortening` + `flat even lighting from the front` + `camera at infinite distance`。

### 12｜表情集（1:1 九宫）

```
1:1 九宫格表情集。3×3 等距网格，同一角色同一角度头肩像，
依次为：平静、微笑、惊讶、愤怒、悲伤、厌恶、思考、害羞、大笑；共 9 格，仅此 9 格；
写实摄影，85mm 头肩，统一正面平光，统一浅色背景，表情只改眉眼与嘴，发型与服装一字不改。
画面内无格号与文字。
```
**常错**：发型跟着变｜九格角度不一致｜表情夸张到认不出。

### 13｜表情 BS 图（2 行，动画向）

> AI 出不了 Blend Shape 的中间态。能给的只有**中性 + 极值**两态，这是美术定形用的，不是 rig 数据。

```
1:1 两行表情 BS 图，共 4 格，仅此 4 格。上行为中性表情；下行为嘴部张开极值（jaw open）
与眉部上抬极值（brow up），各占一格，共 4 格。
两行同角度、同光、同构图、同景别（85mm 头肩正面）；只改嘴部开合与眉毛高度，
面部其他结构、发型、服装、光照完全一致；写实摄影，85mm；flat even lighting，浅灰纯色背景。
画面内无格号、无箭头、无可读文字。
```
**写不了中间态**：别写"张嘴 30%/60%/100%"，模型给的三格会是三个不同的人。要中间态就分三次生成。

### 14｜姿态集（4 格，动作可读性）

```
16:9 姿态集。同一角色同一服装，四个动作横向等距排列，仅此 4 格：
站立、行走中、下蹲、跃起。每格全身入画、脚下有同一条地面线；
主视角为正面偏 3/4，写实摄影，35mm，相机高度一致、焦段一致；flat even lighting；
动作之间肢体不重叠、不跨格；画面内无格号、无文字。
```
**常错**：写"各种动作"（数量与内容都失控）｜每格视角不同（没法比较）。

### 15｜动态姿势图（4–6 格，动作设计向）

> 姿态集看"动作是否成立"，动态姿势图看"动作是否有势"。区别是**动态线**：每格要有一条明确的动势方向。

```
16:9 动态姿势图，4 格横排，仅此 4 格。同一角色同一服装，
依次为：蓄力下蹲、起步前冲、腾空跃起、落地卸力。
每格一条贯穿全身的主动态线（从支撑脚经髋、脊柱至发梢），躯干扭转与四肢摆动方向一致；
动势方向统一为自左向右；衣摆与发梢的飘向跟随动势，不逆势；脚下地面线贯通；
写实摄影，中景全身，35mm，相机与角色胸口同高；flat even lighting，浅灰背景；
画面内无格号、无速度线、无可读文字。
```
**常错**：只写"跑步跳跃"（没有动势方向，四格像四个静态姿势）｜衣摆反向飘（一眼假）｜加了速度线（把参考图变成插画）。

### 16｜动态多视图（3 格，同一动作冻结）

> 用途是查**穿模**：同一个动作从三个角度看，看腋下、裆部、肘内侧有没有互相插进去。

```
16:9 动态多视图，3 格横排，仅此 3 格。同一角色同一服装，完全相同的动作冻结：
右臂上举过肩、左腿前跨，姿态在三格中逐像素一致，不允许任何细微差异。
三格分别为正面、左侧面、背面；orthographic projection, no perspective foreshortening；
三格等高，脚底对齐同一水平线；flat even lighting，浅灰纯色背景；
画面内无格号、无箭头、无图注、无可读文字。
```
**常错**：三格动作不一致（最常见的崩法）｜写成"转身过程"（变成动画序列）。

### 17｜发型图（3–4 格）

```
16:9 发型参考，3 格横排，仅此 3 格。同一发型：正面、左侧面、背面。
重点可见：发际线形状、分缝位置（偏左 1/3）、发束走向、发尾长度（至肩胛上缘）；
发束成组呈块面，不糊成一整团；每束有明确端点。头部占每格高度 80%，
三格头部同尺寸、同高度对齐；写实摄影，85mm f/2.8 头部特写；flat even lighting，浅灰纯色背景；无文字、无格号。
```
**常错**：只写"一头长发"（发路、长度、分缝全丢）｜三格发型不是同一个｜背面格画成正面的镜像。

### 18｜发型分层图（3 格，逐层剥）

> 这是建模与绑定用的。AI 画不了真正的剖面，能做的是"三层各画一格"，把遮挡关系拆开。

```
16:9 发型分层图，3 格横排，仅此 3 格。同一发型的三个层次，从外到内：
第一格只画表层发束（覆盖额前与两侧）；第二格只画中层发束（表层移除，露出内部走向）；
第三格只画贴头皮的底层与发际线。每格都完整画出头型轮廓以作定位，
被移除的层次完全不出现在该格中；三格同角度（正面偏 3/4）、同尺寸、同光；
写实摄影，85mm f/2.8；flat even lighting，浅灰纯色背景；无文字、无格号、无箭头。
```
**常错**：三层叠在同一格里（等于没分层）｜写"剖面图"（AI 会画成解剖切片）｜每格角度不同（对不上位）。

### 19｜眉眼图（4–6 格，只画眼周）

```
16:9 眉眼结构参考，4 格横排，仅此 4 格。取景范围仅眉至颧骨上缘，不含口鼻与下巴。
依次为：正面、四分之三、侧面、闭眼。
每格标清：眉形走向与眉峰位置、上眼睑褶皱层数、内眼角形状、外眼角上扬角度、
下眼睑卧蚕有/无、睫毛密度与走向。皮肤为平滑风格化，无毛孔。
四格同尺寸、同高度、同光；写实摄影，85mm 微距；flat even lighting；浅灰纯色背景；无文字、无格号。
```
**常错**：取景带上整张脸（失去结构参考意义）｜写"眼睛很美"（无任何结构信息）。

### 20｜脸部特写（1 格，高精度）

```
4:5 脸部特写。取景自额顶至锁骨，正脸略 3/4；皮肤保留自然纹理与毛孔，
嘴唇有细纹，眼周有细微色差；虹膜有径向纹理与环形暗部，两点高光（主光 + 反光板）；
主光自左前 45°，光比 1:4，5600K，加右侧反光板补暗部；

> 其它多格图都要求"光统一"，**只有这一张相反**：每格光位必须不同，其余必须相同。

```

**常错**：四格连光也统一了（就成了一张图重复四次）｜写了"光位示意图"的箭头与标注（出乱码）｜色温跟着变（无法比较）。

### 30｜骨骼视图（关节与比例参考）

> **这不是绑定骨架。** AI 给不出 rig、给不出层级、给不出权重。它能给的是"关节点在哪、比例对不对"，用来对齐建模与绑定。

```
16:9 骨骼参考图，3 格横排，仅此 3 格。正面、侧面、背面。
半透明灰白人体外轮廓叠加白色骨骼线与关节球：
关节球位于下颌、肩、肘、腕、髋、膝、踝，共 7 组，
球径相对关系为 肩 > 髋 > 膝 > 肘 > 腕 ≈ 踝 > 下颌；
脊柱为一条自骨盆中心至颅底的连续曲线，颈段前凸、胸段后凸、腰段前凸；
四肢骨为连接关节球的直段，标注骨段长度比例（上臂 : 前臂 ≈ 1 : 0.9，大腿 : 小腿 ≈ 1 : 0.95）。
三格等高、同一比例尺、脚底对齐同一水平线；无肌肉细节、无内脏；
orthographic projection，flat even lighting，浅灰背景；无文字、无编号、无箭头。
```
**常错**：以为能出 rig（它是图不是数据）｜写了"骨骼绑定/权重/控制器"（模型会给奇怪的机械结构）｜加了骨名标签（乱码）。

### 31｜资产套装（多页组合）

一页一信息，**逐页生成，不要指望一张图塞完**。标准六页：

| 页 | 内容 | 图型 |
|---|---|---|
| P1 | 三视图 / 四视图 | §9、§10 |
| P2 | 表情集 + 口型 | §12、§22 |
| P3 | 服装正侧背 + 配饰 | §23、§26 |
| P4 | 材质分区 + 配色 | §27、§28 |
| P5 | 发型图 + 发型分层 | §17、§18 |
| P6 | 骨骼 + 灯光参考 | §30、§29 |

每页开头逐字复制同一段**锚点块**（年龄/脸型/发/主色/比例），这是套装能对上的唯一原因。

---

## 五、多格通用三件套（所有多格图必带）

1. **封顶句**：`仅此 N 格，不增加任何额外画格`。只写"共 N 格"是下限，模型会补第 N+1 格。
2. **排标注句**：`画面内无格号、无箭头、无尺寸标注、无图注、无可读文字`。图上的字会被下游继承。
3. **齐整句**：`N 格等高等宽，脚底对齐同一水平线，统一 flat even lighting，纯色背景`。

> 唯一例外是**灯光参考图**：第 3 条改成"仅背景与构图齐整，光位各不相同"。

**分区写法**（一图两区以上时）：`分上下两区，上区占 55%、下区占 45%，两区之间留 4% 纯白分隔带`。比例必须写数字，写"上面放缩略图下面放细节"会被随意分配。

## 六、组合请求怎么处理

用户说"三视图 + 发型图"，**不是一条词，是两个图型**。先做一件事：**判能不能合图**。

### 合图三条件（三条全满足才能合成一张）

| 条件 | 说明 |
|---|---|
| **同姿态** | 都是 A-Pose，或都不需要姿态 |
| **同角度集合** | 需要的角度能对齐（都有正/侧/背） |
| **同光** | 都是平光（灯光参考图永远不能与别人合） |

### 组合判定表

| 组合 | 能否合 | 处理 |
|---|---|---|
| 三视图 + 服装正侧背 | ✅ 能合 | 服装三视图本身就是三视图的裁剪版；合成一张上半身三视 + 下半身服装，或干脆只出服装版 |
| 三视图 + 发型图 | ⚠️ 分区合 | 角度可对齐，但取景范围差太多（全身 vs 头部）→ 上下分区：上排全身三视，下排头部三角度 |
| 三视图 + 表情集 | ❌ 拆 | 表情集要 9 格，与三视同图必挤 |
| 表情集 + 口型图 | ❌ 拆 | 八格口型会被压成蚂蚁 |
| 脸部特写 + 眉眼图 | ⚠️ 分区合 | 同角度可合；但眉眼图要 4 格，建议拆 |
| 服装正侧背 + 换装图 | ❌ 拆 | 一个是一套衣服三角度，一个是多套衣服一角度，逻辑正交 |
| 材质分区 + 配色图 | ⚠️ 分区合 | 左分区纯色标记，右分区角色 + 色块条；容易互相干扰建议拆 |
| 骨骼视图 + 任何美化图型 | ❌ 拆 | 骨骼要透视线框，美化图不能有线框 |
| 灯光参考 + 任何图型 | ❌ **绝不**合 | 它是唯一要"光不一致"的图型，合了就废 |
| 动态姿势 + 动态多视图 | ❌ 拆 | 一个多动作一角度，一个单动作多角度 |
| 配饰图 + 服装正侧背 | ⚠️ 分区合 | 可把配饰平铺放下排 |
| 局部放大 + 任何图型 | ⚠️ 只在同类合 | 放大图自带两分区，再加就三层了 |

**默认策略：宁可拆两条，不要硬合一张。** 合图的唯一好处是省一次生成，代价是所有格都被压缩、每格信息量下降——而资产图的全部价值就在信息量。

## 七、图型 → 必加约束（一句话清单）

| 图型 | 必加 |
|---|---|
| 头像 / 半身 | 背景纯色或极简，不加场景元素 |
| 全身立绘 | 脚不入画裁切，写腿身比与重心 |
| 任何多格 | 格数封顶 + 排标注 + 齐整 |
| 正交系列 | 正交三件套 + A-Pose + 八条地标线 |
| 表情集 / 口型 / BS | 只改指定部位，发型服装光照一字不动 |
| 换装图 | 除服装外全部相同（姿态/角度/光/发/妆） |
| 灯光参考 | **每格光位不同**，其余全同，色温统一 |
| 骨骼视图 | 只给关节位置与比例，不加肌肉/文字/rig 术语 |
| 材质分区 / 配色 | 纯色平涂，无渐变无纹理，色号写在画外 |
| 拆分 / 放大 / 配饰 | 不加引线箭头编号，用分区或等距排列代替 |
| 骨骼 / 材质 / 配色 | 必须配"这不是资产，是参考"的交付说明 |

## 八、识别不到图型怎么办

| 情况 | 处理 |
|---|---|
| 只说"画个××" | 默认**全身立绘 2:3** |
| 只说"要个图" | 默认**半身 3:4** |
| 说了用途但不给规格（"做封面"） | 给 2:3 + 留白，附一句"如需竖版改 3:4" |
| 一次要多种 | **按图型分别给**，先判合图三条件 |
| 说了个没听过的图型名 | 按最接近的资产图型给，并在交付说明写"按 ×× 处理，若要另一种告我" |

## 九、纪律

1. **一条提示词只服务一个图型**。混着写必崩。
2. **先判族再选型**：A 族追好看，B 族追能用，标准相反，别串。
3. **B 族不许出现戏剧光、氛围光、体积光**——除了灯光参考图，那张反过来。
4. **图型决定画幅与格数**，不要让用户先想比例。
