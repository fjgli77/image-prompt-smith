# 面部：十一格定脸，告别"同一张 AI 脸"

> 模型默认往"标准高吸引力面孔"收：瓜子脸、大眼、无瑕皮肤，放一起一个模子。
> 解法不是加形容词，是**把脸的底子拆成可写死的段**。

---

## 一、十一格公式（照顺序写）

```
身份 → 年龄气质 → 脸型骨相 → 眼型 → 五官距离 → 鼻唇 → 肤质特征 → 表情 → 视角 → 光影 → 画风
```

| # | 格 | 词例 |
|---|---|---|
| 1 | 身份 | 古风少女 / 现代职场女性 / 动漫少年 / 修仙长老 |
| 2 | 年龄气质 | 十八岁 / 三十二岁 / 成熟冷艳 / 稚嫩天真 / 疲惫坚毅 |
| 3 | **脸型骨相** | 鹅蛋脸 / 方下颌 / 圆脸带婴儿肥 / 高颧骨 / 窄长脸 / 短圆脸 |
| 4 | **眼型** | 细长眼 / 圆杏眼 / 上挑眼 / 下垂眼 / 三白眼 / 单眼皮 / 内双 / 深眼窝 |
| 5 | **五官距离** | 中庭短 / 中庭长 / 眼距宽 / 眼距近 / 人中短 / 下颌留白多 |
| 6 | 鼻唇 | 鼻梁挺直 / 鼻头圆润 / 薄唇 / 厚唇 / 唇角上扬 / 唇珠明显 |
| 7 | **肤质特征** | 泪痣 / 雀斑 / 酒窝 / 眉间疤 / 唇角痣 / 眼下青黑 / 鼻尖泛红 |
| 8 | 表情 | 清冷 / 温柔 / 愤怒 / 自信 / 脆弱 / 坚毅 |
| 9 | 视角 | 正面 / 四分之三侧 / 侧面 / 低角度仰视 |
| 10 | 光影 | 柔和自然光 / 侧逆光 / 顶光 / 烛光 / 冷色月光 |
| 11 | 画风 | 二次元平涂 / 3D 厚涂 / 水墨 / 写实 3D 渲染 |

**只有 3、4、5、7 四格决定"像不像同一个人"**，其余是可换的外壳。改动越集中在 8–11，越像同一角色换状态。

## 二、脸型骨相（5 套，直接套）

| 型 | 骨相写法 | 气质 | 适合 |
|---|---|---|---|
| **鹅蛋脸** | 线条柔和，颧骨适中不外扩，下颌流畅，额头饱满 | 温婉、女主 | 古风女主、正派 |
| **方下颌** | 下颌线分明，颧骨略高，脸偏方，立体感强 | 英气、御姐 | 职场、女将、反派 |
| **圆脸婴儿肥** | 脸颊饱满，下颌柔和，下巴短圆 | 幼态、亲善 | 萌妹、少女 |
| **窄长脸** | 中庭偏长，下颌留白多，脸瘦削，颧骨微凸 | 清冷、仙气 | 仙子、隐士 |
| **高颧骨** | 脸偏方长，下颌收得紧，骨相立体 | 成熟、压迫 | 大女主、贵妇、魔头 |

> **一条铁律**：脸型定了不许换词。`鹅蛋脸` 与 `瓜子脸` 在模型眼里是两个不同分布，混用等于换人。

---

## 三、眼型（决定有没有戏）

| 眼型 | 写法 | 读出来的性格 |
|---|---|---|
| 细长眼 | 眼裂细长，眼尾微挑或微垂，单眼皮 | 冷、谋、克制 |
| 圆杏眼 | 眼裂圆，双眼皮明显，眼距略宽 | 天真、明亮 |
| 上挑眼 | 眼尾明显上扬，重眼线感 | 妖、精明、危险 |
| 下垂眼 | 眼尾下垂，双眼皮 | 温柔、忧郁 |
| 三白眼 | 眼白露出过多，眼尾下垂 | 阴冷、压迫 |

**写眼必须同时写三样**：眼裂长短 + 眼尾方向 + 眼皮层次（单/内双/双）。
只写"大眼睛"= 交给模型自由发挥，出来必是同一双。

---

## 四、五官距离（决定年龄感）

| 比例 | 写法 | 读作 |
|---|---|---|
| 幼态 | 中庭短 + 眼距宽 + 人中短 | 十四到十六岁 |
| 成熟 | 中庭长 + 眼距略近 + 人中长 + 下颌收得紧 | 三十岁以上 |
| 大气 | 中庭偏长但舒展 + 眼距适中 + 下颌留白多 | 三十岁，长公主型 |

> **别写"成熟女主"**，要写"中庭偏长、眼距略近"。**比例词比评价词有效十倍。**

---

## 五、肤质特征：一个就够

`完美皮肤是 AI 脸的元凶。` 加一处特征，脸立刻有辨识度：

| 标记 | 写法 | 注意 |
|---|---|---|
| 泪痣 | 左眼下方一颗小泪痣 | **位置必须每轮一致**，换边就是换人 |
| 疤 | 眉心一道浅疤 / 右眉尾一道细长剑痕 | 只写一处，写两处变战损 |
| 雀斑 | 脸颊与鼻梁密集雀斑，鼻尖微红 | 配"健康肤色"，不配"冷白" |
| 痣 | 唇角一颗小痣 | 面部三处以内 |

**铁律**：特征不超过两处；位置写死；跨图不改。

## 六、3D 国漫脸专用写法

3D 国漫不是"真人 + 大眼"，它有独立口径：

```
高精度 3D 国漫角色，东方骨相；眼睛较真人略大但克制，眼裂修长，虹膜通透；
鼻唇精致，轮廓干净；皮肤为细腻通透的 CG 瓷感材质，不出现真人毛孔、油腻高光、皮肤噪点。
面部骨相与五官适度二次元化，中低饱和、高明度高级灰调。
```

| 要写 | 别写 |
|---|---|
| `东方骨相` `眼裂修长` `虹膜通透` `CG 瓷感` `次表面散射` | `真人毛孔` `油光` `皮肤噪点` `塑料脸` |
| `眼睛略大但克制` | `big anime eyes`（会冲到日式赛璐璐） |

**反向必备**：`真人照片感、真人毛孔、油光、过度磨皮、塑料脸、二维平涂、欧美卡通、皮克斯风`。

## 七、崩坏点（6 条）

| # | 崩坏 | 根因 | 写法 |
|---|---|---|---|
| 1 | 每张图都是同一个人 | 只写"美/精致"，没写骨相 | 脸型 + 眼型 + 距离 + 一处特征，四格写死 |
| 2 | 侧脸崩、换角度就变人 | 只按正面写 | 加"四分之三侧"下的颧骨与下颌描述 |
| 3 | 特征位置漂移 | 泪痣写"眼下方"不写左右 | 写"左眼下方"、"右眉尾" |
| 4 | 3D 国漫出成日式 | 画风词混写 | `PBR` 与 `anime/cel shading` 不同现 |
| 5 | 年龄与脸不匹配 | 只写年龄不写比例 | 用中庭/眼距/人中去兑现年龄 |
| 6 | 表情把脸改了 | 表情写太大（大笑/大哭） | 只改眉眼嘴，不动骨相 |

---

## 八、一句话自检

写完读一遍，问四句：

1. 换一个人来读，能凭这段描述认出同一张脸吗？
2. 脸型、眼型、距离、特征，四格是不是都写死了？
3. 有没有出现"精致/高级/绝美"这类不执行的词？
4. 画风词是不是只有一个族？

一题答不上就回去补，别加形容词。
