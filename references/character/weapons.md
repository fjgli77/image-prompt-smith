# 武器：从"一把剑"到"能画的兵器"

> 覆盖：通用冷兵器 + 玄幻仙侠法宝 + 3D 国漫渲染 + 建模交接
> 一句话：**玄幻的"神感"不来自发光，来自品阶。**

---

## 〇、先判三件事（30 秒）

| 判什么 | 三选一 | 影响 |
|---|---|---|
| **品类** | 手持兵器 / 悬浮法宝 / 阵器（旗盘石）/ 秘宝（珠符锥） | 七类法宝里只有三类长成"剑"的样子，写错品类必错 |
| **品阶** | 法器 / 灵器 / 玄器 / 帝器 / 圣器 | **决定光**（见 §二），不是靠形容词 |
| **画风** | 3D 国漫 / 三渲二 / 写实 CG | 词族互斥，混写变小日式或塑料 |

三者定完再动笔。**先定品阶再写光**，反了就是"满身神光"的中式 AI 味。

---

## 一、四段词法（每段只干一件事）

| 段 | 写什么 | 词例 |
|---|---|---|
| **① 形制** | 刃型 + 长度 + 持握，**必须唯一** | 直刃 / 弧刃；单刃 / 双刃；短（前臂长）/ 标准（身高 1.2 倍）/ 长柄（过人高）；单手 / 双手 |
| **② 结构件** | 从刃到鞘逐件点名，**至少 3 件** | 剑身、剑脊、血槽（fuller）、剑格/护手（crossguard）、握柄、缠绳方向、剑首（pommel）、剑鞘（scabbard）、佩带位 |
| **③ 材质工艺** | 主体色 + 配件色，**金属色两种封顶** | 拉丝铁灰、锻打水波纹、哑光黄铜、氧化斑驳青铜、黑漆嵌银鞘、拉丝银面 |
| **④ 状态** | 一眼看出"用过" | 刃口一线寒光、轻微卷刃、缺口两处、包浆（patina）、缠绳起毛 |

**四段模板**

```
〔形制〕直刃长剑，刃长约人身高 1.2 倍，单手持握、双手时柄尾留一拳——
〔结构件〕十字护手、单螺旋缠绳握柄、剑首圆盘配重；银质雕花剑鞘佩于左腰，鞘口朝前——
〔材质〕刃面拉丝铁灰，护手哑光黄铜，鞘身黑漆嵌银——
〔状态〕刃口一线寒光，护手边缘磨白，鞘底磕碰痕。
不是弯刀、不是法杖、不是光剑。
```

**结构件是唯一的抗崩手段**：只写"剑"，模型给一根亮棍；写"十字护手 + 缠绳 + 圆盘剑首"，它才有东西可画。

## 二、品阶定光表（玄幻仙侠核心，别跳）

| 品阶 | 对应境界 | 视觉语言 | 绝不写 |
|---|---|---|---|
| **法器** | 练气 | 坚固锋利、**无光**；金属本色，刃口一线寒光 | 光效、悬浮、剑气 |
| **灵器** | 筑基 | 入灵力后**通体转属性色**，可发各色剑气 | 器灵、自主行动 |
| **玄器** | 金丹 | **聚气成罡**：剑身外裹一层半透明罡气，剑气连绵 | 巨大光柱、领域 |
| **帝器** | 元婴 | **灵力化形 + 器灵**：剑身可虚化重组，旁浮兽形/人影虚像 | 独立人格 |
| **圣器 / 地神器** | 化神 / 成圣 | **自我意识 + 引动天象**：无需持握即悬空，云聚地裂 | 具体招式动作 |

### 铁律：品阶越高，常态越暗

```
【错】剑身泛着耀眼金光，周身环绕金色光环，神光四射
【对】帝器，未出鞘时通体暗哑无光——唯剑鸣之际，方圆十丈草叶齐伏、露珠凝而不落
```

**"神"体现在它对环境的影响**，不在它自己发光。这一条能直接消掉大部分中式 AI 味。圣器不需要"发光特效"，需要"天象变了"。

## 三、仙侠专属零件（通用兵器没有的）

| 零件 | 写法 | 备注 |
|---|---|---|
| **剑匣** | 墨玉长匣，长约四尺，匣面刻云纹，匣口微启，三柄剑柄并列外露 | 不写"长条""匣口" → 必画成箱子 |
| **剑穗** | 剑首垂剑穗，穗身紫玉嵌一缕青丝，末端三缕流苏各缀玉珠，**垂落至剑格下方两寸，随动作摆动** | **性价比最高的零件**：柔性件在满屏硬边里制造对比；不写位置必丢 |
| **剑脊** | 剑脊笔直，一线高光不断 | 决定"有厚度"还是"纸片" |
| **剑格 / 剑镡** | 剑格为镂空云纹，呈飞鸟展翅状，护住剑柄 | 形制写死一种，防刀剑混血 |
| **剑鞘** | 银质雕花剑鞘，鞘口嵌玉，鞘身三道箍 | 最常被漏写的一件 |
| **剑首** | 剑首圆盘，嵌一枚暗色灵石 | 与剑穗同句写，省字数 |

## 四、飞剑六状态（决定剑在画面里的位置）

| 状态 | 写法 | 用在哪 |
|---|---|---|
| **在手** | 单手握柄，剑身斜指地面 | 常规立绘 |
| **离手悬停** | 剑悬于身侧一尺，剑尖朝下，垂直静止，无手接触 | **仙侠标志姿态**，最出效果 |
| **绕身盘旋** | 绕周身水平环飞，剑尖朝切线方向 | 战斗前摇 |
| **分化剑影** | 一柄主剑 + N 柄半透明虚影，**必须封顶** | 输出爆发 |
| **成阵** | 按几何排布：三才三角 / 四象四方 / 周天环形 | 大招 |
| **归匣** | 剑身没入匣口，仅余剑柄 | 收势 / 登场 |

### 数量封顶（写"万千"必糊）

```
【错】万千剑影铺满天空              → 糊成噪点，且数不出来
【对】主剑一柄，另有虚影恰好 8 柄，分两层环绕：外层五柄等距成环、内层三柄略高，
      虚影为半透明青碧色、可见完整剑形轮廓——不增加第九柄
```

要"多"，用**阵列结构**（环形/分层/对称）表达，不用数量词。这一条同样适用于剑雨、飞刀、针、箭。

## 五、剑气六形态（别混写）

| 形态 | 视觉 | 写法要点 |
|---|---|---|
| **剑气** | 沿剑身延伸的弧形光刃 | 弧形、贴合剑势方向、边缘锐利 |
| **剑丝** | 细如发丝的密集线状 | 扇形铺展，**可数**，不写"无数" |
| **剑罡** | 外放的柱状/壁状气劲 | 垂直轰地，写直径与高度 |
| **剑轮** | 环形旋转 | 必须是**剑首尾相接排成环、剑尖朝外**，不是齿轮/风车 |
| **剑域** | 领域场 | 写环境响应：地面环状裂纹、草叶伏倒、碎石离地半寸 |
| **剑意** | 无形，只靠环境暗示 | 不画光，画"露珠凝而不落""落叶悬停" |

**属性色必须绑定**：火→赤红/金红｜水→碧蓝/青白｜木→青碧｜金→银白｜雷→紫电白｜冰→霜白泛淡蓝。

## 六、3D 国漫渲染：画风词混写必崩

| 画风 | 关键词 | 混错后 |
|---|---|---|
| **3D 国漫电影级** | 顶级院线级3D国漫风、3D国漫电影CG、PBR物理材质、电影级ACES、次表面散射、体积雾 | 掺 anime/cel → 日式赛璐璐 |
| **三渲二** | 三渲二、NPR、赛璐璐、描边、平涂+高光 | 掺 PBR/写实 → 变游戏 CG |
| **写实 CG** | 超写实、金属拉丝、真实反射 | 掺"动漫" → 变塑料 |

**硬规矩**：`PBR / photorealistic` 与 `anime / cel shading / cartoon` **不得同现**。

**3D 国漫武器配方（五句）**

```
① 画质：顶级院线级3D国漫风，电影级CG，PBR物理材质
② 材质：蓝银与鎏金剑身金属拉丝，精密反射（主体冷、配件暖）
③ 光：冷白剑芒，边缘极淡霜色衰减
④ 比例：九头身
⑤ 排除：无文字、无水印、非真人、非Q版、非赛璐璐
```

> **九头身是国漫 3D 的硬规格**，多份成品提示词都单列这条。

**画幅与底**：刀剑平铺 1536×1024 横版、长兵器 1024×1536 竖版、设定卡 16:9；**冷刃配深底**（深色绒布 + 单向冷光），白底配银白刃口容易糊边。

## 七、佩带位表（武器与身体的接触点）

| 位置 | 写法 |
|---|---|
| 腰侧 | 左侧腰际，鞘口朝前，鞘尖向后下方出画 |
| 背后 | 斜跨背带，跨右肩至左腰，剑柄高出右肩一头 |
| 手持 | 拇指扣在剑格上方，四指并拢搭缠绳（**此句抢占注意力，必须同句写全剑身与剑鞘**） |
| 插地 | 剑尖入地约一掌，剑身略向人物倾斜 |
| 悬浮 | 身侧一尺，剑尖朝下，无接触 |

## 九、崩坏点（12 条）

| # | 崩坏 | 根因 | 写法 |
|---|---|---|---|
| 1 | 剑变成一根亮棍 | 只写形制不写结构件 | 结构件 ≥3 件 |
| 2 | 刀身像塑料片 | 缺材质工艺层 | 补"拉丝/锻打/氧化" + 主体色 |
| 3 | 刀剑混血（弧刃+直刃） | 矛盾描述 | 形制唯一，护手形制写死当分界线 |
| 4 | 背在背上变"贴"在背上 | 缺背带 | 写斜跨带、压肩位置、出画方向 |
| 5 | 双持一长一短、手黏连 | 两手同时握物 | 先出单手，另一手局部重绘 |
| 6 | 飞剑画成握在手里的普通剑 | 只写"飞剑"没写状态 | 写"离手悬停，剑尖朝下，无手接触" |
| 7 | 剑影剑雨糊成噪点 | 用"万千/无数" | 恰好 N 柄 + 分层环绕 + 不增 N+1 |
| 8 | 剑轮画成齿轮/风车 | 只写"剑轮" | 剑首尾相接排成环、剑尖朝外 |
| 9 | 剑穗丢失 / 变挂坠 | 柔性件无位置 | 垂至剑格下方两寸，随动作摆动 |
| 10 | 剑匣画成箱子 | 缺形制 | 长条形、长约四尺、匣口微启、剑柄外露 |
| 11 | 法器满身神光 | 品阶与光脱钩 | 品阶定光（§二） |
| 12 | 剑域只是一个光罩 | 没写环境响应 | 地面裂纹、草叶伏倒、碎石悬浮 |

## 十一、交给建模时多说三句

| 项 | 口径 |
|---|---|
| **面数** | 移动端小道具 500–2000 tris；PC/主机主角武器 5000–15000；AAA 英雄武器可到 8 万 |
| **剪影** | 先做黑形测试，剪影不成立细节救不回 |
| **细节分级** | 小于几像素的细节放法线贴图；**改剪影的必须真几何** |

**武器专用**：模块化拆分（剑身/剑格/握柄/剑首/剑鞘独立）、挂点 socket（鞘挂腰位、握持段中心）、硬边倒角视觉当量 2–3 px、Auto Smooth 30°。

> 与 `modeling-handoff.md` 同口径：**AI 出的武器图不能直接绑定或进引擎**，只当三视图比例参照。
