# 部位词法：从颅顶到脚底

> `appearance-anchors.md` 解决"用 3 个特征锁住这个人"；这一份解决**"把一个人完整写出来"**。
> 一句话原则：**先体块，再部位，最后细节。顺序反了，越写越糊。**

---

## 一、先定写几层（按景别裁剪，不是写得越多越好）

| 景别 | 必写 | 可省 | 写了反而坏事 |
|---|---|---|---|
| 头像 / 胸像 | 颅顶、发际、脸型、眉眼鼻唇、耳、颈、锁骨 | 腰以下全部 | 腿长、鞋、站姿 |
| 半身 | 上面全部 + 肩、背线、胸腰、上臂、手（若入画） | 膝以下 | 足部细节 |
| 全身 | 全部部位 + 重心 + 站姿 | — | — |
| 特写（脸/手/足） | 该部位的分块与转折 | 其他部位 | 全身比例 |
| 多视图 / 资产图 | 全部 + 每视图可见的识别特征 | — | — |

**铁律**：写了的部位模型一定画，没写的部位模型自己编。**所以"裁剪"比"补全"更重要。**

---

## 二、比例与体态（全身图的第一段，别省）

```
身高 + 头身比 + 肩宽 + 腰线位置 + 腿身比 + 体脂 + 重心
```

| 项 | 写法 |
|---|---|
| 头身比 | `7 头身` / `6.5 头身`（**必写**，不写必漂向可爱） |
| 肩宽 | `肩宽约 1.6 个头宽`（窄肩 1.3 / 标准 1.6 / 宽肩 2.0） |
| 腰线 | `腰线在身高 0.6 处`（高腰显腿长） |
| 腿身比 | `腿长占身高 52%`（常规 48–50%，长腿 53%+） |
| 体脂 | `清瘦见骨` / `匀称` / `精瘦有肌肉线条` / `丰腴` |
| 重心 | `重心落在右脚，左腿微屈`（站姿可信度的关键） |

**三套方言**

| | 写实 | 3D 动漫 | 2D 动漫 |
|---|---|---|---|
| 比例 | `realistic human proportions, 7.5 heads` | `stylized 7-head proportion, slender build` | `7-head anime proportion, long legs` |
| 体态 | `natural contrapposto, weight on right leg` | `clean silhouette, clear center of gravity` | `dynamic pose, clear silhouette` |

**崩坏点**：不写头身比 → 出 Q 版；不写重心 → 站姿像立牌；同时写"娇小"和"170cm" → 比例乱。

---

## 三、头面（权重最高的一段）

### 3.1 颅顶与发际

```
颅顶高度 + 发际线形状 + 发量 + 发旋位置
```
- 写实：`rounded cranial vault, natural hairline with slight widow's peak, thick hair`
- 3D 动漫：`clean rounded skull volume, sculpted hairline, strand-based hair with visible part line`
- 2D：`发际线整齐，发量蓬松，刘海分束`

**崩坏**：颅顶太扁 → 显老；发际线不写 → 额头忽高忽低（跨图不一致的头号原因）。

### 3.2 脸型与骨相

```
脸型 + 颧骨 + 下颌角 + 下巴 + 面部脂肪
```
- 写实：`oval face, high cheekbones, defined jaw angle, slightly pointed chin, minimal facial fat`
- 3D 动漫：`planar facial structure, soft rounded jaw, subtle cheek volume, stylized chin`
- 2D：`鹅蛋脸，下颌线柔和，下巴小巧`

**崩坏**：只写"瓜子脸"→ 换角度就变；3D 动漫写"高颧骨 + 硬下颌"→ 变真人。

### 3.3 眉 / 眼 / 鼻 / 唇 / 耳

| 部位 | 写实 | 3D 动漫 | 2D |
|---|---|---|---|
| 眉 | `natural brow, slight arch, individual hairs visible` | `sculpted brow ridge, clean brow shape` | `柳叶眉，眉尾细` |
| 眼 | `almond eyes, visible upper eyelid crease, iris with radial fibers, single catchlight` | `large expressive eyes, sculpted eyelids, iris radial gradient, two specular highlights, upper lash as solid geometry` | `凤眼，上挑眼尾，虹膜渐变，双高光，下眼睑一道浅影` |
| 鼻 | `straight bridge, defined tip, visible nostrils` | `small rounded nose, soft tip highlight, minimal nostril detail` | `鼻梁一条线，鼻头一个点，鼻翼一道弧` |
| 唇 | `full lower lip, defined cupid's bow, natural texture` | `soft lips with subtle volume, corner shadow` | `上唇薄下唇厚，唇珠一点高光` |
| 耳 | `detailed helix and lobe, ear canal shadow` | `simplified ear shape, soft helix` | `耳廓简化，一条弧线带过` |

**崩坏**：眼睛不写"眼睑结构"→ 贴纸眼；耳不写 → 出现"融进头发"的耳；唇不写厚度 → 上下唇一样厚。

### 3.4 颈与锁骨（最容易被跳过、但决定"是否有身体"）

```
颈长 + 颈粗 + 胸锁乳突肌 + 锁骨明显度 + 颈窝
```
- 写实：`long slender neck, visible sternocleidomastoid, defined clavicles, suprasternal notch shadow`
- 3D 动漫：`slim neck with soft volume, subtle clavicle line, soft shadow under jaw`
- 2D：`颈部细长，锁骨一道浅线，下颌投影落在颈上`

**崩坏**：不写颈 → 头直接坐在肩上；不写锁骨 → 胸口一片平；不写下颌投影 → 头和脖子连成一块（即梦高频）。

---

## 四、躯干

| 部位 | 必写 | 写实 | 3D 动漫 |
|---|---|---|---|
| 肩 | 肩线角度、三角肌 | `sloped shoulders, soft deltoid curve` | `clean shoulder line, simplified deltoid` |
| 背 | 肩胛、脊柱沟 | `visible scapula, spinal groove` | `smooth back plane, subtle scapula hint` |
| 胸 | 胸廓体积、衣物贴合 | `natural chest volume, fabric follows ribcage` | `stylized chest plane, clean fabric fold` |
| 腰 | 腰线高度、腰臀比 | `waist at 0.6 body height, defined waist-hip ratio` | `narrow waist, clear silhouette curve` |
| 胯 | 骨盆宽度 | `hip width ≈ 1.5 head widths` | `stylized hip plane, clean transition` |

**崩坏**：躯干只写"身材好"→ 比例随机；衣物不写"贴合胸廓"→ 衣服像纸板。

---

## 五、手臂

```
上臂长度 + 肘部 + 前臂肌肉 + 腕部 + 手臂姿态
```
- 写实：`upper arm to elbow at waist level, subtle forearm muscle, visible wrist bone`
- 3D 动漫：`clean arm volume, simplified elbow, soft wrist transition`
- 2D：`手臂线条流畅，肘部一个转折，腕部细`

**崩坏**：臂长比例错（肘不到腰）→ 手长在胯上；不写姿态 → 手臂穿模进身体。

---

## 六、手（专章：全模型最难部位）

### 6.1 结构五项（写全就稳一半）

```
手指数 5 + 长短序（中>无名>食>小，拇指最短）+ 关节（每指 3 节）+ 拇指位置（掌侧，与食指 30–45°）+ 指甲形状
```

```
手部：五指，中指最长，拇指最短；拇指位于掌侧，与食指夹角 30–45°；四指并排有缝；
每指三关节，关节处皮肤褶皱；指甲长方形带圆弧，占末节一半。
```

### 6.2 姿态白名单（只写静止，别写复杂手势）

| ✅ 安全 | ⚠️ 中等 | ❌ 高危 |
|---|---|---|
| 自然下垂、轻握拳、平放桌面、插兜、拢袖、背手、扶栏、持物（剑/杯/伞） | 半握、指尖触碰、单手托腮、拨发 | OK 手势、比心、数字、交叉手指、弹奏、结印 |

### 6.3 藏手四法（比修手便宜一百倍）

1. **入袖**：`双手拢在宽袖中`（古装最好用）
2. **背手**：`双手背在身后`
3. **持物**：`手握剑柄`（握持比张开简单）
4. **出画**：半身构图让手落在画外

### 6.4 手部反向

`extra fingers, fused fingers, six fingers, missing fingers, malformed hands, claw hands, merged knuckles`

**崩坏**：写"修长的手指"→ 指节消失；写"手势自然"→ 随机手势；不写拇指位置 → 拇指长在掌心。

## 七、下肢

| 部位 | 必写 | 写实 | 3D 动漫 |
|---|---|---|---|
| 大腿 | 粗细、肌肉线条 | `thigh with subtle muscle line, knee at mid-leg` | `clean thigh volume, simplified muscle` |
| 膝 | 髌骨 | `visible patella, soft shadow above knee` | `soft knee plane, minimal detail` |
| 小腿 | 腓肠肌 | `calf muscle curve, ankle taper` | `clean calf taper, smooth ankle` |
| 踝与足 | 踝骨、足弓 | `visible ankle bone, natural arch` | `simplified foot, clean instep` |
| 鞋 | 款式+材质+磨损 | `worn leather boots, scuffed toe, visible stitching` | `clean boot shape, matte leather` |

**崩坏**：全身图不写膝位置 → 腿长得像两根棍；不写鞋 → 脚变成一团；写"高跟鞋"不写跟高 → 站姿前倾。

---

## 八、皮肤与体表

| 项 | 写实 | 3D 动漫 | 2D |
|---|---|---|---|
| 质感 | `natural skin texture, fine pores, subtle vellus hair` | `smooth stylized skin, no pores` | `平涂肤色，一处腮红渐变` |
| 血色 | `natural flush on cheeks and nose` | `soft blush gradient on cheeks` | `腮红两团，鼻尖一点红` |
| 疤痕/痣 | `small scar above left brow, mole below right eye` | 同（要保留，是识别锚点） | 同 |
| 汗/湿 | `fine sweat beads on forehead and neck` | `subtle sheen on skin, no droplets` | `额角一滴汗` |
| 纹身 | `black ink tattoo on left forearm, line work` | `stylized tattoo pattern, clean edges` | `小臂一道纹样` |

**铁律**：**3D 动漫写"毛孔/绒毛/皮肤纹理"必变真人**；2D 写"真实皮肤"必变半写实。

## 九、部位崩坏速查（12 条）

| 现象 | 根因 | 改法 |
|---|---|---|
| 头直接坐在肩上 | 缺颈段 | 补颈长 + 下颌投影 |
| 手长在胯上 | 缺肘位置 | 写 `elbow at waist level` |
| 腿像两根棍 | 缺膝与小腿曲线 | 补髌骨 + 腓肠肌 |
| 脚成一团 | 缺鞋/足弓 | 写鞋款 + `natural arch` |
| 脸换角度就变 | 脸型只有形容词 | 换骨相词（颧骨/下颌角/下巴） |
| 五官像贴纸 | 缺眼睑与投影 | 补 `sculpted eyelids` + 下颌投影 |
| 额头忽高忽低 | 缺发际线 | 写发际线形状 + 发旋 |
| 身体像纸板 | 缺躯干体块 | 写胸廓/腰线/骨盆宽 |
| 手臂穿模 | 缺姿态 | 写手臂停在哪 |
| 手指数不对 | 缺结构五项 | 上 6.1 修正句 / 藏手 |
| 皮肤塑料感 | 缺材质语义 | 3D 写 SSS；2D 写平涂 |
| 多图身材不一 | 比例只写了一次 | 比例段逐字复制 |

## 十、可复制的「部位段」模板

```
【比例】7 头身，肩宽约 1.6 头宽，腰线在身高 0.6 处，重心落在右脚。
【头面】颅顶圆润，发际线略呈美人尖；鹅蛋脸，颧骨微显，下颌角柔和，下巴小巧；
        柳叶眉，眼尾微上挑，虹膜墨黑带径向纹理，双高光；鼻梁挺直，鼻头小巧；
        上唇薄下唇厚，唇珠一点高光；耳廓清晰，耳垂饱满。
【颈肩】颈部细长，锁骨一道浅线，下颌投影落在颈上。
【躯干】肩线略斜，背部平坦见肩胛，腰细，骨盆宽约 1.5 头宽。
【上肢】手肘与腰线齐平，前臂线条收束，腕骨可见。
【手】五指，中指最长，拇指在掌侧与食指夹角 40°，轻握剑柄，指节有褶皱。
【下肢】大腿线条柔和，髌骨可见，小腿向踝收束，足弓自然，穿做旧皮靴。
【皮肤】平滑风格化皮肤，无毛孔，颊部有柔和腮红渐变。
```

**用法**：全身图整段抄；半身图删【下肢】；头像只留【头面】+【颈肩】；特写只留该部位。

---

## 十一、四条使用纪律

1. **部位段是常量**，跨图逐字复制；只改动作、场景、镜头。
2. **先写能看见的**：正脸写眉距与瞳色，侧面写鼻梁与下颌线，背面写发际与肩背——**每个角度都要有一个能认人的特征**。
3. **一个部位只写一处**：造型别在【头面】和【服装】里各写一遍，模型会当成两件事。
4. **写完过一遍 12 条崩坏表**，比事后修图便宜。

---

## 十二、建模友好的六个约束（要进 Blender 时加）

> AI 出不了拓扑，但**造型会决定好不好布线**。下面六条是"让图能被建模师用"的最小代价。

| # | 约束 | 写法 | 为什么 |
|---|---|---|---|
| 1 | **关节处干净** | `loose folds above and below the elbow, clean surface at the joint` | 肘/膝要环形 loop，横向密褶会打断 |
| 2 | **硬饰物不跨关节** | 护肩/绑带"在关节上下分段"，或改软质 | 跨关节硬物无法分权重 |
| 3 | **手指分开** | `fingers naturally separated, one-finger-width apart` | 指缝要分权重；并拢的图只能猜 |
| 4 | **头发分片** | `hair in distinct clumps, visible part line, bangs stop above the eyebrows` | 糊成一整块无法分片、无法做动力学 |
| 5 | **中性基型** | `neutral expression, mouth closed, eyes open looking straight` | 表情 morph 与 viseme 要从 neutral 起算 |
| 6 | **服装分层可拆** | 内层/外层/配件分开写，并给覆盖边界（袖口到前臂中段） | 绑定要把衣服做成独立壳，不能是"一整块布" |

**反向**（建模向专用）：
`single-strand hair, merged fingers, tight folds across the joint, armor crossing the elbow, heavy embroidery covering the whole garment`

> 详细交接规范（正交条件、A-Pose 角度、尺度换算、交付命名）见 `modeling-handoff.md`。
