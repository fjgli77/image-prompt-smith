# 题材图鉴：24 类世界观，一眼定位

> `style-atlas.md` 管**"用哪种介质/哪一家画"**（3D 国漫 / 皮克斯 / NPR / 定格…），
> 这一份管**"这是什么世界"**（仙侠 / 赛博 / 民国 / 蒸汽朋克 / 克苏鲁…）。
>
> **两者是乘法**：先定题材（世界观），再定风格（画法）。只定一个必漂。
>
> **一句话：题材不是形容词，是五件东西——配色 / 材质 / 服装 / 场景 / 标志物。**
> 五件齐了，模型才进那个世界；缺三件，它就回默认值：现代人穿古装、或者一片灰底。

---

## 零、通用拆解法（没收录的题材也能用）

任何题材，问五个问题就能拆出提示词骨架：

| # | 问 | 得到 | 例：赛博朋克 |
|---|---|---|---|
| 1 | **这个世界的颜色是什么？**（3 色 + 配比） | 配色 | 洋红 40 / 青 40 / 墨黑 20 |
| 2 | **东西是什么做的？**（主材 + 对比材） | 材质 | 湿混凝土 + 镜面金属 + 全息光膜 |
| 3 | **人怎么穿？**（主件 + 时代线索） | 服装 | 机能风外套 + 内衬发光条 + 义体接缝 |
| 4 | **人在哪里？**（前景/中景/远景各一件） | 场景 | 霓虹招牌 / 雨巷积水 / 塔楼群 |
| 5 | **一句话就能认出它的是什么？** | 标志物 | 全息广告 + 雨中倒影 |

**用法**：先答这五问，再去下面找最接近的一族抄"关键词串"。**答不出来，说明这个题设想清楚了但没写出来。**

## 二、分族关键词串（整串抄，别混两家）

### 东方族（1–6）

```
玄幻仙侠  3D donghua, oriental immortal fantasy, spirit motes, dharma projection,
          jade and silk, volumetric cloud sea, cold shaft light
古风宫廷  chinese period drama, court ritual costume, layered silk with gold embroidery,
          vermilion and ink, candlelit hall, lattice shadow
武侠江湖  wuxia, worn cotton and leather, bamboo hat, sword at the hip,
          inn interior, bamboo forest, hard side light with dappled shade
民国      republican-era Shanghai, qipao with high collar, wool coat and fedora,
          shikumen alley, tram wires, tungsten warm light, overcast soft
和风      japanese wa style, kimono with obi, haori, torii gate, tatami room,
          paper shoji light, lantern glow
东南亚    southeast asian temple, gold stupa, silk sarong, frangipani,
          humid tropical backlight, wet stone, emerald and gold
```

**东方族三个通病**：① 只写"古装"→ 出影楼戏服；② 纹样写满 → 糊；③ 不用"层"写服装 → 一块布。

### 现代族（7–11）

```
都市现代  contemporary urban, tailored coat, glass curtain wall, wet street,
          overcast diffuse light, one accent color
校园青春  nostalgic youth anime, sailor uniform with ribbon, classroom corridor,
          backlit golden afternoon light, dust in the beam
街头潮流  streetwear, oversized hoodie, cargo pants, sneakers, graffiti wall,
          hard flash, convenience store glow
职场制服  office uniform, crisp shirt, lanyard, glass partition, flat ceiling light
运动竞技  sports kit, team colors, sweat and motion, stadium floodlight, high contrast
```

**现代族三个通病**：① 写"现代"→ 出泛化模特；② 没有具体场所（街口/教室/球场）；③ 光写"自然光"→ 死平光。

### 未来族（12–15）

```
赛博朋克  cyberpunk, neon magenta and cyan, wet reflective asphalt,
          cybernetic seams, holographic signage, volumetric haze
硬科幻    hard sci-fi, spacecraft interior, cold white panels, holographic UI,
          orange warning strips, screen glow
机甲      mecha hangar, segmented armor plates, hydraulic joints, warning decals,
          maintenance arms, scarred metal
末世废土  post-apocalyptic wasteland, scavenged armor, dust haze, rusted vehicles,
          harsh sun, bleached palette
```

**未来族三个通病**：① 霓虹写满 → 发脏（主光色只能两种）；② 金属满反光 → 塑料感；③ 场景无尺度 → 像模型玩具。

### 奇幻族（16–21）

```
蒸汽朋克  steampunk, brass gears and pipes, corset and long coat, goggles,
          airship, steam backlight, warm tungsten
西幻      western fantasy, plate armor with heraldry, stone castle, overcast northern light,
          weathered steel and leather
暗黑哥特  gothic, pointed arches, black lace, corset gown, candelabra,
          single candle key light, deep shadow
童话绘本  storybook illustration, soft rounded shapes, cream and blush palette,
          cottage in the woods, gentle dappled light
神话宗教  mythology, temple with colossal statue, draped robe, gold ornaments,
          altar smoke, divine top light
克苏鲁    lovecraftian, wet organic textures, tentacles, sickly yellow-green,
          lighthouse in fog, single light source, oppressive darkness
```

**奇幻族三个通病**：① 写 `epic fantasy` 一个词 → 通用游戏海报；② 甲胄不写分件 → 杂兵甲；③ 暗部压死 → 看不出结构（永远留一处反光）。

### 亚文化与年代族（22–24）

Y2K      y2k aesthetic, glossy fabric, silver jewelry, low-rise, CRT screen,

80s复古  synthwave, neon grid, magenta and cyan gradient, leather jacket,

## 四、混搭：能混与不能混

| 混法 | 可行性 | 怎么做 |
|---|---|---|
| **同族叠加**（仙侠 + 暗黑 / 校园 + 雨天） | ✅ 最稳 | 主题材定五件，情绪只改配色与光 |
| **相邻族**（民国 + 克苏鲁 / 蒸汽朋克 + 西幻） | ✅ 可行 | 时代线索取一个，材质取另一个，**服装只跟一个** |
| **跨族对冲**（仙侠 + 赛博 / 校园 + 废土） | ⚠️ 需定主 | 必须声明"主题材"，另一族只做**局部元素**（配件/背景/纹样） |
| **三族以上** | ❌ | 必出四不像 |

**跨族混搭模板**：

```
主题材：〔A〕——它的配色、材质、服装、场景决定底层规则。
次题材：〔B〕——只允许出现在〔指定局部：配件/纹样/背景一侧/一件道具〕。
冲突裁决：造型夸张度与光逻辑听主题材的。
```

例（仙侠 × 赛博）：

```
主题材仙侠：月白 + 浅金，法袍与披帛，云海仙山，云隙冷光。
次题材赛博：仅左臂一只机械义肢（深灰分件 + 一条青色发光缝），其余不出现霓虹。
光逻辑仍按仙侠（体积光 + 柔过渡），不做霓虹双色。
```

## 五、题材与"图型/平台"的关系

| 题材偏冷门时 | 做法 |
|---|---|
| 模型不认识这个题材（如"民国 + 东南亚混血"） | **拆成通用元素**写：时代服装款式 + 具体建筑 + 具体光，别用题材名当关键词 |
| 中文平台（即梦/Seedream） | 中文写五件 + 结构词最稳；题材名只做氛围后缀 |
| MJ / Flux | 英文题材名有效（`wuxia` / `steampunk` / `gothic` 都认），但要补五件，否则出刻板印象 |
| SDXL | 题材靠 LoRA 定，词表只做微调；不要用 20 个题材词堆 |
| 3D 模型（text→3D） | **题材不进场**，只写几何/材质/用途（见 `text-to-3d.md`） |

## 六、八个跨题材通病（不分族，都会踩）

| 现象 | 根因 | 改法 |
|---|---|---|
| 出成"通用游戏 CG" | 五件只写了两件 | 补齐配色/材质/服装/场景/标志物 |
| 服装像影楼戏服 | 只写题材名，不写款式与层 | 写主件名 + 分层 + 材质 |
| 场景是灰底/贴纸 | 只写题材不写三层 | 见 `scene-space.md` 三段 |
| 颜色发脏 | 主光色 >2 | 限两色，第三色只做点缀 |
| 人物悬空 | 没写地面接触 | `contact shadow beneath the feet` |
| 光与环境不符 | 光位与场景光源矛盾 | 先定场景（光从哪来）再定光比 |
| 混搭四不像 | 没声明主题材 | §四 模板：主定规则，次只做局部 |
| 年代错位 | 服装与道具跨了时代 | 时代线索只取一个（服装或道具，别各取一个） |

## 七、自检（七项）

- [ ] 说得出这是 24 类里的哪一类（或哪两类的主次）
- [ ] 五件齐了：配色 / 材质 / 服装 / 场景 / 标志物
- [ ] 配色是 3 色 + 配比，不是"好看的颜色"
- [ ] 服装写了主件 + 分层 + 材质，不是题材名
- [ ] 场景有三层 + 接触
- [ ] 光有唯一主光源，且与场景来源一致
- [ ] 混搭时声明了主题材
