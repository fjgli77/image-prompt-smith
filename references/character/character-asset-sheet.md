# 人物资产图（Character Asset Sheet · 生产参考级）

> **和 `profile-poster.md` 的分工——这两个不是一回事，别混：**
>
> - **`profile-poster.md` = 角色档案海报**：给**人看**的展示页。讲究好看、有设计感，像官方 IP 定妆页 / 美术设定集内页。
> - **`character-asset-sheet.md`（本文件）= 人物资产图**：给**下一个环节用**的生产图。讲究信息完整、可测量、可复现——建模师、绑定师、动画师、周边制作方拿到它就能干活。
>
> 一句话：**档案海报是"宣传品"，资产图是"工程图纸"。**
> 资产图不追求单张惊艳，追求**每一格都回答了下一个人的一个问题**。

> ⚠️ **一句诚实的话（建模师视角）**：AI 出的资产图最高只能到 **A 级"准工程参考"**。
> 它不能给拓扑、UV、权重、表情形变目标——**真正可绑定/可进引擎的资产必须经过人工重拓扑**。
> 因此本文件的定位是"给建模师当 Image Plane 对位与造型依据"，不是"可直接导入的资产"。
> 精确的交接规范（正交条件 / A-Pose 角度 / 分层 / 尺度换算 / AI 做不到的七件事）见 `modeling-handoff.md`。

---

## 一、核心观念：资产图是一个"套装"，不是一张图

**最大的误区是把资产图当成一张超大的图。** 生产级的资产图是**一族相互配套的图页**，每一页负责一类信息：

| 页 | 名称 | 交给谁 | 回答什么问题 |
|---|---|---|---|
| P1 | 结构图 Construction | 建模/原画 | 形体怎么搭？地标在哪？ |
| P2 | 转面页 Turnaround | 建模/绑定 | 各个角度长什么样？ |
| P3 | 比例与剪影页 Proportion & Silhouette | 建模/主美 | 头身比多少？剪影认得出吗？ |
| P4 | 表情情绪页 Expression | 动画/2D | 这个脸怎么做表情？ |
| P5 | 姿势页 Pose | 动画 | 平时怎么站怎么动？ |
| P6 | 头面部细节页 Head Study | 原画/建模 | 五官结构、发型走线是怎样的？ |
| P7 | 服装结构页 Costume Construction | 服装/建模 | 衣服有几层？怎么缝合？ |
| P8 | 四肢道具配件页 Extremities & Props | 建模/周边 | 手、鞋、武器、背包什么样？ |
| P9 | 色彩规范页 Color Model | 全体/周边 | 标准色是什么？绝对不能漂 |
| P10 | 材质研究页 Material Study | 渲染/材质 | 皮革、金属、布料各是什么质感？ |
| P11 | 口型图 Viseme（可选） | 动画/配音 | 说话时嘴怎么动？ |
| P12 | 尺度对比图 Scale Chart（可选） | 关卡/演出 | 相对其他角色/物体多高？ |

> **不是每个项目都要全 12 页。** 短项目要「转面 + 表情 + 色卡」就够；主机级主角才需要全套。**先问"下一步是谁干什么"，再决定出哪几页。**

## 二、每页的要素与提示词

### P1 · 结构图（Construction Sheet）

**作用**：不看成品插画，只看**底下的形体怎么搭**。标出稳定地标：头高、肩宽、躯干长、髋位、四肢长、手大小、脚大小。

```
角色结构分解图，character construction sheet：
简化体块构成的角色（球体头、圆柱四肢、方体躯干），半透明叠加显示底层结构，
标注比例地标线：头顶、眼睛线、下巴、肩线、腰、髋、膝盖、脚底；
标注头身比、肩宽、躯干长度、手臂长度、手掌大小、脚长。
纯白背景，细线标注，技术图纸风格，干净无渲染质感。
【外貌锚点：<逐字复制>】
画质：8K，线条清晰，标注为装饰性占位文字。
```

### P2 · 转面页（Turnaround Sheet）

**作用**：最核心的一页。定"转起来长什么样"。

- **视角**：正面 / 3-4 前视 / 正侧 / 3-4 后视 / 背面（5 格最标准；最低配是正面+正侧+背面）
- **铁律**：同一比例尺、同一中性站姿（A-pose 或 T-pose）、共享水平地标线（头顶/眼线/肩/腰/髋/膝/脚底）
- **建模向必加四项**（只写 "A-pose" 不够）：
  ① 手臂外张角度 `arms 30° away from the torso`
  ② 手掌朝向 `palms facing inward, thumbs forward`
  ③ 手指状态 `fingers naturally separated, one-finger-width apart`
  ④ 中性表情 `neutral expression, mouth closed, eyes open looking straight`
- **不对称特征必须标在对的那一侧**

```
角色转面设定图，character turnaround sheet：
正面、3/4前视、正侧面、3/4后视、背面，五格水平排列，
同一中性 A-pose，人物高度完全一致、脚底对齐同一条水平线、共享水平地标辅助线；
服装、发型、配饰、缝线、图案在每个角度完全一致。
【外貌锚点：<逐字复制>】
【服装：<逐字复制>】
背景：浅灰纯色，细线分隔，技术标签（装饰性文字）。
光照：左上45度均匀柔光，全格一致。
画质：8K，全身完整入镜，横向长构图。
```

### P3 · 比例与剪影页（Proportion & Silhouette）

**作用**：检查**缩小成纯黑剪影还能不能被认出来**。这是设计成败的硬指标。

```
角色比例与剪影研究页，proportion and silhouette study sheet：
1. 左侧全身立绘 + 头身比例尺（每格一个头高，纵向刻度线）；
2. 中部三个纯黑剪影缩略图（正面/侧面/背面），只保留外轮廓；
3. 右侧标注：头身比、肩宽腰线腿长比例、服装外轮廓对剪影的影响、武器道具对剪影的影响。
【外貌锚点：<逐字复制>】
背景：米白色，技术规格图风格，细辅助线，标注为装饰性占位文字。
画质：8K，干净生产图布局。
```

### P4 · 表情情绪页（Expression Sheet）

> 详细方法见 `expression-specs.md`。这里是资产图口径的标准写法。

- **网格**：2×4 = 8 格最专业
- **推荐 8 表情**：neutral 冷静 / focused 专注 / faint smile 微笑 / skeptical 怀疑 / thoughtful 思考 / determined 坚定 / surprised-alert 惊讶警觉 / stern 冷峻
- **铁律**：无论嘴张多大，**头骨体积必须锁死**

```
角色表情情绪页，character expression sheet：
2行×4列网格，8个胸肩以上特写头像，逐格：
neutral 冷静、focused 专注、faint smile 微笑、skeptical 怀疑、
thoughtful 思考、determined 坚定、surprised-alert 惊讶警觉、stern 冷峻。
保持同一脸型、同一发型、同一瞳色、同一标志性特征、同一领口服装、同一气质，
头骨体积完全一致，每格下方配优雅英文标签。
【外貌锚点：<逐字复制>】
背景：纯白，面部大小一致、对齐同一水平线。
光照：左上45度均匀柔光，全格一致。
画质：8K，面部细节锐利，表情差异清晰可辨。
```

### P5 · 姿势页（Pose Sheet）

**作用**：传达角色的**体态与行为方式**。不是站姿，是"这个人怎么动"。

```
角色姿势研究页，character pose sheet：
4–6 个全身姿势，同一角色的不同体态：
放松站立、自信站姿、行走中、坐着、与道具互动、招牌动作。
保持完全一致的比例、服装结构与可识别剪影。
【外貌锚点：<逐字复制>】
背景：浅灰，姿势均匀分布、不重叠、不裁切。
光照：统一柔光。
画质：8K。
```

### P6 · 头面部细节页（Head Study / Facial Details）

**作用**：把脸拆透——正面/侧脸/背面/3-4 视角 + 各局部特写。

```
角色头部细节研究页，head study sheet：
包含 正面 / 侧脸 / 背面 / 3/4 视角头部；
眼睛特写、发型结构与发际线细节、耳朵细节、面部标记（痣/疤/刺青）特写、
脖颈与领口过渡细节。
保留同一发型结构、五官比例、瞳色、肤色、表情语言与独特身份标识。
【外貌锚点：<逐字复制>】
背景：纯白，技术标注。
画质：8K，细节锐利。
```

### P7 · 服装结构页（Costume Construction）

> 详细服装拆解见 `outfit-design.md`。这里只给资产图口径。

**作用**：**透视角色的穿着层级**——一件衣服是怎么穿上去的。

- **左侧**：完整角色上身；**右侧**：拆解部件
- **拆解清单**：外套 / 内搭 / 内着 / 领口 / 袖子 / 袖口 / 下摆 / 裤装或裙装 / 手套 / 鞋靴 / 腰带 / 绑带 / 护甲片 / 布料拼接线 / 扣件 / 金属边 / 装饰线
- **必加**：材质说明 + 结构标注

```
角色服装结构拆解页，costume construction breakdown：
左侧为完整角色立绘，右侧按穿着位置拆解服装部件：
外套、内搭、内层衣物、领口、袖子、袖口、下摆、下装、手套、鞋靴、
腰带、绑带、护甲片、布料拼接线、扣件、金属边、装饰线。
每件单品独立可读、不重叠，附材质说明与结构标注。
所有服装形状、颜色、材质与主体完全一致。
【外貌锚点：<逐字复制>】
背景：米黄色羊皮纸质感或浅灰，技术拆解图风格，手写体注释（装饰性占位文字）。
画质：8K，版式像高级产品设计拆解图。
```

### P8 · 四肢道具配件页（Extremities & Props）

**作用**：手、鞋、武器、包袋这些"容易糊"的部分单独出。

```
角色四肢道具配件页，extremities props and accessories sheet：
展示手部动作与手势、手套、鞋靴的正面/侧面/背面、武器特写、
道具特写、腰部挂件、首饰、机械零件、背包与袋子、装饰符号。
所有道具延续同一设计语言（同色系、同材质体系、同风格）。
【外貌锚点：<逐字复制>】
背景：纯白，干净技术标注。
画质：8K。
```

### P9 · 色彩规范页（Color Model）

**作用**：色值是多少，**绝对不能漂**。这是资产图的硬规范。

```
角色色彩规范页，color model sheet：
一排标准色块，按角色分区排列：
肤色 / 发色 / 主服装色 / 次服装色 / 强调色 / 配饰与材质色。
每个色块下方标注色值（装饰性文字），
配一张中性光下的角色小图作为配色参照。
【外貌锚点：<逐字复制>】
背景：纯白，色块整齐排列，设计规范图风格。
```

> **资产图口径的配色描述法**（比"蓝色外套"强一百倍）：
> ❌ `blue coat`
> ✅ `deep navy wool coat with matte surface, desaturated blue-grey in shadow, silver metal fasteners, no teal shift`

### P10 · 材质研究页（Material Study）

```
角色材质研究页，material study sheet：
展示角色设计中出现的主要材质球与局部应用：
皮革、金属、布料、针织、丝绸、塑料、玻璃、亚麻、牛仔、头发、皮肤。
每格展示该材质的表面行为、纹理、反射率与构造方式。
【外貌锚点：<逐字复制>】
背景：中性灰，材质球 + 局部应用图对照，专业材质规范风格。
画质：8K，材质感真实可辨。
```

### P11 · 口型图（Viseme Chart，有对白的项目才要）

```
角色口型图，viseme / mouth shape chart：
展示标准发音口型序列，A / E / I / O / U / M / F / L / W / rest，
每格一个头部正面特写，只改变嘴部形状，
保持同一脸型、同一头骨体积、同一五官位置。
【外貌锚点：<逐字复制>】
背景：纯白，每格下方标注音素（装饰性文字）。
画质：8K。
```

### P12 · 尺度对比图（Scale Chart）

```
角色尺度对比图，scale chart：
同一水平面上并排站立：目标角色 + 一个标准成年人体型参照物 + 一个常见物体（如门/桌子），
标注各自身高数值与相对比例。
【外貌锚点：<逐字复制>】
背景：浅灰，工业规格图风格。
画质：8K，透视统一（正交）。
```

## 三、一页式资产总板（Asset Board · 只出一张时的最优解）

如果只能出一张，用这个"九宫格式资产总板"——比档案海报更偏工程感、更少装饰：

```
专业角色资产总板，professional character asset board / production model sheet：

【01 主视觉肖像】左上一个较大的头肩或3/4肖像，中性专业表情，作为身份锚点。
【02 全身转面】正面 / 3/4前 / 正侧 / 3/4后 / 背面，同一比例尺，中性站姿，
             头顶/眼线/肩/腰/髋/膝/脚底水平对齐。
【03 表情研究】6–8 格表情网格，同一张脸，可信的面部表演而非夸张变形。
【04 招牌姿势】4–6 个全身姿势研究。
【05 服装与细节特写】发型、面部、领口、袖、鞋、珠宝配饰、徽记纹样、重要道具的特写格。
【06 材质研究】金属、皮革、布料、丝绸等主要材质的表面表现。
【07 色彩规范】一排色块：肤/发/主服装/次服装/强调/配饰。
【08 比例与剪影】转面旁加低调的比例辅助线与剪影缩略图。
【09 设计连续性】整页为同一角色的唯一标准，任何一格不得出现换脸/换装/比例漂移。

【外貌锚点：<逐字复制>】
【渲染风格：<从 render-styles.md 抄一段>】
【人物风格：<从 character-styles.md 抄风格家族>】
版面：横向 16:9，米白/浅灰中性studio背景，精炼的编辑级生产板美学，
     层级分明、留白充足、低调技术辅助线、克制的标签排版（装饰性文字），
     无装饰性杂物，无重叠人物，无裁切身体。
光照：统一左上前方45度柔光，全板一致。
画质：8K，清晰可读的细节，专业艺术指导级质感。
```

## 四、三次元 vs 二次元：交付重点差异

| 环节 | 3D 项目重点 | 2D 项目重点 |
|---|---|---|
| 转面 | **正交投影**、严格比例尺、结构可建模 | 透视可适度，重在画风统一 |
| 结构图 | 必有（建模要地标） | 可选 |
| 表情 | 中性表情优先（绑定基准） | 夸张表情可上 |
| 服装 | 缝合结构、层次、材质 | 褶皱走向、色块归纳 |
| 色卡 | 必须精确 | 必须有，但可带手绘感 |
| 口型 | 视语音需求 | 番剧必配 |
| 手部 | 五指结构清晰 | 可简化但要一致 |

## 五、资产图自查清单（交付前逐条过）

**跨格一致性**
- [ ] 各视角**同一比例尺**、脚底同一水平线、地标线对齐？
- [ ] 脸型 / 发型 / 瞳色 / 标志性特征**跨所有格一致**？
- [ ] 不对称特征（单耳饰、刀疤、机械臂）是否在**正确的一侧**，没被镜像？
- [ ] 服装缝线、图案、配饰位置跨视角一致？
- [ ] 色卡是否与服装配色一致，且颜色没漂（不是"蓝得像绿")？

**信息完整性**
- [ ] 每一格都回答了下一个环节的一个具体问题（不是重复的画面）？
- [ ] 结构图的地标是否标全（头/肩/腰/髋/膝/脚）？
- [ ] 剪影缩略图缩小后还能认出角色？
- [ ] 关键道具、复杂机关是否给了特写？
- [ ] 材质是否给了"它反射/它吸光"的说明，而不只是名字？

**可生产性**
- [ ] 文字是否走装饰性占位（避免乱码）？
- [ ] 有无裁切、重叠、多余人物、多手多脚？
- [ ] 缩小到游戏实际观看尺寸，重要特征还读得出来？
