# 视图规格与示例提示词

生成前读取本文件对应章节，严格按既定视角顺序与网格排布书写提示词。

---

## 〇·〇 先判两件事：给谁看 / 用什么姿态（口径统一表）

> 这一节是为了消灭三处历史上互相打架的口径。**先在这里定，再往下抄模板。**

### 1. 画幅：按"人物形状"选，不按"视图数量"选

| 场景 | 画幅 | 理由 |
|---|---|---|
| 三格**长裙 / 礼服 / 大摆**并排 | **3:4 竖幅**（三列纵向排开） | 16:9 会把裙摆压扁、下摆被裁 |
| 三格常规角色（短装 / 裤装） | **16:9** | 横向留白舒服，人物不挤 |
| 印刷长条 / 网页通栏 | 3:1 | 只在明确要"长条"时用 |
| 四格以上 | 16:9 或 1:1（2×2 / 3×3） | 格数越多，单格越接近方形 |

**判断口诀**：**先看裙摆宽度，再看格数**。裙摆越宽，画幅越竖。

### 2. 姿态：给建模用 A-Pose，纯展示用自然站姿

| 这张图给谁 | 姿态 | 为什么 |
|---|---|---|
| 建模 / 绑定 / 进 DCC | **A-Pose**（双臂外张 15–45°、掌心朝内、五指分开） | 绑定姿态，权重好分 |
| 纯展示（设定集 / 甲方看图 / 封面） | **自然站姿**（重心在一腿，肩髋反向） | A-Pose 在展示稿上显得僵硬 |
| 资产级正交图 | A-Pose + 地标线 + 平光 | 见 `modeling-handoff.md` |

**T-Pose 只在明确要"最易量测"时用**，且必须在提示词里写 `T-pose`，不能与 A-Pose 混写——两者是两种生产口径，混用会导致绑定返工。

### 3. 画质词：本文件所有示例都不写 `8K / 4K / 锐利细节`

理由见 `SKILL.md` 铁律 3：这一整类在新模型上基本不增加清晰度，只增加噪点风险。
**清晰度靠出图尺寸与材质语义（`crisp edge, clean lineart, matte fabric`），不靠分辨率词。**

## 〇、视图体系总览（三层分类，先定位再选规格）

> **"视图"不只是"视角"。** 行业里通常分三层，写提示词前先判断用户要的是哪一层。

### 第一层 · 2D 人物设计常用视图（看"角度"）

| 视图类型 | 内容 | 作用 |
|---|---|---|
| **正面图 / 前视图** | 角色正对镜头 | 看脸型、五官、正面服装结构 |
| **侧面图 / 侧视图** | 左/右侧 90° | 看头骨、鼻梁、下颌、体侧轮廓、服装厚度 |
| **背面图 / 后视图** | 角色背面 | 看发型后部、背部服装、披风、配件 |
| **3/4 侧面图** | 约 45° 角 | **最常用、最能体现体积和角色气质** |
| **顶视图 / 俯视图** | 从头顶往下看 | 看肩宽、发型俯视轮廓、帽子/头饰结构 |
| **底视图 / 仰视图** | 从下往上看 | 看鞋底、裙底结构、下摆层次 |
| **透视图** | 带近大远小的立体视角 | 展示整体空间感、动态和体积 |
| **转面图 / Turnaround** | 同一角色多角度连续排列 | 建模、动画、周边制作的**核心参考** |

**转面图常见规格**（越往后越难，越容易崩）：

| 规格 | 内容 | 定位 |
|---|---|---|
| **三视图** | 正面、侧面、背面 | **最低配** |
| **四视图** | 正面、侧面、背面、3/4 侧面 | **常用** |
| **五视图** | 正面、左/右侧、背面、顶视或 3/4 | 信息更全 |
| **六视图** | 含俯视 + 仰视 | 需要顶/底结构 |
| **八视图** | 每 45° 一个角度 | 高精度建模、手办 |

### 第二层 · 角色设计专项视图 / 图稿（看"专项信息"）

> **这些不一定是"视角"，但属于人物设计设定的一部分。**

| 专项图稿 | 内容 | 作用 |
|---|---|---|
| **比例图** | 标出头身比、各部位长度关系 | 锁定比例，防漂 |
| **剪影图** | 只着外轮廓 | 检查角色辨识度（缩小成黑影还认得出吗） |
| **表情图 / 表情集** | 喜怒哀乐、眨眼、张嘴等 | 面部情绪范围 |
| **口型图** | 动画/游戏口型参考 | 对口型、配音 |
| **动作姿势图** | 站姿、战斗姿态、常用动作 | 体态与行为方式 |
| **结构 / 解剖图** | 肌肉、骨骼、关节结构 | 建模、绑定、画准 |
| **服装拆分图** | 外套、内搭、配饰分层 | 服装设计与制作（详见 `outfit-design.md`） |
| **细节特写图** | 面部、手部、鞋、武器、纹样 | 复杂部位说清 |
| **色指定图 / 色稿** | 标准色、材质分区 | 色彩规范（绝不能漂） |
| **材质 / 质感说明图** | 金属、布料、皮肤等 | 材质规范 |
| **道具与配件图** | 武器、背包、饰品独立视图 | 道具交付 |

### 第三层 · 3D 人物建模常用视图（看"软件操作"）

> **AI 出图时，这一层主要用来"对齐生产语言"**——如果你出的资产图是给 3D 团队用的，按这些术语写规格，对方一看就懂。

| 视图 | 内容 |
|---|---|
| **正交视图** | 前视图、后视图、左视图、右视图、顶视图、底视图（`orthographic projection`） |
| **透视图** | 自由旋转观察体积 |
| **参考图视图 / Image Plane** | 把正面、侧面、背面图贴到对应平面 |
| **线框图视图** | 看拓扑布线 |
| **实体 / 材质 / 渲染视图** | 检查造型和贴图 |
| **UV 视图** | 展开贴图用 |
| **骨骼 / 绑定视图** | 做动画前检查 |

> **AI 出图时必须写 `orthographic projection`（正交投影）的场景**：六视图含俯/仰视、3D 建模参考图、尺度对比图、任何需要"严格可比"的转面。不写就会透视畸变，各格比不了。

**三层对照速查：**

```
要"角度"        → 第一层，出转面图（三~八视图）
要"专项信息"     → 第二层，出对应专项图稿（比例/剪影/表情/服装拆解/色指定…）
要"给3D团队用"   → 第三层口径：正交、地标线、UV/线框（说明用途即可，AI 可示意）
```

## 通用八段公式

```
【外貌锚点】+【视图数量与排布】+【姿态规范】+【服装/道具细节】+【画风】+【背景与排版】+【光照】+【画质参数】
```

多视图三铁律（每条提示词都要写）：
1. 统一比例尺 — 所有视图人物高度一致、脚底对齐同一水平线
2. 统一光照 — 一个光源方向（推荐「左上45度均匀柔光」）
3. 统一留白 — 等距排列、细灰分隔线

## 三视图（正面 / 侧面 / 背面）

- **视角**：正面(0°) → 正侧面(90°) → 背面(180°)
- **排布**：横向 3 格，等距
- **比例**：常规 16:9；**长裙/礼服三列 → 3:4 竖幅**（见〇·〇 画幅表）
- **要点**：最基础的转面参考，侧视必须是严格 90 度

```
角色三视图设定稿，character turnaround sheet，同一角色并排三个完整全身立绘：
左：正面视角；中：正侧面90度视角；右：背面视角。
【外貌锚点：round face, almond-shaped amber eyes, mole under left eye, silver waist-length straight hair with blunt bangs, slim build, 168cm】
【服装：深蓝色机能风短外套、黑色高腰短裤、白色长筒袜、厚底靴】
标准 A-Pose 站姿：双臂自然下垂并向外张开约 30°，手肘微屈，掌心朝内、五指分开；中性表情，闭嘴平视。三视图人物身高比例完全一致、脚底对齐同一条水平线。
背景：纯白背景，无阴影投地，视图之间等距排列、带细灰色分隔线。
画风：日系二次元动画角色设定图，清晰线稿，赛璐璐上色，干净描边。
光照：左上45度均匀柔光，无硬阴影。
画质：全身完整入镜，横向长构图；边缘干净、材质分区清楚（不写 8K/4K）。
```

## 四视图（正面 / 3/4侧 / 正侧 / 背面）

- **视角**：正面(0°) → 3/4前侧(45°) → 正侧(90°) → 背面(180°)
- **排布**：横向 4 格 或 2×2 网格
- **比例**：4:1 或 1:1
- **要点**：3/4 视角是四视图中信息量最大的视角，注意朝向一致（统一为同一侧前方）

```
角色四视图设定稿，4-view character reference sheet：
第1格 正面全身；第2格 3/4侧前方45度；第3格 正侧面90度；第4格 背面。
【外貌锚点：25-year-old male swordsman, sharp angular jawline, crimson heterochromia eyes, black medium-length tied-back hair, old scar on left cheek, muscular build, 182cm】
【服装：皮质胸甲、红色披风、腰间佩剑、皮革护臂与战靴】
姿态：自然站姿（A-pose），双臂微张约30度；四格人物居中、高度完全一致。
背景：浅灰色纯色背景，2×2 网格排布，每格内角色完整不被裁切。
画风：半写实游戏概念设计（semi-realistic game concept art），厚涂质感，柔和体积光。
光照：左上45度均匀柔光。
画质：超高细节，4K，边缘锐利，色彩统一。
```

## 五视图（正面 / 两侧3/4 / 正侧 / 背面）

- **视角**：正面(0°) → 3/4右前(45°) → 正右(90°) → 3/4右后(135°) → 背面(180°)
- **排布**：横向 5 格，等距
- **比例**：5:1 或 4:1
- **要点**：单侧环绕转面，5 格姿态必须完全一致（统一垂手或统一叉腰）

```
角色五视图转面设定图，5-view turnaround：
依次为 正面、3/4右前侧、正右侧面、3/4右后侧、正背面。
【外貌锚点：22-year-old female mechanic, orange fluffy short hair, oil smudge on cheek, right mechanical prosthetic arm, 165cm】
【服装：沾满机油的连体工装裤、护目镜挂脖、工具腰带】
全身直立站姿，双脚并拢，自然垂手（或统一双手叉腰，五格必须一致）。
背景：米白色背景，五格横向等距排列，每格灰细框线，角色头顶与脚底对齐。
画风：欧美卡通渲染（stylized cartoon），粗描边平涂，干净配色。
光照：左上45度均匀柔光，统一光源。
画质：人物完整，构图横长，轮廓清晰、无多余物件。
```

## 六视图（四面包围 + 俯视 / 仰视）

- **视角**：第一行 正面 / 背面 / 正左 / 正右；第二行 俯视顶视 / 仰视底视
- **排布**：2 行 × 3 列
- **比例**：4:3 或 3:2
- **要点**：俯视与仰视**必须标注 `orthographic projection`（正交投影）**，否则透视畸变；正左与正右是独立两格，不要合并

```
角色六视图设定稿，6-view orthographic character sheet：
第1行 正面、背面、正左侧、正右侧；第2行 俯视顶视图、仰视底视图。
【外貌锚点：30-year-old female mage, deep purple long wavy hair, golden pupils, 172cm, flowing robe】
【服装：星空纹样长袍、悬浮符文腰带、尖顶法师帽、长靴】
姿态：标准 A-pose，六格姿态完全一致，人物比例尺严格统一。
背景：白色背景，2行×3列网格，细灰分隔线，每格内角色完整居中对齐，脚底水平线一致。
画风：厚涂概念设定（digital painting concept sheet），柔和光影，细节精致。
光照：左上45度均匀柔光。
画质：4K 超高分辨率，正交投影（orthographic projection），无透视畸变。
```

## 八视图（360度全转面，每45度一格）

- **视角**：0°正面 → 45°右前 → 90°正右 → 135°右后 → 180°正后 → 225°左后 → 270°正左 → 315°左前
- **排布**：4 行 × 2 列 或 2 行 × 4 列
- **比例**：1:1 或 3:4
- **要点**：完整 360 度环绕，肩线与高度严格一致；最容易崩，建议逐张生成

```
角色八视图360度转面设定图，8-view character turnaround sheet，均匀绕Y轴每45度一格：
正面0°、右前45°、正右90°、右后135°、正后180°、左后225°、正左270°、左前315°。
【外貌锚点：20-year-old female pilot, chestnut twin tails, green eyes, 160cm】
【服装：棕色飞行夹克、白色围巾、短裙、马丁靴】
标准A-pose，八格人物高度与肩线严格一致、脚底同一水平线，形成完整转面参考。
背景：纯白背景，4行×2列 或 2行×4列 网格，等距排列，细灰分隔线。
画风：日系精致动画设定，干净的赛璐璐上色 + 轻微高光。
光照：统一光源（左上前方45度）。
画质：全身完整，正式设定集排版风格，边缘干净、留白均匀。
```

## 人物设计图（Character Design Sheet · 完整设定页）

> **完整版式（含档案字段/台词/表情参考/细节特写/色卡/条形码的分区与提示词模板）见 `profile-poster.md`**，本节只给"简约版设定页"的通用写法。要做参考图那种完整角色档案海报，读 profile-poster.md。

- **内容区块**：主视觉全身立绘 / 三视图转面 / 面部表情组 / 服装配饰拆解 / 色卡色板 / 身高比例标注
- **版式**：专业美术设定集排版，A2 竖版海报
- **要点**：区块清晰、对齐、细线分隔；标注文字设为装饰性假文字（避免乱码）

```
完整人物设计设定集页面，character design sheet / model sheet，一页包含：
① 主视觉全身立绘（大尺寸，展示完整造型）
② 三视图转面（正面/侧面/背面小图）
③ 面部特写 3 组表情（微笑、生气、惊讶）
④ 服装与配饰细节拆解（帽子、腰带、武器等单品放大图）
⑤ 色卡色板（列出主色、辅色、强调色的色块与色号位置）
⑥ 身高比例标注（头身比、参考线与尺寸数字）
【外貌锚点：18-year-old eastern demon-slayer, black hair with red highlights, golden eyes, 170cm, cold elegant aura】
【服装：黑色高领汉服改良长袍、红色腰带、青铜护腕、背负长刀】
版式：专业美术设定集排版，区块清晰对齐，区块间用细线分隔，标注为装饰性假文字。
画风：高质量游戏原画概念设计（AAA game concept art），写实厚涂 + 清晰线稿结合，柔和电影级光照。
光照：柔和均匀设定稿光。
画质：A2 竖版海报比例，印刷级排版；轮廓与色块干净，细节集中在面部与主件。
```

| 需求 | 推荐规格 |

| 快速定造型、做 3D 建模参考 | 三视图 |

## 规格难度与崩图预警

| 规格 | 崩图风险 | 建议 |
|---|---|---|
| 三视图 | 低 | 可一图直出 |
| 四/五视图 | 中 | 一图直出 + 接受小瑕疵 |
| 六/八视图 | 高 | **逐张生成再拼版**，必写 `orthographic projection` |
| 资产图套装（多页） | 高 | 必分页逐张出，**同一锚点块逐字复制** |
| 服装拆解环绕图 | 中高 | 中心立绘 + 环绕元素，明确"不重叠" |
| 一图塞入档案海报全部区块 | 最高 | 走 `profile-poster.md` 路径 B 分块拼版 |
