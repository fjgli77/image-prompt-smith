# 10 出图前自检与评测

> 交付前跑一遍。**30 项里任何一项 P0 未过，不要发给用户。**

---

## 一、30 项自检清单

### A 组｜结构（8 项）

- [ ] A1 主体出现在提示词前 20 字内
- [ ] A2 十一格里，②③④⑤⑥⑦ 六个核心格都有对应信息
- [ ] A3 主体是具体名词，不是"东西/场景/氛围"
- [ ] A4 动词 ≤2 个，主次明确
- [ ] A5 场景描述字数 ≤ 主体描述的 1.5 倍
- [ ] A6 风格词 ≤3 个，同族
- [ ] A7 光段含"光位 + 光质"（不是只有"柔和/明亮"）
- [ ] A8 镜头段含"景别 + 焦段"（不是只有"特写"）

### B 组｜一致性（6 项）

- [ ] B1 没有互相矛盾的时间/天气（夜景 + 明亮阳光）
- [ ] B2 没有互斥光位（逆光 + 正面光）
- [ ] B3 没有互斥景别（大远景 + 特写）
- [ ] B4 没有互斥风格（写实 + 动漫）
- [ ] B5 数字与数量前后一致
- [ ] B6 色温与时间/场景匹配

### C 组｜可执行性（6 项）

- [ ] C1 画幅用数字比例（`3:4`），不用"竖版"
- [ ] C2 权重语法与目标平台匹配（SD 才用括号）
- [ ] C3 参数没有混进正文（`--ar` 不出现在 SD 提示词里）
- [ ] C4 反向写法与平台匹配（SD 独立字段 / MJ `--no` / 自然语言禁令句）
- [ ] C5 长度在平台建议区间内
- [ ] C6 没有"高级/大气/唯美/精致"这类空词（或已换成具体词）

### D 组｜交付形态（6 项）

- [ ] D1 用途要求的留白比例已写进提示词
- [ ] D2 留白给了颜色或明确"纯净无元素"
- [ ] D3 文字策略已定档（零文字 / 假文字 / 真文字）
- [ ] D4 若赌真文字：文案有引号 + 位置 + 层级 + 禁译
- [ ] D5 若不能赌：已改为留白后期，并在交付说明里写明
- [ ] D6 避开了平台禁止项（如电商主图不得带文字/道具）

### E 组｜稳健性（4 项）

- [ ] E1 没有把"手/正脸"放在不可控位置（必要时藏手、侧脸）
- [ ] E2 背景元素 ≤3 件
- [ ] E3 已加基础反向（变形/多元余/水印/模糊）
- [ ] E4 若为系列图：锚点块已逐字复用

## 二、评分表（100 分）

| 维度 | 权重 | 评分要点 |
|---|---|---|
| **结构完整** | 25 | 十一格覆盖率；缺核心格每格 −5 |
| **可执行性** | 25 | 平台语法正确、参数正确、长度合理 |
| **视觉精度** | 20 | 光位/焦段/景别/材质是否可量化 |
| **冲突为零** | 15 | 语义互斥项数量（每个 −5） |
| **交付匹配** | 15 | 画幅/留白/文字策略是否符合用途 |

**分档**：

| 分 | 判定 |
|---|---|
| 90–100 | 可直接交付 |
| 75–89 | 可交付，标注 1–2 个风险点 |
| 60–74 | 必须先修 P0 |
| <60 | 重写（通常是结构问题，不是词的问题） |

## 三、机检脚本用法

```bash
# 基本
python scripts/prompt_lint.py --text "提示词全文" --platform mj --purpose poster

# 从文件读
python scripts/prompt_lint.py --file prompt.txt --platform seedream

# 机器可读
python scripts/prompt_lint.py --file prompt.txt --json
```

输出示例：

```
=== 提示词机检 ===
平台：mj ｜ 用途：poster ｜ 长度：86 字
得分：68 / 100   [P0×2 P1×3 P2×1]

[P0] 冲突：写实 与 动漫 同时出现 → 删其一（05 混合规则）
[P0] 缺画幅：用途为海报但未给比例 → 加 --ar 3:4
[P1] 空词：'高级感' 无法执行 → 换成光位/焦段（04 速查表）
[P1] 画质词堆砌：8k/ultra detailed/masterpiece 共 4 个 → 保留 ≤2（铁律 5）
[P1] 动作过多：检测到 3 个动词 → 保留 1 个（铁律 2）
[P2] 建议补光位：当前只有'柔和的光'
```

**脚本是启发式**：命中后自己复核，不要机械照改。P0 必须处理后重跑一次。

## 四、A/B 对照法（判断哪句在起作用）

1. 固定 seed，固定提示词 90%
2. **只改一格**，出一张
3. 两张并排，看差异是否来自那一格
4. 记录：改了什么 → 变化是什么 → 保留还是回退

**不要做的**：一次改三处然后说"好多了"——你无法知道哪句有用，下次还得重猜。

## 六、"看起来对但其实错"的六种情况

| 表面 | 实际 |
|---|---|
| 提示词很长很专业 | 主体被淹没，出图平庸 |
| 画质词堆了 8 个 | 增加噪点与假 HDR 风险，不增加清晰度 |
| 反向词写了 60 个 | 画面呆板，模型什么都不敢画 |
| 风格写了 5 个形容词 | 互相抵消，出"四不像" |
| 写了"电影感" | 模型只加重暗角，不改光 |
| 留白写了"留白" | 模型理解成"稍微空一点"，实际填满 |

- **推荐平台**：Seedream 5.0 Pro（中文原生）｜备选：MJ v7 `--style raw`

  1. 图内中文标题成功率约 60%，失败请用留白后期叠字
  2. 手部未入画，如需人物请单独生成

- **机检**：92 分，无 P0
